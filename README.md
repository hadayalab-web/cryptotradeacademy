# WhaleShield (CryptoSignal AI)

## Overview
Automated cryptocurrency signal bot powered by AI (Grok) and On-chain data (CryptoQuant).
Detects whale movements and generates high-accuracy trading signals.

## Setup
1. Install dependencies: `npm install`
2. Configure `.env.local` with API keys.
3. Start the bot: `npm start`

## Features
- Tier 1: Bitcoin Core Analysis (Whale Inflow, MPI)
- AI Analysis: Grok 3 Integration
- Alerts: Telegram Real-time Notifications

## Scripts
- `npm start`: Run the monitor process (Production)
- `npm run test:local`: Run a single test cycle
- `npm run test:grok`: Test AI connection
