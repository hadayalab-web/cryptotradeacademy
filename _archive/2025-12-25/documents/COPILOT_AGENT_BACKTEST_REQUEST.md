@copilot-swe-agent バックテスト機能の改善タスクを依頼します。テスト・デバッグが真骨頂の皆さんにお願いしたいタスクです！

## 📋 依頼内容

詳細は `COPILOT_AGENTS_BACKTEST_TASKS.md` を参照してください。

### タスク1: 過去クリティカルイベント検証機能の強化（PR用） 🔴 高優先度

**目標**: 過去の重要な市場イベント時に、アルゴリズムがどのようなアラートを出力していたかを検証し、PR用の詳細レポートを生成

**実装内容**:
1. クリティカルイベントデータの定義（イベント構造、メタデータ）
2. イベント検証ロジック（アラート発火の有無、タイプ、タイミング）
3. 詳細レポート生成機能（Markdown形式、JSON形式）
4. PR用レポートテンプレート

**参考ファイル**:
- `scripts/backtest/run_events_backtest.js` - 基本実装あり（拡張が必要）
- `data/events_backtest_summary.json` - 既存のサマリーデータ

### タスク2: アルゴリズム自動チューニング機能の完成 🟡 中優先度

**目標**: `autoTuner.js`の評価メトリクスを実装し、実際のバックテストエンジンと統合

**実装内容**:
1. 評価メトリクスの実装（Accuracy, Precision, Recall, F1 Score, Sharpe Ratio, Max Drawdown）
2. バックテストエンジン（`eval_signals.js`）との統合
3. 最適化アルゴリズムの改善（グリッドサーチ、オプション: ベイズ最適化）
4. 結果の保存と可視化

**参考ファイル**:
- `scripts/backtest/autoTuner.js` - 基本実装あり（評価メトリクスが簡易版）
- `scripts/backtest/eval_signals.js` - バックテストエンジン

### タスク3: テスト・デバッグ支援 🟢 低優先度

**追加でお願いしたいこと**:
1. バックテストデータの検証（整合性確認、異常値検出）
2. エラーハンドリングの強化
3. パフォーマンス最適化

## 🎯 期待される成果

1. **PR用レポート**: 過去のクリティカルイベントでのアルゴリズム性能を示す詳細レポート
2. **自動チューニング**: アルゴリズムパラメータを自動的に最適化する機能
3. **品質向上**: バックテスト機能の信頼性と保守性の向上
