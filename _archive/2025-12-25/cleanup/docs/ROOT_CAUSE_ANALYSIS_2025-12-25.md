## 🎯 根本原因

### 問題の本質

**`vercel.json`の`includeFiles`構文が間違っていた**

#### ❌ 間違った構文（3回適用された）
```json
{
  "functions": {
    "api/cron.js": {
      "includeFiles": "config/**"  // ← 文字列形式（間違い）
    }
  }
}
```

#### ✅ 正しい構文（最終的に修正された）
```json
{
  "functions": {
    "api/cron.js": {
      "includeFiles": ["config/**"]  // ← 配列形式（正しい）
    }
  }
}
```

### Vercel公式ドキュメントの要件

Vercelの`includeFiles`プロパティは**配列形式**である必要があります：
- ✅ 正しい: `"includeFiles": ["config/**"]`
- ❌ 間違い: `"includeFiles": "config/**"`

文字列形式では、Vercelがファイルを認識せず、デプロイバンドルに`config/`フォルダが含まれませんでした。
