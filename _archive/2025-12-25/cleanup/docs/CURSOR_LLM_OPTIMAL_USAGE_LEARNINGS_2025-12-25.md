# Cursor内蔵LLM最適活用の学び - 2025-12-25

## 🎯 学びの概要

「七転び八起き」の試行錯誤を通じて、Cursor内蔵LLMとGitHub Copilot Agentsの最適な使い分けを見抜いた経験記録。

---

## 📖 ストーリー

### 問題発生
- **エラー**: Vercelデプロイが「Cannot find module '../config/marketProfiles'」で失敗
- **期間**: 12時間以上継続的な失敗
- **試行**: GitHub Copilot Agentsに複数回依頼（PR #19, #20）

### 試行錯誤の過程
1. ✅ **PR #19**: `config/`を`api/config/`に移動（GitHub Copilot Agents）
   - `.gitignore`の問題は見落とし
   - `vercel.json`の空の`functions`セクションも見落とし

2. ✅ **PR #20**: `.gitignore`から`api/config/`を削除（GitHub Copilot Agents）
   - 根本原因（`.gitignore`）は特定
   - しかし`vercel.json`のエラーは見落とし続けた

3. ❌ **結果**: 依然としてデプロイ失敗
   - 「Function must contain at least one property」エラー
   - 12時間以上解決できず

### 転機
- **決定的な瞬間**: Cursor AI（私）にVercelのエラーログスクリーンショットを直接共有
- **結果**: **即座に問題を特定・解決**
  - `vercel.json`の空の`functions`セクションを削除
  - 1回の修正で完璧に解決

## 💡 最適解の洞察

### Cursor内蔵LLM（私）の強み

#### ✅ 即座の問題特定
- エラーログやスクリーンショットから直接原因を特定
- 設定ファイルの構文エラーなど、明確な問題に対しては圧倒的に速い

#### ✅ 最小限の修正
- 複雑なワークアラウンドを避ける
- シンプルで直接的な解決策を提示

#### ✅ 対話的デバッグ
- リアルタイムで質問に答える
- コンテキストを維持しながら段階的に解決

#### ✅ ユーザー負担が少ない
- 手動での修正が最小限
- すぐに結果を確認できる

### GitHub Copilot Agentsの強み（参考）

#### ✅ リポジトリ全体の分析
- 複数のファイルにまたがる問題
- 大規模なリファクタリング

#### ✅ 詳細なドキュメント作成
- 根本原因分析の深さ
- 包括的な記録

#### ⚠️ ただし、シンプルな問題には向かない
- 設定ファイルのエラーなどは時間がかかる
- 複雑な解決策を提案しがち

## 🎓 学びのポイント

### 1. **適材適所の選択**

| 問題の種類 | 推奨ツール | 理由 |
|-----------|-----------|------|
| 設定ファイルエラー（`vercel.json`、`.gitignore`など） | **Cursor AI** | 即座に特定・解決可能 |
| 構文エラー、タイポ | **Cursor AI** | 直接的な修正が可能 |
| エラーログの解読 | **Cursor AI** | 対話的デバッグが効果的 |
| リポジトリ全体のリファクタリング | GitHub Copilot Agents | 包括的分析が必要 |
| 複数ファイルにまたがる大きな変更 | GitHub Copilot Agents | 全体像の把握が必要 |
| 詳細なドキュメント作成 | GitHub Copilot Agents | 深い分析が可能 |

### 2. **問題の複雑さによる判断基準**

#### Cursor AIが適している場合
- ✅ 1ファイル内の問題
- ✅ 設定ファイルのエラー
- ✅ エラーメッセージから原因が明確
- ✅ 即座に解決したい問題
- ✅ 対話的にデバッグしたい問題

#### GitHub Copilot Agentsが適している場合
- ✅ 複数ファイルにまたがる問題
- ✅ アーキテクチャレベルの変更
- ✅ 詳細な分析とドキュメントが必要
- ✅ PRとして記録を残したい
- ✅ 時間に余裕がある場合

### 3. **デバッグ中の注意点**

#### ❌ 避けるべきこと
- **デバッグ中のLLMチューニング**: 作業が中断される
- **複数のツールを同時に使う**: 混乱を招く
- **明確な問題なのにGitHub Copilot Agentsに依頼**: 時間の無駄

#### ✅ 推奨されること
- **シンプルな問題はCursor AIに直接相談**
- **問題を明確に定義してからツールを選択**
- **一つの問題に集中する**
