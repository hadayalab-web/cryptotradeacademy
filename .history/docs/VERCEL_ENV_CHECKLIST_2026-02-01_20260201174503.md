# Vercel 環境変数チェックリスト（.env との照合）

**作成日**: 2026-02-01  
**目的**: ローカル `.env` の内容で Vercel の環境変数を設定補完する際の抜け漏れチェック。

---

## 1. 抜け漏れ（.env に無いがコードで参照されている）

### 要設定（本番で必須 or 強く推奨）

| 変数名 | 用途 | 備考 |
|--------|------|------|
| **WHOP_WEBHOOK_SECRET** | Whop Webhook 署名検証 | `api/whop-webhook.js` で使用。未設定だと本番で署名検証がスキップされセキュリティリスク。Whop ダッシュボードで Webhook 用シークレットを取得し Vercel に設定すること。 |

### 推奨（機能を有効にする場合）

| 変数名 | 推奨値 | 用途 |
|--------|--------|------|
| **QUOTE_REPOST_USE_MINIMAL_REGULAR_TEMPLATES** | `true` | 引用リポストで Minimal / Regular 2種類×複数パターンを有効にする。未設定時は `false`（従来の Grok/フォールバック）。 |

### 任意（コードにデフォルトあり・必要に応じて設定）

- `XAI_BASE_URL` — デフォルト: `https://api.x.ai/v1`
- `X_API_BASE_URL` — デフォルト: `https://api.twitter.com/2`
- `X_MAX_DAILY_POSTS` / `X_MAX_HOURLY_POSTS` / `X_MAX_DAILY_POSTS_PER_INFLUENCER` — コード内デフォルトあり
- `VSL2_LANGS` / `VSL2_MULTI_LANG` — VSL2 多言語（未設定時はコードのデフォルト）
- `TELEGRAM_BOT_TOKEN_EN` / `TELEGRAM_BOT_TOKEN_MINIMAL` — 未設定時は `TELEGRAM_BOT_TOKEN` にフォールバック
- `TELEGRAM_CHAT_ID` — 言語別 `TELEGRAM_CHAT_ID_*` が無い場合のフォールバック
- `REGULAR_SCHEDULE` — `4h` / `6h` 等
- `GPT_THRESHOLD_INFLOW` / `GPT_THRESHOLD_MPI` / `GPT_THRESHOLD_CHANGE24H` — 閾値（デフォルトあり）
- `ENABLE_EVENT_DRIVEN` / `ENABLE_X_PROOF_POST` / `X_PROOF_USE_CARTOON` — 機能フラグ
- `WHOP_MINIMAL_CHECKOUT_URL_*` — 未設定時はコード内デフォルト URL を使用
- `INFLUENCER_COUNT_*` / `INFLUENCER_STOCK_COUNT_*` — config のデフォルトあり
- `EMAIL_RECIPIENTS` / `EMAIL_*_RECIPIENTS` — CEO レポート等の宛先
- `CRYPTOQUANT_PLAN` — `professional` / `premium` / `enterprise`（デフォルト: professional）
- `GEMINI_MODEL` / `GPT_MODEL_*` / `GROK_MODEL_*` — モデル名（デフォルトあり）
- `X_API_USER_ID` / `X_API_USERNAME` — ユーザーリプライ用（未設定時デフォルトあり）
- `HEYGEN_AVATAR_ID_*` / `HEYGEN_API_URL` — HeyGen（未使用なら不要）
- `THINKIFIC_*` — Thinkific（未使用なら不要）
- `EMAIL_FROM` — 送信元（デフォルトあり）
- `DEBUG_WEBHOOK` — デバッグ用

## 3. Vercel に設定しないほうがよいもの（ローカル/CI 用）

| 変数名 | 理由 |
|--------|------|
| **GITHUB_PERSONAL_ACCESS_TOKENS** | ローカル/CI 用。Vercel ランタイムでは参照していない。 |
| **VERCEL_TOKEN** | Vercel CLI やデプロイ用。Vercel ダッシュボードの「Environment Variables」には不要。 |

---

## 4. Vercel が自動設定するもの（設定不要）

- `NODE_ENV`
- `VERCEL`
- `VERCEL_ENV`
- `VERCEL_GIT_COMMIT_SHA`
- `VERCEL_BUILD_TIME`
- `GIT_SHA`（Vercel は通常 `VERCEL_GIT_COMMIT_SHA` のみ）

---

## 5. アクションまとめ

1. **必須**: Vercel に **WHOP_WEBHOOK_SECRET** を追加（Whop の Webhook シークレットの値）。
2. **推奨**: **QUOTE_REPOST_USE_MINIMAL_REGULAR_TEMPLATES** = `true` を追加（引用リポストの 2 種類×複数パターン有効化）。
3. **補完**: 上記「2. .env にある項目」を、ローカル `.env` の値で Vercel の Environment Variables に不足分だけ追加。
4. **除外**: `GITHUB_PERSONAL_ACCESS_TOKENS` と `VERCEL_TOKEN` は Vercel の環境変数に登録しない。

以上で、.env ベースの Vercel 環境変数設定の抜け漏れチェックと補完ができる。
