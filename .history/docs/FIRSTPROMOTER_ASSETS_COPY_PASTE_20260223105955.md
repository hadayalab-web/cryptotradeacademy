**Q: ref リンクと DEFEND50、どちらが必要？**

**Q: Minimal（無料版）を見せた人があとで購入したら、成約になる？**

**Q: クッキーやセッションの有効期限は？**

FirstPromoter の仕様による。一般的に、ref リンククリック後のセッション（同一ブラウザ）で購入すれば紐付く。長時間経過した場合は、改めて ref リンクを送り直すと確実。
