# Vercel エラー改善対応（2026-02-04）

**対応日**: 2026-02-04  
**元報告**: `docs/VERCEL_ERROR_REPORT_2026-02-04.md`

---

## 1. 有料版（Regular Briefing）EN・無料版（Minimal Version）ES/PT/AR/KO/JA 時間通り配信

### 原因
- **Telegram 認証未設定**: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, 言語別チャンネルID が Vercel 環境変数に未設定または不足

### 対応
- **`docs/TELEGRAM_SETUP_VERCEL.md`** を追加。必要な環境変数の一覧と設定手順を記載。
- **`.env.example`** に Telegram 関連のコメントを追記。

### 実施内容（運用側）
1. Vercel ダッシュボード → Settings → Environment Variables で以下を設定:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`（有料版 EN 用）
   - `TELEGRAM_CHAT_ID_BTC_EN`（有料版 EN チャンネル）
   - `TELEGRAM_CHAT_ID_MINIMAL_ES`, `_PT_BR`, `_AR`, `_KO`, `_JA`, `_EN`（無料版用）
2. 再デプロイまたは次回デプロイで反映

---

## 2. 504 Cron タイムアウト

### 原因
- `/api/cron` が 300 秒以内に完了しない（GPT + Grok + Gemini 分析、Trap 検出、配信処理が重い）

### 対応
- 現状 `maxDuration: 300` が上限のため、コード変更での短縮は未実施。
- 定期スロット（UTC 0, 6, 12, 18 時）に 504 が発生した場合は配信されない。ログで確認し、必要に応じて Cron の分割や処理の軽量化を検討。

---

## 3. Tweet not found（削除/非公開）

### 原因
- インフルエンサーリスト内の tweetId が X 上で削除または非公開になっている

### 対応
- **`utils/invalidTweetIdBlocklist.js`** を追加。
- postQuoteTweet が "not found" 系エラーで失敗した場合、該当 tweetId を KV のブロックリストに追加。
- 次回以降、`filterInvalidTweetIds` でストックから除外してから引用リポストを実行。

---

## 4. Early return（残り時間不足）

### 原因
- x-quote-repost の `maxDuration` が 60 秒で、バッファ 15 秒/10 秒により処理が早めに打ち切られていた

### 対応
- **`vercel.json`**: 全 x-quote-repost-* の `maxDuration` を **60 → 120 秒** に変更。
- **`api/x-quote-repost.js`**: `MAX_DURATION_MS` を 120_000 に変更。早期リターンの閾値を 15 秒→10 秒、10 秒→5 秒に短縮し、実行時間を有効活用。

---

## 5. postQuoteTweet タイムアウト

### 原因
- X API 呼び出しの遅延やネットワーク問題

### 対応
- maxDuration 120 秒により、全体の処理余裕が増加。
- 個別の postQuoteTweet タイムアウトは既存の 8 秒のままで、ブロックリストにより無効 tweetId の再試行を抑制。

---
