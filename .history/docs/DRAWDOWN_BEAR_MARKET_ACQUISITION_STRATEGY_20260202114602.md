# 市況悪化時のトレード依存症トレーダー囲い込み戦略

## 前提

- **ペルソナ**: トレード依存症のトレーダー（やめられない・負けても続ける・リベンジトレードしがち）
- **市況**: BTC が ATH から -30〜40% のドローダウン、日足で下落継続
- **我々の価値**: 「罠スコア」「出口マップ」「トラップスタンバイ」＝**相場が悪いほど「嵌り」が増えるので、防御ツールの必要性が最大化する**

## なぜ「今」が囲い込みのチャンスか

1. **痛みが大きい**  
   含み損・連敗で「このままではダメだ」と感じている人が増える。  
   → 「罠を避ける」「スコアで待つ」というメッセージが刺さりやすい。

2. **リベンジトレードが増える**  
   戻りを掴みたくなり、さらに嵌る。  
   → 「待て」「スコアを見てから」がそのまま我々のオファーになる。

3. **ノイズに負けない武器が欲しい**  
   FUD・ホドラー論争が増える中、「データで罠を見る」は差別化になる。  
   → Trap Score / Exit Map の訴求が効く。

## メッセージングの方向性

- **既存テンプレート（A/B/C）**: 「やめられない」「6連敗」「彼らは罠の場所を知っていた」「90%が嵌る」  
  → すでにトレード依存症・負け体験に刺さる設計。
- **バリアントD（ドローダウン特化）**:  
  - 「相場が血の海のときこそ、次の罠に嵌るな」  
  - 「ダンプはもう来た。次に来るのは『戻りだと思って嵌る罠』」  
  - 「みんなが損してる今、スコア見ずにエントリーするな」  

→ **市況が悪いときは D が多く出るように**（テンプレートに D を追加し、A/B/C/D でランダムに回す）。

## 実装済みの対応

- **引用リポスト**: `config/quoteRepostTemplatesMinimalOptin.js` と `config/quoteRepostTemplatesRegularOptin.js` に **バリアント D** を追加。
  - Minimal: 「相場が荒れている今、罠スコアを見ずに飛び込むな」系
  - Regular: 「ドローダウンでまた負けたくないなら、出口マップを見ろ」系
- **ローテーション**: A/B/C/D のいずれかがランダムで選ばれるため、市況悪化期でも D が一定割合で流れる。

## 運用のコツ

- **インプレッション・エンゲージメント**: まずは D を含めた投稿がちゃんと出ているか確認。
- **クリック・登録**: D の投稿だけフィルタしてクリック率や登録数を見られれば、市況悪化期の CVR 改善に使える。
- **市況が戻ったら**: A/B/C の割合を維持しつつ、D も残しておいて「次のドローダウン」に備える。
