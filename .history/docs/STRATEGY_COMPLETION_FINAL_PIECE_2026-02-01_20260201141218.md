## 3. 我々が求めるインフルエンサーリストの定義

我々が求めるインフルエンサーリストとは、

- **高インプレッションと高エンゲージメントが期待できる**
- **「高視聴率の番組」と同じ**である

という在庫である。

引用リポストを通じて、**我々のプロモーションコンテンツを CM として運用**する。  
広告枠を買うのではなく、高視聴率番組（＝高品質インフルエンサーのツイート）に、我々の CM（＝引用リポスト）を載せる。  
この **画期的な脱広告運用のチートスタイル** が、本戦略の核である。

| 比喩         | 本戦略での対応                                           |
| ------------ | -------------------------------------------------------- |
| 高視聴率番組 | 高インプレ・高エンゲのインフルエンサーのツイート         |
| CM           | 引用リポスト（我々のメッセージ＋Whop リンク）            |
| 視聴者       | インフルエンサーのフォロワー・アルゴリズムで届くユーザー |
| 成果         | 無料版オプトイン（Minimal）・有料版購入（Regular）       |
