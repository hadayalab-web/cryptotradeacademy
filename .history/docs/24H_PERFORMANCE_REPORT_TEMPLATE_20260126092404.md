# 24時間実績レポート & 予測レポート（テンプレート）

## 📋 レポート生成方法

このレポートは、Vercel KVストレージからデータを取得して生成されます。

### 実行方法

```bash
node scripts/generate_24h_performance_report.js
```

**注意**: ローカル実行ではKV環境変数が必要です。Vercel環境で実行するか、環境変数を設定してください。

## 📝 注意事項

1. **データ取得**: KVストレージからデータを取得するため、環境変数（`KV_REST_API_URL`, `KV_REST_API_TOKEN`）が必要です。
2. **メトリクス更新**: メトリクスは毎日UTC 0時に`/api/x-engagement-metrics`で更新されます。
3. **予測値**: 予測値は過去の実績とインフルエンサーの平均インプレッション数に基づいて計算されます。
4. **コンバージョン率**: Whopコンバージョン率は保守的（2%）、中程度（3.5%）、楽観的（5%）で計算されます。
