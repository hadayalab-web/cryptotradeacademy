# 初速ターボモード 1週間シミュレーション

**作成日**: 2026-02-01  
**前提**: ターボモード有効（QUOTE_REPOST_TURBO_MODE=true）、日次上限 400、時間あたり 80、1回あたり合計 17 投稿、6言語計300リストスタンバイ。  
**参照**: `docs/DAILY_METRICS_AND_WEEKLY_REVENUE_FORECAST_2026-02-01.md`, `docs/QUOTE_REPOST_TURBO_MODE_2026-02-01.md`

## 前提パラメータ（ターボ・1週間＝7日）

| 項目                                       | 値                                         |
| ------------------------------------------ | ------------------------------------------ |
| 1日あたり目標投稿数                        | **400**（X_MAX_DAILY_POSTS）               |
| 1週間投稿数                                | **2,800**（400 × 7）                       |
| 1投稿あたりインプレッション                | 保守 5,000 / 中間 7,500 / 楽観 15,000      |
| エンゲージメント率（imp 比）               | 保守 3.8% / 中間 4.5% / 楽観 4.7%          |
| クリック率（imp 比）                       | 保守 0.5% / 中間 1.0% / 楽観 1.5%          |
| 無料版オプトイン率（クリック→Minimal）     | 保守 2% / 中間 3.5% / 楽観 5%              |
| 有料版コンバージョン率（クリック→Regular） | 保守 0.3% / 中間 0.9% / 楽観 1.5%          |
| 有料版 1件あたり手取り                     | **約 $47.30**（50%クーポン・Whop手数料後） |

## 補足

- **最終利益**は有料版（Regular Briefing）の**手取り**のみ（50%クーポン・Whop手数料控除後）。無料版オプトインからのアップセルは含めていない。
- **X API コスト**は「投稿の作成」を $0.01/回 とした場合（クレジット側の詳細に基づく）。ツイート取得・検索・DM等を多用するプランでは別途加算される。
- **ネット利益**＝手取り − X API コスト。Grok・Gemini・Vercel等のその他コストは含めていない。
- 実際はストック・クールダウン・日次/時間上限で **400/日** に満たない場合があり、その分だけ投稿数・imp・利益は下振れし、X API コストも投稿数に比例して減る。
- コンバージョン率・クリック率はコード未計測のため、実績に合わせて見直すとよい。
