# 引用リポスト「ほとんど反応がない」について

6言語・厳選インフルエンサー・Grokセールスレターで約800実行/3日でも反応が薄い場合の整理。

---

## 1. 「そんなものか？」の答え

**完全にそう、とは言い切れないが、引用リポストはもともと反応が付きにくい。**

- **Xのアルゴリズム**: 引用ツイート（Quote Tweet）は「オリジナルより価値が低い」とみなされ、インプレッションが抑えられやすい傾向がある（公式は明言していないが、多くの計測・事例で報告されている）。
- **同一アカウントで大量投稿**: 1アカウントで 200〜250 本/日 級を続けると、スパム/ボットとみなされ、さらに露出が絞られる可能性がある。
- **反応の定義**: 「反応」を「いいね・RT・リプライ」とすると、引用リポストは元ツイートのフォロワーに届きにくく、自分のフォロワーも少なければ数値は伸びにくい。

→ **「ほとんど反応がない」だけでは異常とは言い切れず、まず実測（インプレッション・エンゲージメント）を見る必要がある。**

---

## 2. 実測の確認方法

- **日次メトリクス**: 引用リポスト投稿時に `recordEngagementMetrics` で KV に記録している。`api/x-engagement-metrics.js` の Cron が投稿後メトリクスを更新。
- **KV キー**: `x:metrics:YYYY-MM-DD` に、その日の totalImpressions / totalEngagements などが入る。
- **確認**: Vercel KV のダッシュボード、または `/api/x-engagement-metrics` 等で日別のインプレッション・エンゲージメント合計を取得できる。  
  「約800本で合計インプレッションがどの程度か」を見れば、アルゴリズムでほぼゼロに近いのか、ある程度出ているがエンゲージメントだけ少ないのかが分かる。

---

## 3. 改善の方向性（レバー）

1. **量より質**: 1回あたり 5 人 cap のまま、**時間帯をピークに集中**（例: 対象言語のアクティブ時間のみ実行）して、同じ本数でも露出されやすいタイミングに寄せる。
2. **コンテンツ**: セールスレターの**冒頭1文で興味を引く**・**質問CTAを明確に**（既に推奨済み）。長文より短文＋リンクの方がエンゲージメント率は出やすい場合がある。
3. **インフルエンサー**: 「厳選ストック」のうち、**直近のインプレッション・エンゲージメント率が高いアカウント**を優先する（既に `recentImpressions` 等でソートしているが、閾値や重みを調整可能）。
4. **同一アカウント負荷**: 1日 200 本超を続ける場合は、**投稿頻度を下げる**（例: 言語あたり 1 日 2〜3 回に制限）して、スパム判定リスクを下げる。
5. **KPIの見直し**: 引用リポストの主目的を「コンバージョン（クリック・登録）」に置くなら、**インプレッションよりクリック数・UTM 経由の登録数**を追う方が妥当。

---

## 4. まとめ

- **「約800でほとんど反応」は、アルゴと運用次第ではあり得る。** まず KV / x-engagement-metrics で**実インプレッション・エンゲージメント**を確認する。
- 実測でインプレッション自体が極端に少ないなら、量の削減・時間帯集中・コンテンツ短文化を試す価値がある。
- インプレッションは出ているがいいね等が少ないなら、「反応」より**クリック・登録**をKPIにした方が運用しやすい。
