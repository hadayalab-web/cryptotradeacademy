# 精度の高い X 投稿システム — 全体像と趣旨

**作成日**: 2026-02-01  
**目的**: 構築した X 投稿システムの全体像と趣旨を共有し、認識を合わせる。

---

## 1. 趣旨（なぜこのシステムか）

- **X 上で「引用リポスト」だけに絞り、精度と再現性を上げる**  
  自アカウント向けの直接投稿（free_report / minimal_version / regular_direct）は廃止し、**引用リポストのみ**で運用する。
- **2種類の導線をローテーション**  
  無料版（Minimal Version）オプトイン導線と、有料版（Regular Briefing）直導線を、インフルエンサーごとに「前回の逆」で交互に出す。初速とコンバージョン分散を両立する。
- **6言語・300リスト・初速ターボ**  
  6言語計 300 インフルエンサーを KV にスタンバイし、Cron で言語別・30分枠まで含めて実行。X API の制限内で日次約 400 投稿を目指し、インプレッションとクリックを最大化する。
- **収益は有料版の手取り**  
  Regular Briefing（50%クーポン常時・Whop手数料後）の手取りを軸に、無料版オプトインはファネル上部として位置づける。

---

## 2. 全体像（アーキテクチャ）

```
[6言語 × 300リスト（KV）]
         ↓
[Cron: 言語別 :00 / :30 枠 → 12回/時]
         ↓
[インフルエンサー選択]（ローテ・8hクールダウン・日次上限）
         ↓
[導線タイプ選択]（Minimal / Regular、前回の逆・KV 記録）
         ↓
[テンプレート A/B/C から 1 つ]（言い回し・フックのバリエーション）
         ↓
[引用リポスト投稿]（X API: 投稿の作成 $0.01/回）
         ↓
[クリック] → [無料版オプトイン] or [有料版購入] → [手取り約 $47.30/件]
```

- **入力**: KV のインフルエンサーストック（6言語計 300）、市場データ（trapScore, priceUsd 等）。
- **制御**: 日次 400・時間あたり 80・1回あたり 17 投稿（ターボ時）。ピーク時間・オフピークの時価配分。
- **出力**: X 上の引用リポスト（Minimal 導線 or Regular 導線）、Telegram/Whop への流入。

## 3. 主要コンポーネント

| 役割 | 内容 |
|------|------|
| **投稿形態** | **引用リポストのみ**（自アカウント直接投稿は廃止） |
| **導線** | **Minimal オプトイン**（無料版）／**Regular 直導線**（有料版）。インフルエンサーごとに交互。 |
| **言語** | EN, ES, PT-BR, AR, KO, JA（6言語） |
| **インフルエンサー** | 6言語計 **300 リスト**が KV にスタンバイ。Grok 発掘・ストック。 |
| **スケジュール** | 言語別 Cron。:00 枠 6 + :30 枠 6 ＝ **12回/時**（ターボ）。計 **17 Cron**（引用 12 + 他 5）。 |
| **上限** | 日次 **400**、時間あたり **80**（ターボ）。X API（100/15min, 10,000/24h）内。 |
| **テンプレート** | Minimal/Regular 各 A・B・C バリアント。`quoteRepostTemplatesMinimalOptin.js` / `quoteRepostTemplatesRegularOptin.js`。 |
| **収益** | Regular Briefing 手取り **約 $47.30/件**（50%クーポン・Whop手数料後）。 |

## 4. 精度を高める設計

- **導線ローテーション**: 同一インフルエンサーに同じ導線を連続させない（Minimal ⇄ Regular）。コンバージョン分散と簡易 A/B 感覚。
- **テンプレート A/B/C**: 言い回し・フックのバリエーションでクリック率・オプトイン率のばらつきを取得しやすくする。
- **ピーク時間・時価配分**: `getPeakMapForHour` / `HOURLY_DISTRIBUTION` で言語別・時間帯別の投稿量を制御。
- **8h クールダウン・日次上限**: 同一インフルエンサーの連打を防ぎ、X のレート制限・スパム判定を避ける。
- **文字数**: 280/140 制限廃止。X プレミアム 25,000 文字対応。最適は 800〜1,200 文字（軸 1,000）。
- **環境変数**: `QUOTE_REPOST_USE_MINIMAL_REGULAR_TEMPLATES`、`QUOTE_REPOST_TURBO_MODE`、`X_MAX_DAILY_POSTS`、`X_MAX_HOURLY_POSTS` で挙動を切り替え。
