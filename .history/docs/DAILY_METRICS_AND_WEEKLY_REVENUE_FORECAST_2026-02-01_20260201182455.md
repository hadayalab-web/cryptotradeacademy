# 一日あたりの指標と今週の収益予測

**作成日**: 2026-02-01  
**前提**: 現在のCron構成（引用リポストのみ・6言語×24回/日）、Minimal/Regular 導線ローテーション有効時。

---

## 1. 一日あたりの投稿数

| 項目           | 値                   | 備考                                                                                   |
| -------------- | -------------------- | -------------------------------------------------------------------------------------- |
| **目標投稿数** | **約 240 投稿/日**   | `config/influencerStrategy.js` の目標値（en 72, es 48, pt-br 24, ar 48, ko 24, ja 24） |
| Cron 実行回数  | 144 回/日            | 6言語 × 24時間（各言語 1回/時）                                                        |
| 1回あたり      | 言語別 1～3 投稿     | ストック・クールダウン・ピーク時間で変動                                               |
| 実際の投稿数   | ストックと制限に依存 | キュー不足・8hクールダウン・日次上限で 240 未満になる場合あり                          |

**結論**: 一日あたりの投稿数は **最大約 240 投稿/日**（目標）。運用上は **約 100～240 投稿/日** の範囲で変動すると想定。

---

## 2. 一日あたりの期待インプレッション数

`docs/X_POSTING_IMPRESSIONS_ENGAGEMENT_EXPECTATION_2026-01-30.md` の計算を、**約 240 投稿/日** に合わせて換算。

| シナリオ                         | 1投稿あたり期待 imp | 1日あたり合計 |
| -------------------------------- | ------------------- | ------------- |
| **保守的（約 5,000 imp/投稿）**  | 5,000               | **約 120 万** |
| **中間**                         | 約 7,500            | **約 180 万** |
| **楽観的（約 15,000 imp/投稿）** | 15,000              | **約 360 万** |

**結論**: 一日あたりの期待インプレッション数は **約 120 万～360 万**（中央は **約 180 万**）。

---

## 3. 一日あたりの期待エンゲージメント率

インプレッションに対するエンゲージメント数（いいね・RT・リプ・クリック等）の割合。

| 前提                        | 率                 | 根拠                               |
| --------------------------- | ------------------ | ---------------------------------- |
| コード上の `engagementRate` | 0～1（2～8% 想定） | インフルエンサー選定・メトリクス   |
| 既存ドキュメントの換算      | **約 3.8%～4.7%**  | 保守〜楽観の eng/imp 比            |
| 業界レンジ                  | **2～8%**          | X の引用リポスト・クリプト系の目安 |

**結論**: 一日あたりの期待エンゲージメント率は **約 3.8%～4.7%**（インプレッション比）。レンジでは **2～8%** を想定。

---

## 4. 無料版（Minimal Version）のコンバージョン率

- **定義**: X のクリック → Telegram オプトイン（Minimal 導線）までの率。
- コード上は Minimal/Regular 別のコンバージョン率は未計測。以下は **一般的なファネル仮定**。

| 指標                          | 仮のレンジ   | 備考                                                      |
| ----------------------------- | ------------ | --------------------------------------------------------- |
| クリック → Minimal オプトイン | **2～5%**    | 無料のためクリック単価比では高めになりやすい              |
| インプレッション → クリック   | 約 0.5～1.5% | 既存 doc の「クリック＝エンゲージメントの約 15%」から逆算 |

**結論**: 無料版（Minimal Version）のコンバージョン率は、**クリックベースで 2～5%** を目安に計測・チューニング推奨。

---

## 5. 有料版（Regular Briefing）のコンバージョン率

- **定義**: X のクリック（または Regular 直導線経由）→ Whop で有料購入までの率。
- 同上、コード上は未計測。**一般的な有料ファネル仮定**。

| 指標                                             | 仮のレンジ    | 備考                             |
| ------------------------------------------------ | ------------- | -------------------------------- |
| クリック → Regular 購入                          | **0.3～1.5%** | 有料のためクリック単価比では低め |
| 既存 doc の「クリックの 1～3% がコンバージョン」 | 1～3%         | 無料＋有料の合算として記載       |

**結論**: 有料版（Regular Briefing）のコンバージョン率は、**クリックベースで 0.3～1.5%** を目安に計測・チューニング推奨。

---

## 6. 今週の収益予測

### 前提

- **収益**: Regular Briefing（有料）の売上のみを想定。
- **単価**: Whop の Regular Briefing 価格（例: 月額 $XX）を **あなたの実際の価格** に置き換えて使用。
- **今週**: 7 日間。

### 計算式

```
今週のクリック数（保守） ≈ 1日あたりインプレッション（保守）× 7 × クリック率（0.5%）
今週のクリック数（楽観） ≈ 1日あたりインプレッション（楽観）× 7 × クリック率（1.5%）

今週の有料コンバージョン数 ≈ 今週のクリック数 × Regular CR（0.3%～1.5%）
今週の収益予測 ≈ 今週の有料コンバージョン数 × Regular Briefing 単価（税・手数料は要確認）
```

### 例（単価を $50/月 と仮定した場合）

| 項目                         | 保守        | 楽観         |
| ---------------------------- | ----------- | ------------ |
| 1日 imp                      | 120 万      | 360 万       |
| 今週 imp                     | 840 万      | 2,520 万     |
| クリック率                   | 0.5%        | 1.5%         |
| 今週クリック数               | 42,000      | 378,000      |
| Regular CR                   | 0.5%        | 1%           |
| 今週の有料コンバージョン数   | 210         | 3,780        |
| **今週の収益予測（$50/月）** | **$10,500** | **$189,000** |

※ 実際の単価・手数料・為替・キャンセル率で変動します。Minimal 経由後のアップセルは別途計測が必要です。

### あなたの今週の収益予測を出すには

1. **Regular Briefing の月額単価**（税込・手数料後など）を決める。
2. 上記の「今週の有料コンバージョン数」を、実測または保守/楽観のどちらかで選ぶ。
3. **今週の収益予測 ＝ 今週の有料コンバージョン数 × 単価** で計算。

必要なら、Whop のダッシュボードで「今週の新規購入数」を追い、実績と予測の差で CR やクリック率を逆算すると精度が上がります。
