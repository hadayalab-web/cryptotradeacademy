# VSL 関連 4 API の機能分析（2026-02）

`/api/vsl1-post` / `/api/vsl2-free-users` / `/api/vsl1-reminder` / `/api/vsl2-last-call` の役割と動きを整理したドキュメントです。

---

## 1. `/api/vsl1-post`

| 項目 | 内容 |
|------|------|
| **目的** | VSL1（無料版オプトイン誘導用動画）の **X（Twitter）への自動投稿** |
| **Cron** | `0 1,13,21 * * *` → **毎日 1:00, 13:00, 21:00 UTC**（1日3回） |
| **ファイル** | `api/vsl1-post.js` |

### やっていること

- **X への投稿**
  - VSL1 用ツイートを生成（Grok センチメント・A/B テスト・多言語対応）。
  - サムネイル画像をアップロードしてから `postTweet` で投稿。
  - 言語は `VSL1_LANGS` / `VSL1_MULTI_LANG` で制御。デフォルトは単一言語（`LANG`）。
- **Telegram には送らない**
  - コメントのとおり「無料版チャンネルには配信しない」。既存無料版ユーザーに VSL1 を送らない設計。
- **認証**  
  `CRON_SECRET` の Bearer チェック。失敗時は CEO 向けエラーレポート送信。

### 依存

- `services/x/client.js`（postTweet, uploadMedia）
- `services/x/vsl1-strategy.js`（buildVSL1Tweet, selectVsl1Variant）
- `services/grok/client.js`（analyzeXSentimentLive）
- `services/gemini/messageOptimizer.js`（optimizeVSL1Message）
- 環境変数: `VSL1_YOUTUBE_LINK`, `VSL1_LANGS`, `VSL1_MULTI_LANG`, X API 系, `CRON_SECRET`

---

## 2. `/api/vsl2-free-users`

| 項目 | 内容 |
|------|------|
| **目的** | 無料版ユーザーに **VSL2（有料版誘導動画）を Telegram DM で送る** |
| **Cron** | `0 * * * *` → **毎時 0 分**（1日24回） |
| **ファイル** | `api/vsl2-free-users.js` |

### やっていること

- **対象ユーザー**（`services/free-users/manager.js` の `getFreeUsersForVSL2`）
  - 無料版リスト（KV または `data/free-users.json`）のうち、
  - **参加から 24 時間以上経過** かつ **VSL2 未送信**（`vsl2Sent === false`）のユーザー。
- **送信内容**
  - 多言語の VSL2 メッセージ＋サムネイル＋インラインボタン（動画・Whop 購入）。
  - YouTube は字幕パラメータ付き。Whop は `getPromoCode()` 付き。
- **送信後**  
  `markVSL2Sent(chatId)` で「VSL2 送信済み」にし、二重送信を防止。

### 依存

- `services/free-users/manager.js`（getFreeUsersForVSL2, markVSL2Sent）
- `services/telegram/bot.js`（sendMessageToUser, sendPhotoToUser）
- `services/telegram/messages/vsl2.js`
- `services/telegram/whop-links.js`（getWhopProductUrl, getPromoCode）
- 環境変数: `VSL2_YOUTUBE_LINK`, `CRON_SECRET`, Telegram 系

---

## 3. `/api/vsl1-reminder`

| 項目 | 内容 |
|------|------|
| **目的** | 無料版ユーザーに **VSL1 のリマインドを Telegram DM で送る**（まだ VSL2 を見せていない人向け） |
| **Cron** | `0 */12 * * *` → **0:00 と 12:00 UTC**（1日2回） |
| **ファイル** | `api/vsl1-reminder.js` |

### やっていること

- **対象ユーザー**（`getFreeUsersForVSL1Reminder`）
  - 無料版リストのうち、
  - **参加から 12 時間以上・24 時間未満**（`isWithinTimeRange(joinedAt, 12, 24)`）かつ **VSL2 未送信**。
- **送信内容**
  - 多言語の VSL1 リマインドメッセージ＋サムネイル＋インラインボタン（VSL1 動画・無料版 Deep Link）。
  - `services/telegram/messages/vsl1-reminder.js` の `generateVSL1ReminderMessage`。
- **送信後**  
  VSL2 送信フラグは変更しない（この API では `markVSL2Sent` は呼ばない）。あくまで「VSL1 を見てね」のリマインド。

### 依存

- `api/vsl1-post.js`（getTelegramDeepLink, generateVSL1InlineKeyboard）
- `services/free-users/manager.js`（getFreeUsersForVSL1Reminder）
- `services/telegram/bot.js`, `services/telegram/messages/vsl1-reminder.js`
- 環境変数: `VSL1_YOUTUBE_LINK`, `CRON_SECRET`, Telegram 系

---

## 4. `/api/vsl2-last-call`

| 項目 | 内容 |
|------|------|
| **目的** | 無料版ユーザーに **VSL2 の「終了直前」リマインドを Telegram DM で送る**（まだ VSL2 を送っていない人向け） |
| **Cron** | `0 * * * *` → **毎時 0 分**（1日24回） |
| **ファイル** | `api/vsl2-last-call.js` |

### やっていること

- **対象ユーザー**（`getFreeUsersForVSL2LastCall`）
  - 無料版リストのうち、
  - **参加から 22 時間以上・24 時間未満**（`isWithinTimeRange(joinedAt, 22, 24)`）かつ **VSL2 未送信**かつ **Last Call 未送信**（`vsl2LastCallSent === false`）。
  - つまり「もうすぐ 24 時間で VSL2 が送られる直前」のユーザーに「最後の案内」を送る。
- **送信内容**
  - VSL2 Last Call 用メッセージ＋サムネイル＋インラインボタン（購入・動画）。
- **送信後**  
  `markVSL2LastCallSent(chatId)` で Last Call 送信済みにし、重複送信を防止。

### 依存

- `services/free-users/manager.js`（getFreeUsersForVSL2LastCall, markVSL2LastCallSent）
- `services/telegram/bot.js`, `services/telegram/messages/vsl2-last-call.js`
- `services/telegram/whop-links.js`
- 環境変数: `VSL2_YOUTUBE_LINK`, `CRON_SECRET`, Telegram 系

---

## 5. 無料版ユーザーの「時間軸」まとめ

| 経過時間 | 実行される API | 内容 |
|----------|----------------|------|
| 12–24h | vsl1-reminder | VSL1 リマインド（Telegram） |
| 22–24h | vsl2-last-call | VSL2 終了直前リマインド（Telegram） |
| 24h+ | vsl2-free-users | VSL2 本配信（Telegram） |

- **vsl1-post** は「無料版ユーザーリスト」とは独立で、**X に VSL1 ツイートを投稿するだけ**（1日3回）。

---

## 6. 共通事項

- **認証**  
  いずれも `Authorization: Bearer ${CRON_SECRET}` を要求（未設定の場合はスキップ可能な実装の可能性あり）。
- **ストレージ**  
  無料版ユーザーは `services/free-users/manager.js` 経由で **Vercel KV**（優先）または `data/free-users.json` を利用。
- **言語**  
  6 言語対応（en, es, pt-br, ar, ja, ko）。ユーザーごとの `lang` またはデフォルト言語でメッセージを切り替え。
