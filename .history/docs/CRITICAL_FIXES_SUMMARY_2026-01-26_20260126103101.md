# 重大な不具合修正サマリー
**作成日**: 2026-01-26  
**修正内容**: 投稿数のカウントロジックとエラーハンドリングの根本的な修正

## 🔧 修正した問題

### 1. 投稿数の過剰カウント問題

**問題**:
- `incrementDailyPostCount`がスレッドの各リプライで個別に呼ばれていた
- 実際の投稿数（12件）に対して、カウントが38回と大幅に過剰

**修正内容**:
- スレッド投稿の場合、メイン投稿のみをカウントするように変更
- スレッドリプライはメトリクス追跡のためには保存するが、投稿数にはカウントしない

**修正ファイル**:
- `api/x-post-free-report.js`
- `api/x-post-minimal-version.js`

### 2. `savePostId`の失敗が無視される問題

**問題**:
- `savePostId`が失敗しても警告のみで処理が続行されていた
- `incrementDailyPostCount`が`savePostId`の前に呼ばれていたため、保存に失敗してもカウントが増えたまま

**修正内容**:
- `savePostId`を成功時に`true`、失敗時に`false`を返すように変更
- `savePostId`が成功した場合のみ`incrementDailyPostCount`を呼ぶように変更
- 保存に失敗した場合は致命的エラーとして扱い、カウントを増やさない

**修正ファイル**:
- `services/x/postTracker.js`
- `api/x-quote-repost.js`
- `api/x-post-free-report.js`
- `api/x-post-minimal-version.js`

## 📊 修正前後の比較

### 修正前のフロー
```
1. 投稿成功
2. incrementDailyPostCount() → カウント +1 ✅
3. savePostId() → エラー発生 ❌（警告のみ、処理続行）
結果: カウントは増えるが、KVには保存されない
```

### 修正後のフロー
```
1. 投稿成功
2. savePostId() → 成功 ✅ → trueを返す
3. incrementDailyPostCount() → カウント +1 ✅
結果: 保存に成功した場合のみカウントが増える
```

### スレッド投稿の修正前後

**修正前**:
```
メイン投稿: incrementDailyPostCount() → +1
スレッドリプライ1: incrementDailyPostCount() → +1
スレッドリプライ2: incrementDailyPostCount() → +1
結果: 1つのスレッドで3回カウント
```

**修正後**:
```
メイン投稿: savePostId() → 成功 → incrementDailyPostCount() → +1
スレッドリプライ1: savePostId() → 成功（カウントなし）
スレッドリプライ2: savePostId() → 成功（カウントなし）
結果: 1つのスレッドで1回のみカウント
```
