# 🚨 緊急: インフルエンサーストック再構築 - 明確な実行手順

## ✅ 実行する手順（3ステップ）

### ステップ1: XAI_API_KEYを取得
- Vercel Dashboardまたは環境変数からXAI_API_KEYを確認

### ステップ2: XAI_API_KEYを設定

**PowerShellの場合:**
```powershell
$env:XAI_API_KEY="あなたのXAI_API_KEY"
```

**コマンドプロンプトの場合:**
```cmd
set XAI_API_KEY=あなたのXAI_API_KEY
```

### ステップ3: バッチファイルを実行
```bash
scripts\emergency-rebuild-influencer-stock.bat
```

---

## 📝 または、バッチファイルを編集する方法

`scripts\emergency-rebuild-influencer-stock.bat`を開いて、以下の行を追加：

```batch
set XAI_API_KEY=あなたのXAI_API_KEY
```

その後、バッチファイルをダブルクリックするか、コマンドラインから実行：

```bash
scripts\emergency-rebuild-influencer-stock.bat
```

---

## ⚠️ 重要な注意

**XAI_API_KEYを設定するだけでは再構築されません！**

必ず以下の順序で実行してください：
1. XAI_API_KEYを設定
2. **バッチファイルを実行** ← これが重要！

---

scripts\check-kv-direct.bat
