## 📊 現在の実装状況

### 使用中のモデル
- **開発環境**: `gemini-3-pro-preview`
- **本番環境**: `gemini-2.0-flash-exp`（タイムアウト対策）

### 用途
- **深層心理分析** (`services/gemini/deepPsychologicalAnalyzer.js`)

- **コスト効率**: 大量のAPI呼び出しを考慮
- **品質要件**: 深層心理解析の精度を維持

**理由**:
1. ✅ **最もコスト効率が高い**
2. ✅ **高速処理**

## 📝 推奨実装変更

### 現在の実装
```javascript
const GEMINI_MODEL = process.env.GEMINI_MODEL || 
  (isDevelopment ? 'gemini-3-pro-preview' : 'gemini-2.0-flash-exp');
```

### 推奨実装
```javascript
const GEMINI_MODEL = process.env.GEMINI_MODEL || 
  (isDevelopment ? 'gemini-3-pro-preview' : 'gemini-2.0-flash');
// または、コスト最優先の場合:
// (isDevelopment ? 'gemini-3-pro-preview' : 'gemini-2.0-flash-lite');
```

**変更理由**:
- `gemini-2.0-flash-exp`は実験版（exp = experimental）の可能性が高い
- `gemini-2.0-flash`は一般利用可能（GA）で安定性が高い
- 同じ高速処理とコスト効率を維持しつつ、より安定したモデルを使用可能

## 💡 モデル選択の判断基準

### タイムアウト対策が最優先の場合
→ **`gemini-2.0-flash`** を推奨

### コスト最優先の場合
→ **`gemini-2.0-flash-lite`** を検討（プレビュー版のため注意）

### 最高品質が必要な場合（開発環境）
→ **`gemini-3-pro-preview`** を継続使用

### 非常に長いコンテキストが必要な場合
→ **`gemini-1.5-pro`** を検討（ただしコストとタイムアウトリスクに注意）

## 🔄 移行計画

### Phase 1: 検証（推奨）
1. 環境変数 `GEMINI_MODEL=gemini-2.0-flash` を設定

3. 品質とコストを比較評価

2. コスト最優先の場合は `gemini-2.0-flash-lite` を検討

## ✅ 結論

### **`gemini-2.0-flash-exp`は最適解ではない**

**推奨**:
- **本番環境**: `gemini-2.0-flash`（一般利用可能、安定性が高い）
- **開発環境**: `gemini-3-pro-preview`（現状維持）
- **コスト最優先**: `gemini-2.0-flash-lite`（プレビュー版のため注意）

**理由**:
1. `gemini-2.0-flash-exp`は実験版（exp = experimental）の可能性が高い
2. `gemini-2.0-flash`は一般利用可能（GA）でより安定している
3. 同じ高速処理とコスト効率を維持しつつ、より安定したモデルを使用可能
