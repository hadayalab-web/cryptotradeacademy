## 📝 実装の詳細

### 時間帯チェックのロジック

```javascript
// 🚀 ゴール逆算最適化: ピーク時間帯チェック（インプレッション最大化のため）
const force = req.query?.force === 'true';
if (!force) {
  const { getLanguagesForCurrentHour } = require('../services/x/optimization');
  const currentHour = new Date().getUTCHours();
  const { langs, type } = getLanguagesForCurrentHour(currentHour);
  
  // その言語が対象時間帯でない場合はスキップ
  if (!langs.includes(LANG) || type !== 'quote') {
    return res.status(200).json({
      success: true,
      skipped: true,
      reason: 'not_peak_time',
      currentHour,
      message: 'Not peak time for quote reposts. Use ?force=true to override.',
      runId,
      timestamp: new Date().toISOString(),
    });
  }
}
```

**動作**:
1. 現在のUTC時刻を取得
2. `getLanguagesForCurrentHour`でピーク時間帯を判定
3. その言語が対象時間帯でない場合はスキップ
4. `force=true`パラメータがある場合は強制実行
