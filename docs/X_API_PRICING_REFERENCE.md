# X API 料金メモ（リクルートDMフロー関連）

コピペ元: X API ダッシュボード料金表。**Read 系の詳細は `X_API_READ_ANALYSIS.md` を参照。**

---

## 読み取り系（取得したリソースごとに課金）

**重要**: 課金単位は「リクエスト数」でも「クエリ数」でもなく **取得したリソース数**。検索 1 回で 30 件返れば 30 リソース分課金。

| カテゴリ | 単価 | 単位 | 想定される用途 |
|----------|------|------|----------------|
| **投稿: 読み取り** | $0.005 | リソースごと | ツイート検索で取得した投稿（1ツイート = 1リソース） |
| **ユーザー: 読み取り** | $0.010 | リソースごと | ユーザー情報（search の expansions 等） |
| DMイベント: 読み取り | $0.010 | リソースごと | DM一覧取得等 |
| リスト/スペース/コミュニティ/ノート/メディア/分析/トレンド など | $0.005–0.010 | リソースごと | 当フローでは未使用 |

---

## 作成系（リクエストごとに課金）

| カテゴリ | 単価 | 単位 | 用途 |
|----------|------|------|------|
| **DMインタラクション: 作成** | **$0.015** | **リクエストごと** | **DM 送信 1 通 = 1 リクエスト。403 はカウントされない** |
| コンテンツ: 作成 | $0.010 | リクエストごと | 投稿作成 |
| ユーザーインタラクション: 作成 | $0.015 | リクエストごと | いいね・リツイート等 |

---

## リクルートDMでの使われ方（整理）

- **投稿: 読み取り**: 検索で返ったツイート 1 件 = 1 リソース = $0.005。1 ランあたり最大 30 件なら 30 × $0.005。
- **ユーザー: 読み取り**: 検索の expansions で返ったユーザー 1 件 = 1 リソース = $0.010。
- **DMインタラクション: 作成**: 送信成功 1 通 = $0.015。403 は課金なし。

→ 課金を抑えるには「検索ラン数」より **1 回あたりの取得件数（maxResults・ページ数）** を絞るのが効く。詳しくは `X_API_READ_ANALYSIS.md`。
