## ⚠️ 課題と改善点

### 1. 達成率の低下（CRITICAL）
**問題**: PT-BRは78.0%と、EN（95.7%）、ES（95.2%）より低い

**原因**:
1. **バッチ6の失敗**: リトライ上限に達して0人取得
2. **重複の増加**: 後半のバッチで重複が増加（バッチ14で9/10が重複）
3. **検証による除外**: username長さ制限で約6-8人除外

**影響**:
- 目標168人に対し37人不足
- 他の言語と比較して達成率が低い

**改善案**:
1. **リトライ回数の増加**: 3回 → 5回に増加
2. **リトライ間隔の調整**: 指数バックオフを延長（2s → 4s → 8s → 16s → 32s）
3. **Grokプロンプトの最適化**: PT-BR特有のキーワードやアカウントを明示
4. **バッチサイズの動的調整**: 重複が増加したらバッチサイズを増やす

### 2. 階層の偏り（EN/ESと同様）
**問題**: すべてのインフルエンサーが「top」階層（followerCount ≥ 10,000）

**原因**: EN/ESと同様に、Grokのプロンプトが大規模アカウントを優先

**改善案**: 全言語完了後に、Grokプロンプトの調整で解決

### 3. Username長さ制限による除外
**問題**: 16文字以上のusernameが自動除外される

**影響**: 約6-8人（4-5%）が検証で除外

**改善案**: Grokプロンプトで「usernameは15文字以内」を明示

### 4. 重複の増加
**問題**: 後半のバッチで重複が増加（バッチ14で9/10が重複）

**原因**: Grokが既に取得済みのインフルエンサーを再度返却

**改善案**:
- Grokプロンプトで「既に取得済みのインフルエンサーは除外」を明示
- または、取得済みのusernameリストをGrokに渡す
