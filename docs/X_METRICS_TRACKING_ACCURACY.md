# X API メトリクス追跡の正確性について

## 📊 追跡可能なメトリクス

### ✅ 正確に追跡可能

#### 1. **自分の投稿した引用リポスト**
- **インプレッション数**: ✅ 取得可能（`non_public_metrics.impression_count`）
- **エンゲージメント数**: ✅ 取得可能（`public_metrics` + `organic_metrics`）
  - いいね数
  - リツイート数
  - リプライ数
  - 引用リツイート数
  - URLクリック数
  - プロフィールクリック数

**制限**: 過去30日以内のツイートのみ

#### 2. **インフルエンサーのツイート（Public Metrics）**
- **エンゲージメント数**: ✅ 取得可能（`public_metrics`）
  - いいね数
  - リツイート数
  - リプライ数
  - 引用リツイート数

### ❌ 正確に追跡不可能

#### 1. **インフルエンサーのツイートのインプレッション数**
- **理由**: X APIのプライバシー保護により、他人のツイートのインプレッション数は直接取得できない
- **現在の実装**: Grokが推定値を提供（範囲: 10000-50000, 50000-100000, 100000+）
- **正確性**: ❌ 不正確（Grokの推測値）

## 🔧 実装状況

### 現在の実装

1. **Grokによる推定**
   - `recentImpressions`: Grokが推定したインプレッション数（範囲指定）
   - 正確ではないが、インフルエンサー選択の参考にはなる

2. **X APIによる正確な取得**
   - `services/x/metrics.js`: メトリクス取得機能を実装
   - 自分のツイート: インプレッション数 + エンゲージメント数を正確に取得
   - 他人のツイート: エンゲージメント数のみ正確に取得

### 推奨される使用方法

#### 1. **インフルエンサー選択時**
- Grokの推定値（`recentImpressions`）を参考にする
- 正確な`public_metrics`（いいね、リツイート、リプライ）で検証する

#### 2. **引用リポスト投稿後**
- 自分の投稿した引用リポストのメトリクスを定期的に取得
- インプレッション数とエンゲージメント数を正確に追跡
- パフォーマンス分析に使用

#### 3. **インフルエンサーリスト管理**
- `public_metrics`で正確なエンゲージメント数を記録
- インプレッション数はGrokの推定値として記録（参考値）

## 📈 正確性のまとめ

| メトリクス | 自分のツイート | 他人のツイート | 正確性 |
|-----------|--------------|--------------|--------|
| インプレッション数 | ✅ 取得可能 | ❌ 取得不可能 | 自分のツイートのみ正確 |
| いいね数 | ✅ 取得可能 | ✅ 取得可能 | ✅ 正確 |
| リツイート数 | ✅ 取得可能 | ✅ 取得可能 | ✅ 正確 |
| リプライ数 | ✅ 取得可能 | ✅ 取得可能 | ✅ 正確 |
| 引用リツイート数 | ✅ 取得可能 | ✅ 取得可能 | ✅ 正確 |
| URLクリック数 | ✅ 取得可能 | ❌ 取得不可能 | 自分のツイートのみ正確 |
| プロフィールクリック数 | ✅ 取得可能 | ❌ 取得不可能 | 自分のツイートのみ正確 |

## 🎯 結論

- **エンゲージメント数（いいね、リツイート、リプライ）**: ✅ 正確に追跡可能
- **自分のツイートのインプレッション数**: ✅ 正確に追跡可能
- **他人のツイートのインプレッション数**: ❌ 正確に追跡不可能（Grokの推定値を使用）

**推奨**: エンゲージメント数（`public_metrics`）を主要指標として使用し、インプレッション数は自分のツイートのみ正確に追跡する。
