## 🎯 実装された機能

### 1. Cryptoキーワード監視（200種以上、6言語対応）

**対応言語**: EN, ES, PT-BR, AR, JA, KO

**キーワードカテゴリ**:
- BTC損失関連（30種以上/言語）
- ハック被害関連（20種以上/言語）
- FOMO/恐怖関連（20種以上/言語）
- トレーダー関連（30種以上/言語）

**優先度判定**:
- **High**: 損失キーワード含む、または3つ以上のキーワードマッチ
- **Medium**: 1-2つのキーワードマッチ
- **Low**: その他

### 2. ドンピシャリード判定

**判定基準**:
- スコア0.8以上 = ドンピシャリード
- 損失キーワード + 高エンゲージメント = 即座に送信

**スコア計算**:
- キーワードマッチング: 0.1-0.5
- マッチしたキーワード数: 0.1-0.3
- エンゲージメント率: 0-0.2

### 3. 優先キューシステム

**優先度レベル**:
1. **PERFECT_MATCH**: ドンピシャリード（スコア0.8以上）
2. **HIGH**: 高優先度（損失キーワード含む）
3. **MEDIUM**: 中優先度
4. **LOW**: 低優先度

**処理フロー**:
1. リード発見 → キューに追加（優先度付き）
2. ドンピシャリード → 即座にVSL1送信
3. その他 → 優先度順に処理

### 4. FOMO VSLリマインダー

**FOMO要素**:
- 「24時間限定防御」メッセージ
- 「今すぐ守れ」緊急性メッセージ
- 残り時間表示（1-12時間のランダム）

**送信タイミング**: 12時間ごと（既存のcronジョブ）
