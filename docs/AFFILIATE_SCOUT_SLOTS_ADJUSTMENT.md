## 調整方針

- Cron は **0,30 * * * *** のため、**1時間あたり最大2スロット**（:00 と :30）。
- 時間帯の対応:
  - **JA / KO**: JST/KST 夕方〜夜 → **11–13 UTC**
  - **AR**: 中東夕方 → **16–18 UTC**
  - **ES/PT 南米**: ブラジル・アルゼンチン等夕方 → **20–23, 0 UTC**（南米のみ、欧州なし）
