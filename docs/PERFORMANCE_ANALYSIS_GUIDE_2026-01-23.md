## 🎯 実測データの取得方法

### 方法1: Vercel本番環境から直接取得（推奨）

2. プロジェクトの「Logs」タブを開く
3. `/api/x-engagement-metrics`の実行ログを確認
4. ダッシュボードJSONデータをコピー

#### 2. APIエンドポイントから直接取得
```bash
# 最新のエンゲージメントダッシュボードを取得
curl "https://your-project.vercel.app/api/x-engagement-metrics" \
  -H "Authorization: Bearer YOUR_CRON_SECRET"
```

#### 3. Vercel KVストレージから直接取得（Vercel CLI使用）
```bash
# Vercel CLIでKVストレージにアクセス
vercel kv get x:metrics:2026-01-23
```

### 方法2: スクリプトを使用（Vercel環境で実行）

```bash

node scripts/analyze-x-performance.js
```

## 📈 実測データ分析のポイント

### 1. インプレッション数（Impressions）
- **目標**: EN 10-20万、その他言語 5-10万 per post
- **確認項目**:
  - 平均インプレッション数
  - 言語別のインプレッション数
  - 投稿タイプ別（動画/ポール/テキスト）のインプレッション数

### 2. エンゲージメント数（Engagements）
- **目標**: エンゲージメント率 2-5%
- **確認項目**:
  - 総エンゲージメント数（リプライ+RT+いいね+引用RT）
  - エンゲージメント率
  - エンゲージメントタイプ別の内訳

### 3. クリック率（CTR / Click Rate）
- **目標**: クリック率 3-8%
- **確認項目**:
  - 総クリック数（Deep Linkクリック）
  - クリック率
  - 言語別のクリック率

### 4. CVR（コンバージョン率）
- **目標**: クリック→Telegram Bot Start率 10-20%
- **確認項目**:
  - Telegram Bot Start数（Deep Link経由）
  - CVR（クリック→Start率）
  - 言語別のCVR

## 🔍 データ分析のステップ

### Step 1: データ取得
1. Vercelダッシュボードから最新のメトリクスデータを取得
2. 過去7日間のデータを収集

### Step 2: 集計
- 総インプレッション数
- 総エンゲージメント数
- 総クリック数
- 平均値（投稿あたり）

### Step 3: 率の計算
- エンゲージメント率 = (総エンゲージメント数 / 総インプレッション数) × 100
- クリック率 = (総クリック数 / 総インプレッション数) × 100
- CVR = (Telegram Bot Start数 / 総クリック数) × 100

### Step 4: 比較分析
- 期待値（Grok推奨値）との比較
- ベースライン（実装前）との比較
- 日別の推移分析

## ⚠️ 注意事項

### データ取得のタイミング
- **デプロイ直後**: まだ十分なデータが蓄積されていない可能性
- **Cron Jobs実行後**: `/api/x-engagement-metrics`が実行された後にデータが利用可能
- **推奨**: デプロイ後24-48時間経過してから分析

### データの信頼性
- **インプレッション数**: X APIから取得（正確）
- **エンゲージメント数**: X APIから取得（正確）
- **クリック数**: X APIから取得（正確）
- **CVR**: Telegram Bot Startイベントが必要（別途取得）

### ベースラインとの比較
- 実装前のデータがない場合、期待値（Grok推奨値）との比較のみ可能
- 実装前のデータがある場合、改善率を正確に計算可能
