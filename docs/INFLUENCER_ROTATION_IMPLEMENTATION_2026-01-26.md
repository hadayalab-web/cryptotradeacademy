## 🎯 実装概要

70人のインフルエンサーリストを上手にローテーションし、時価配分を最適化して**1日100投稿**を達成する仕組みを実装しました。

---

## 📊 実装内容

### 1. インフルエンサーローテーション機能

#### 新規ファイル: `services/x/influencerRotation.js`

**機能**:
- **今日既に投稿したインフルエンサーを記録・除外**
- **ローテーション順に選択**（循環ローテーション）
- **投稿済みリストを管理**（KVストレージ）

**主要関数**:
- `selectInfluencersWithRotation()`: ローテーションを考慮してインフルエンサーを選択
- `markInfluencerPosted()`: 投稿済みとしてマーク
- `getPostedInfluencersToday()`: 今日投稿済みのインフルエンサーを取得
- `getRotationStats()`: ローテーション統計を取得

**ローテーションロジック**:
1. 今日既に投稿したインフルエンサーを除外
2. 利用可能なインフルエンサーから、ローテーションインデックス順に選択
3. 選択後、ローテーションインデックスを更新
4. 利用可能なインフルエンサーが不足している場合、ローテーションをリセット

---

### 2. 時価配分ロジック

#### 更新ファイル: `config/influencerStrategy.js`

**時価配分設定**:
```javascript
const HOURLY_DISTRIBUTION = {
  // ピーク時間（UTC 0,1,20,21,22）: 多く投稿
  peak: {
    hours: [0, 1, 20, 21, 22],
    multiplier: 1.0, // 通常の投稿数
  },
  // オフピーク時間（UTC 13,14）: 少なく投稿
  offPeak: {
    hours: [13, 14],
    multiplier: 0.4, // 通常の40%
  },
};
```

**言語別投稿数**:
- **EN**: ピーク時間10人、オフピーク時間4人
- **その他言語**: ピーク時間2人、オフピーク時間1人

**動的調整**:
- `getInfluencerCountForLang(lang, currentHour)`: 現在時刻に応じて投稿数を動的に調整

## 🔄 ローテーション動作フロー

1. **Cron実行** → `/api/x-quote-repost`が呼び出される
2. **時価配分チェック** → 現在時刻（UTC）に応じて投稿数を決定
3. **ストック取得** → 言語別のストックリストからインフルエンサーを取得
4. **ローテーション選択** → 今日既に投稿した人を除外し、ローテーション順に選択
5. **投稿実行** → 選択されたインフルエンサーに引用リポストを投稿
6. **ローテーション更新** → 投稿成功時に、投稿済みリストとローテーションインデックスを更新
