# 初速ターボモード（引用リポスト）

**作成日**: 2026-02-01  
**目的**: 投稿上限を引き上げ、Cron を最適化して初速を最大化する。

---

## 概要

- **投稿上限**: 日次 250 → **400**、時間あたり 100 → **80**（ターボ時デフォルト）。
- **1回あたり投稿数**: 言語別合計 10 → **17**（en 5, es 3, pt-br 2, ar 3, ko 2, ja 2）。
- **Cron**: 6言語 × **1時間1回**（:00, :05, …）に加え、**30分枠**（:30, :35, …）を追加し、1時間あたり **12回** 実行（初速ターボ用）。

X API の制限（Per User 100/15min、Per App 10,000/24hrs）内で、日次 **約 400 投稿** を目指す。

---

## 有効化

`.env` および Vercel 環境変数に以下を設定する。

```bash
# 初速ターボモード（どちらかで可）
QUOTE_REPOST_TURBO_MODE=true
# または
X_TURBO_MODE=true
```

未設定または `false` の場合は従来どおり（日次 250、時間あたり 100、1回あたり合計 10）。

---

## ターボ時のデフォルト値

| 項目                        | 通常                                        | ターボ                                          |
| --------------------------- | ------------------------------------------- | ----------------------------------------------- |
| **X_MAX_DAILY_POSTS**       | 250                                         | **400**                                         |
| **X_MAX_HOURLY_POSTS**      | 100                                         | **80**                                          |
| **1回あたり投稿数（合計）** | 10（en 3, es 2, pt-br 1, ar 2, ko 1, ja 1） | **17**（en 5, es 3, pt-br 2, ar 3, ko 2, ja 2） |
| **目標投稿数/日**           | 約 240                                      | **約 400**                                      |

環境変数 `X_MAX_DAILY_POSTS` / `X_MAX_HOURLY_POSTS` を明示すると、ターボ時でもその値が優先される。

---

## Cron 最適化（30分枠）

ターボ用に、各言語で **:00 に加え :30** にも実行する Cron を追加している。

| パス                                                                        | スケジュール             |
| --------------------------------------------------------------------------- | ------------------------ |
| `/api/x-quote-repost-en`                                                    | `0 * * * *`（毎時 :00）  |
| `/api/x-quote-repost-en-30`                                                 | `30 * * * *`（毎時 :30） |
| 同様に ES, PT-BR, AR, JA, KO も :05/:35, :10/:40, :15/:45, :20/:50, :25/:55 |

1時間あたり **12回**（6言語 × 2枠）実行される。時間あたり上限 80 により、実際の投稿数は 80/時までに抑えられ、日次 400 で打ち止めになる。

## 注意

- **スパム判定**: 日次 400 は X API の余裕内だが、アルゴリズム・スパム判定は別要因のため、問題が出た場合は `X_MAX_DAILY_POSTS` を 300 前後に下げて調整する。
- **6言語計300リスト**: スタンバイしている前提。ストック不足時は 400 に達しない。
- **429 対策**: X API で 429 が出た場合は [X API Rate Limits](https://docs.x.com/x-api/fundamentals/rate-limits#handling-rate-limits) に従いリトライ・バックオフを検討する。
