# Run 解析用プロンプト定型（Gemini に投げる）

ログを貼って「原因・次の1アクション・理由」だけを返してもらうときの定型。**そのままコピーし、[ここにログ] を直近 run の short_report またはログ抜粋に差し替えて Gemini（Chrome または API）に送る。**

---

## 定型文（コピー用）

```
以下を前提に、原因・次の1アクション・理由の3ブロックだけ出せ。共感・謝罪・受け取り確認・チェックリストは不要。3ブロックで終了し、それ以降は書かない。

【直近 run】
[ここにログ]

1) 原因（1行）
2) 次の1アクション（変更するパラメータと値、1行）
3) 理由（1行）
```

---

## ログの例（short_report 1行）

ログに `[buzzweave-run] short_report` が出ていれば、その行をそのまま【直近 run】に貼る。

例:
```
run_id=bw-pqt-xxx lang=es posts_fetched=13 candidates=10 slots=4 cap=63 posted=4 fill_rate=0.0635
```

複数 run を渡す場合は、時刻・lang を付けて列挙する。

---

## 注意

- **Grok** に同じように「次の1アクション」を聞くときは、**選択肢を明示**する（A: SEARCH_WINDOW_MIN 拡大 / B: FALLBACK 増、どちらか）。自由記述だと誤レバーを出す。
- 返答が 3 ブロック以外（前置き・「他に必要なら」など）を足していたら、その部分は使わない。
