# いつ・誰に・Minimal vs Regular を出すか — Grok / Gemini 回答

生成日時: 2026-02-01T07:43:54.340Z

---

## 共通プロンプト（要約）

- 300インフルエンサー × 2パターン（Minimal オプトイン / Regular 直導線）をぐるぐる回す。
- 「いつ・誰に・Minimal と Regular のどちらを出すか」を決める**実装可能な1本のルール**を提案してほしい。

---

## Grok（grok-4-1-fast-reasoning）

**提案ルール**: 各インフルエンサーごとに、直近の引用リポスト投稿タイプを追跡し、「Minimalだったら次はRegular、それ以外はMinimal」と交互に割り当てる。投稿スケジュール時にこのルールでタイプを決定し、投稿後にタイプを更新（Google SheetsやDBで管理）。

**疑似コード**:
```
if (last_post_type[influencer_id] == "Minimal") {
  next_type = "Regular";
} else {
  next_type = "Minimal";
}
post_quote_repost(influencer_id, next_type);
update last_post_type[influencer_id] = next_type;
```

**理由・補足**:
- **ぐるぐる回す効果**: 300人全員で交互ループするため、同じ人に連続せず、Minimal（認知拡大）とRegular（即CV）の両方を均等に回せ、リーチ×ファネル最大化。
- **実装しやすさ**: インフルエンサーIDをキーとした1列のスプレッドシートで完結。スケジューラー（Zapier/Buffer）で自動化可能。初期は全「未投稿」扱い。
- **アルゴリズム適合**: Xのアルゴが新鮮さを好むため、交互でエンゲージ持続。属性/時間帯不要でシンプル、A/Bテストで微調整可。

## Gemini（gemini-3-pro-preview）

Trap Defence BTCのマーケティング戦略として、最もROI（投資対効果）とリスト構築のバランスが良い**「エンゲージメント率によるオファー優先度・反転ルール」**を提案します。

### 結論：提案するルール

**「エンゲージメント率が2%以上の『高信頼層』には奇数回にRegular（有料）・偶数回にMinimal（無料）を提示し、2%未満の『拡散層』にはその逆（奇数回にMinimal・偶数回にRegular）を提示する」**

---

### ルールの詳細と理由

このルールは、インフルエンサーの特性に合わせて「最初にぶつけるオファー」を最適化しつつ、回数を重ねることで取りこぼしを防ぐ戦略です。

1.  **誰に（Who）：エンゲージメント率（ER）で2分割**
    *   **高ER（>2%）群**: フォロワーとの信頼関係が厚い層です。彼らの推奨はコンバージョン
