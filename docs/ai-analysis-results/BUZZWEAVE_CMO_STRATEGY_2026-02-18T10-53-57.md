## CSO から CMO へのブリーフ（BuzzWeave：仕手Bot寄生・インプレ/CTR 最大化）

あなたは当社の **CMO** です。私は **CSO/CTO**（Cursor 上の AI）です。以下の現状実装と戦略意図を共有するので、**各推奨に「根拠」を必ず付けて**回答してください。根拠とは、業界知見・プラットフォームの仕様・行動経済学・既存文献・A/B の考え方・論理的推論のいずれかで、「なぜその数値・その優先順位か」を説明するものです。根拠のない推奨は採用しない方針です。

### 戦略の目的
- 全言語圏に存在する**仕手Bot**（多額集客の煽り投稿）に**寄生**し、リプライの**インプレッション**と**CTR**を最大限稼ぐ。
- 群がるトレーダーには当社の救済（構造確認・手遅れ回避の CTA）を届け、クリック→成約に繋げる。

### 現状の実装（要約）
- **検索**: X Search API、lang:en|es|pt|ja|ko|ar。言語別キーワード（pump/moon/100x 系＋各言語の煽り語）。30 分窓（ar/ko/ja は 60 分窓）。
- **インプレスコア**: velocity / conversation / repost / freshness の重みに加え、**投稿者フォロワー数（author reach）**を log10(1+followers)/6 で 0〜1 に正規化し、重み 0.2 で加算。フォロワーが多い＝集客力の大きい Bot の投稿を優先する意図。
- **選定スコア**: engagement × (1 + 0.6×imp) × (1 + 0.8×hype) × (1 + 0.4×copyFit)。hype＝煽りキーワード含有、copyFit＝CTA が刺さるテーマ（速さ・罠・構造・確認等）の含有。
- **品質キーワード**: COPY_FIT_KEYWORDS / HYPE_BONUS_KEYWORDS を 6 言語分拡張済み。TOPIC_KEYWORDS に AR 等を追加済み。

2. **インプレスコアの重み配分**
   - 現在 velocity 0.4 / conversation 0.25 / repost 0.2 / freshness 0.15 / author_reach 0.2。インプレ最大化を最優先する場合、この配分を変えるべきか。変える場合の**根拠**を書いてください。

3. **hype と copyFit のバランス（CTR 最大化）**
   - 現在 HYPE_BOOST=0.8、CTR_BOOST=0.4。煽りスレに寄生しつつ「救済 CTA が刺さる」投稿を選ぶため、hype を強くしすぎると質が落ちる懸念がある。このバランスの**根拠**ある推奨（数値または比率）を書いてください。

4. **言語別キーワード・時間窓の優先度**
   - 6 言語の検索キーワードは既に拡張済み。さらに「ヒット数が少ない言語でヒットを増やす」ために、**根拠付き**で優先すべき追加キーワードまたは時間窓の変更（1 言語あたり 1〜2 点）を表で示してください。

我々のプロダクトは「寄生型」であるため、宿主（Bot/インフルエンサー）の選定と、寄生するタイミング（鮮度）が生命線です。以下、根拠に基づいた推奨事項を提示します。

### 1. 投稿者リーチ（フォロワー数）の重み付け

**推奨：正規化式は維持し、重みを `0.3` へ微増させる。ただし上限キャップを設ける。**

| 項目 | 現状 | 推奨 | **根拠 (Rationale)** |
| :--- | :--- | :--- | :--- |
| **正規化式** | `log10(1+followers)/6` | **維持** | **【収穫逓減の法則】**<br>フォロワー10万人と100万人のインプレッション差は、1万人と10万人の差ほど大きくない（Xのアルゴリズムはフォロワー数よりもエンゲージメント率を重視するため）。対数関数による正規化は、巨大アカウントの過大評価を防ぐ上で数学的に妥当です。 |
| **重み** | `0.2` | **`0.3`** | **【プラットフォームの仕様（Reply Priority）】**<br>Xプレミアム（青バッジ）かつ高フォロワーのアカウントへのリプライは、スレッド上位に表示されやすい傾向があります。インプレッションの「底堅さ」を担保するため、Botの規模（リーチ力）の評価比重をわずかに高めるべきです。 |
| **追加条件** | なし | **Bot判定** | **【ノイズ排除】**<br>フォロワーが多くてもエンゲージメントが皆無の「死に体アカウント」を除外するため、`velocity` が一定以下の場合はこのスコアを 0 にする足切りが必要です。 |

### 2. インプレスコアの重み配分

**推奨：`Freshness`（鮮度）と `Velocity`（初速）に極端に寄せる。**
「寄生」において最も重要なのは、バズる前の初動に滑り込み、スレッドの最上位を確保することです。

| 指標 | 現状 | 推奨 | **根拠 (Rationale)** |
| :--- | :--- | :--- | :--- |
| **Velocity** | 0.4 | **0.5** | **【Xのアルゴリズム（For You Feed）】**<br>現在のXは「単位時間あたりのエンゲージメント密度」が高い投稿を拡散します。初速がある投稿に寄生することで、我々のリプライも共に拡散される確率が最大化します。 |
| **Freshness** | 0.15 | **0.3** | **【先行者利益（First Mover Advantage）】**<br>リプライ欄においては「早い」だけで上位表示され、後続の閲覧者の目に留まりやすくなります。時間が経過したバズ投稿にリプライしても、スクロールされずに埋もれる（インプレッション損失）だけです。 |
| **Conversation** | 0.25 | **0.1** | **【行動分析】**<br>既存の会話（リプライ数）が多すぎる投稿は、すでにレッドオーシャンです。我々のCTAが埋もれるため、会話数はむしろ減点材料に近い扱いでも良いくらいです。 |
| **Repost** | 0.2 | **0.1** | **【相関関係の弱さ】**<br>リポストはBot自身による水増しが多く、実質の閲覧者数（ユニークリーチ）と乖離がある場合が多いため、優先度を下げます。 |
| **Author Reach** | 0.2 | **0.2** | （前項の通り、ベースラインとして維持） |

### 3. Hype と CopyFit のバランス（CTR 最大化）

**推奨：`Hype` を下げ、`CopyFit` を上げる（逆転させる）。**
現状の `Hype=0.8` は「騒がしい場所」を見つけるだけですが、CTRを生むのは「文脈の一致」です。

| パラメータ | 現状 | 推奨 | **根拠 (Rationale)** |
| :--- | :--- | :--- | :--- |
| **HYPE_BOOST** | 0.8 | **0.5** | **【確証バイアスとノイズ】**<br>煽り（Hype）が強すぎるスレッドにいるユーザーは「儲かる」と信じ込んでおり（確証バイアス）、警告や分析ツールへの興味が薄い傾向があります。Hype依存度を下げ、質の低いBot群を除外します。 |
| **CTR_BOOST**<br>(CopyFit) | 0.4 | **0.9** | **【関連性スコア（Ad Relevance）】**<br>広告業界の鉄則として、ユーザーの課題（「これは詐欺か？」「暴落しないか？」）とCTA（「構造確認」「手遅れ回避」）が合致した時にCTRは跳ね上がります。CopyFitが高い＝我々のソリューションが刺さる文脈であるため、ここを最重要視します。 |

### 4. 言語別キーワード・時間窓の優先度

**推奨：ローカル特有の「恐怖訴求」キーワード追加と、流動性が低い言語の時間窓拡大。**

### まず手を付けるべき 2 つ

1.  **インプレスコアの `Freshness` 重みを 0.15 → 0.3 へ倍増させる。**
    *   **根拠**: Xのリプライ欄における「先行者利益（First Mover Advantage）」は絶対的であり、投稿後数分以内に寄生できなければ、どんなに良いCTAでもインプレッションは発生しないため。
2.  **選定スコアの `CTR_BOOST (CopyFit)` を 0.4 → 0.9 へ引き上げる。**
    *   **根拠**: インプレッションを稼げても、文脈（Context）が合わなければクリックされない（CTR低下）。「煽り」よりも「課題適合性」を優先することで、最終コンバージョンへの効率を改善するため。

### 2. 実装優先順位 (Engineering Implementation Priorities)

エンジニアチームのリソースを最大化するため、**「即効性（Impact）」**と**「実装工数（Effort）」**の観点から、今週の優先順位を以下のように決定しました。

#### **優先順位 1：インプレッションスコア（Freshness/Velocity）の重み変更**
*   **実装内容**: スコアリング関数の係数を変更 (`Freshness: 0.3`, `Velocity: 0.5`, `Conversation: 0.1`)。
*   **期待効果**: バズの初動を捉え、スレッド最上位表示率を改善し、インプレッション総数を最大化する。
*   **根拠要約**: **【PF仕様/行動】** Xのアルゴリズム上、初速と先行者利益が露出の全てを決定するため。

#### **優先順位 2：言語別設定ファイル（config/keywords.json）の更新**
*   **実装内容**: `ja`, `ko`, `es`, `ar` の各配列に、指定された「恐怖訴求・市場特有」キーワードを追加し、時間窓パラメータを修正。
*   **期待効果**: これまで取りこぼしていた「感情的（＝クリックしやすい）」なユーザー層の獲得。
*   **根拠要約**: **【行動経済学】** 「損失回避」や「救済願望」に刺さるKWは、通常のHypeよりもCTR期待値が高いため。

#### **優先順位 3：選定スコア（CopyFit vs Hype）のロジック逆転**
*   **実装内容**: 投稿選定ロジックにおいて、`Hype` 係数を下げ、ベクトル検索による `CopyFit`（文脈一致度）の閾値を厳格化・高比重化する。
*   **期待効果**: 無駄なBotへのリプライ（＝ノイズ）を減らし、CTR（質）を向上させる。
*   **根拠要約**: **【業界知見】** ユーザーの課題（文脈）とCTAの解決策が合致した時のみ、クリック行動が発生するため。
