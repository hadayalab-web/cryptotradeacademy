**作成日時**: 2026-01-02  
**作成者**: COO（Cursor/Composer 1）

---

## 📅 定期配信スケジュール一覧

### VSL1投稿（無料版オプトイン誘導）
- **Cron設定**: `0 9,21 * * *`（UTC）
- **実行頻度**: **1日2回**
- **UTC時刻**: 9:00, 21:00
- **JST時刻**: **18:00, 6:00（翌日）**
- **配信先**: 
  - Telegram MINIMALチャンネル（6言語）
  - X（Twitter）（1回のみ、最初の言語または`X_VSL1_LANG`で指定）

**注意**: 多言語対応を有効にするには、環境変数`VSL1_MULTI_LANG=true`を設定するか、`VSL1_LANGS=en,es,pt-br,ar,ja,ko`を設定してください。

---

### VSL2配信（24時間後のアップセル/クーポン）
- **Cron設定**: `0 * * * *`（UTC）
- **実行頻度**: **1時間ごと**
- **配信タイミング**: 無料版ユーザー登録から**24時間経過**したユーザーに自動配信
- **配信先**: Telegram DM（ユーザー個別）

---

### VSL1リマインダー（12時間後のリマインド）
- **Cron設定**: `0 */12 * * *`（UTC）
- **実行頻度**: **12時間ごと**（UTC 0時、12時）
- **配信タイミング**: 無料版ユーザー登録から**12-24時間経過**したユーザー（VSL2未送信）
- **配信先**: Telegram DM（ユーザー個別）

---

### VSL2ラストコール（22時間後の最終リマインド）
- **Cron設定**: `0 * * * *`（UTC）
- **実行頻度**: **1時間ごと**
- **配信タイミング**: 無料版ユーザー登録から**22時間経過**したユーザー（VSL2未送信、24時間の2時間前）
- **配信先**: Telegram DM（ユーザー個別）

---

### プロモコード在庫監視
- **Cron設定**: `*/15 * * * *`（UTC）
- **実行頻度**: **15分ごと**
- **機能**: Whop APIでプロモコード在庫を監視し、閾値下回り時に自動リマインド

---

### 定期市場分析配信（cron.js）
- **Cron設定**: `*/15 * * * *`（UTC）
- **実行頻度**: **15分ごと**
- **配信タイミング**: 定時スロット（6時間ごとまたは4時間ごと）で配信
- **配信先**: Telegramチャンネル（有料版）、Email

## 🕐 タイムゾーン変換表

### VSL1投稿時刻（UTC → JST）

| UTC時刻 | JST時刻 | 説明 |
|---------|---------|------|
| 09:00 | **18:00** | 1回目（午後6時） |
| 21:00 | **06:00（翌日）** | 2回目（翌朝6時） |

**注意**: UTCは協定世界時、JSTは日本標準時（UTC+9）

## ⚙️ 環境変数による制御

### 多言語配信の有効化

```bash
# オプション1: 全言語を有効化
VSL1_MULTI_LANG=true

# オプション2: 特定の言語のみ指定
VSL1_LANGS=en,ja,ko

# X投稿の言語を指定（デフォルト: 最初の言語）
X_VSL1_LANG=ja
```

### 配信の無効化

```bash
# X投稿を無効化
X_POSTING_ENABLED=false

# X投稿をDry Runモード（実際には投稿しない）
X_POSTING_DRY_RUN=true
```

## 🔍 次回配信時刻の確認方法

### Vercel Dashboard
1. Vercel Dashboard → Project → Settings → Cron Jobs
2. 各Cronジョブの「Next Run」を確認

### ログ確認
- Vercel Dashboard → Project → Logs
- 配信時刻に実行ログを確認

---

## 📝 注意事項

1. **UTC時刻で実行**: すべてのCronジョブはUTC時刻で実行されます
2. **JST変換**: JST = UTC + 9時間
3. **多言語配信**: `VSL1_MULTI_LANG=true`を設定しない場合、`LANG`環境変数で指定された1言語のみ配信されます
4. **X投稿**: スパム回避のため、1回のCron実行で1回のみ投稿されます（最初の言語または`X_VSL1_LANG`で指定）
