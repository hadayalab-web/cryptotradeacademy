# 新しいVSLワークフロー - シンプルまとめ
**作成日時**: 2026-01-22  
**目的**: 新しいVSLワークフローのシンプルなまとめ

---

## 🎯 ワークフロー（5ステップ）

### 1. ユーザー投稿
**私が手動かX APIで無料版を私のアカウントにポスト**
- 6言語版のVSL1メッセージ（無料版オプトイン誘導）を投稿
- 手動またはX APIで自動投稿

### 2. インフルエンサー発掘
**Grokがホットインフルエンサーアカを見つけて引用リポスト**
- Grokが6言語ごとにインプレッションが伸びやすいインフルエンサーアカウントを発掘
- 発掘基準：フォロワー数、エンゲージメント率、過去のインプレッション実績など（Grokが最適解を判断）

### 3. 文章最適化
**Grokがホットな文章を作成してインプレッションを伸ばす**
- インプレッション数が最大化するように解析して文章を作成
- 元投稿を引用しつつ、インプレッション最大化を狙う文章を生成

### 4. 最適タイミング投稿
**24時間使って、各言語のホットな時間帯にGrokがポスト**
- 6言語 × 2人 × 2投稿 = 24投稿/日
- 1時間に1投稿
- 各市場の最適な時間帯に設定（Grokが判断）

### 5. トラフィック獲得
**インプレッションを最大化させてファネルにトラフィックをどんどん流す**
- 引用リポスト経由でVSL1への流入を増やす
- インプレッション → クリック → VSL1視聴 → 無料版オプトイン → 有料版エンゲージメント

## 🤖 Grokに任せる判断事項

1. **インフルエンサー発掘の基準**（フォロワー数、エンゲージメント率、過去実績など）
2. **引用リポストのタイミング**（投稿後すぐ、数時間後など）
3. **引用リポストの頻度**（1投稿あたり何人に引用リポストするか）
4. **引用リポストの文章生成**（インプレッション最大化のための最適な文章）
5. **各言語のホットな時間帯**（24時間を最適に分散）

---

## 🚀 段階的実装プラン

### Phase 1 (1週間, MVP)
- 1言語（en）× 1人 × 1投稿/日
- Grok発掘精度、引用リポスト効果を検証

### Phase 2 (2週間)
- 3言語（en/es/ja）× 2人 × 2投稿 = 12投稿/日
- レート制限テスト、スパム判定回避を検証

### Phase 3 (1ヶ月)
- 全6言語 × 2人 × 2投稿 = 24投稿/日
- 本番運用、A/Bテスト、ROI測定

---

## ⚠️ リスク対策

- **X APIスパム判定**: 1投稿3-5人以内に制限、ランダム遅延
- **レート制限**: 1時間に1投稿の分散投稿
- **インフルエンサー過負荷**: 複数のインフルエンサーをローテーション
