# PQT テンプレ設計の根拠：Gemini 分析

**方針**: テンプレ（本文・希少性コピー・フック）の設計は、すべてこの Gemini の行動経済学分析に基づいて統一する。

---

## 1. 仮説の検証：「損失回避層に緊急性×希少性は刺さるか？」

**結論：強く支持される。**

- **二重の損失回避（Double Loss Aversion）:** 煽りに反応する層は「儲け損なうこと」を「実損」と同じ痛みとして処理する。「今すぐ行動しないと防御ツールさえ手に入らない」は、失うことへの恐怖を二重に刺激する。
- **認知トンネリング（Cognitive Tunneling）:** 緊急性・希少性は視野を狭窄させ、システム1（直感）を優位にする。Bot の煽りで既に「思考停止」モードに入っている層には、論理説得より「同じシステム1（急げ、なくなってしまう）」でアプローチする方が波長が合う。

---

## 2. 設計の評価：「毒をもって毒を制す」

- **アイキドウ（合気道）効果:** Bot が作り出した「焦り」のエネルギーを消さず、そのまま「防御」という別の出口へ誘導する。
- **同一言語で、行動先だけ防御側に振り向ける:** ナッジとして合理的。
- **権威性の付与:** 「50名限定」で防御情報にプレミアム感を与え、信頼されやすくする（チャルディーニの権威の法則）。

**リスク:** 「アクセル（緊急性）」と「ブレーキ（確認・停止）」の矛盾 → 認知的不協和（「なんだ、面倒くさい」「詐欺か？」）を招く可能性。

---

## 3. 改善案（矛盾解消のチューニング）

### A. コピーの焦点を「枠」ではなく「市場の変動」に置く

- **Before:** 「残り50枠！48h限定で公開」
- **After:** 「**相場が崩れる前の48時間**限定公開。手遅れになる前に確認枠を確保してください」
- ツールの売り切れではなく、**資産が守れるタイムリミット**を煽る。損失回避の対象を「機会損失」から「元本の保護」へスムーズに移行させる。

### B. 「防御」を「攻撃的準備」と言い換える（フレーミング効果）

- **Before:** 「煽りに同調せず、まずは確認して止まろう」
- **After:** 「**カモにされない上位5%のトレーダーだけが知る**『スクリーニング』を適用。生存者枠あと30名」
- 「止まる」という不作為を、「選別する」という作為に見せ、希少性を「賢いグループへの所属権」として機能させる。

### C. 手順の簡略化（認知的負荷の低減）

- 緊急性で釣った直後は深く考えられない。LP では論理説明を省き、**YES/NO で即判定できる UI**（例：信号機的な赤・青判定）を提示する。「急いで枠を取った甲斐があった」という報酬を与える。

---

## 4. リプライ用 3 パターン（Gemini 作成）

Bot 投稿タイプに合わせて使い分ける。実装は `services/td/pqtTemplates.js` の `SCARCITY_VARIANTS`（fear / authority / elitism）。仕手Botの `dangerLabel` に応じた**重み付きランダム（Jitter）**で選択（スパム・Ad fatigue 低減）。`CAMPAIGN_SCARCITY_VARIANT` 指定時はそのパターンで上書き。

| パターン | 狙い | 活用シーン |
|----------|------|------------|
| **恐怖訴求型 (fear)** | 儲け損なう恐怖 → 資産を失う恐怖にすり替え、防御行動を緊急化 | Bot が「To the moon!」「今買わないと損」と強く煽っている時 |
| **権威訴求型 (authority)** | 騒がしい煽りに対し「冷静なプロのデータ」で対比、信頼で釣る | 「確実な情報筋」「激アツ銘柄」など情報の質を謳う Bot 投稿 |
| **選民意識型 (elitism)** | 養分になりたくないプライドを刺激し、防御＝賢い選択と再定義 | 「買いました！」「行けー！」など群がるリプライ・FOMO 煽り投稿 |

文言の詳細は **`docs/PQT_SCARCITY_3PATTERNS_GEMINI.md`** を参照。

## 5. 実装との対応

| 要素 | ファイル・定数 | 備考 |
|------|----------------|------|
| 希少性 3 パターン | `pqtTemplates.js` → `SCARCITY_VARIANTS` | Gemini 出力を使用。dangerLabel に応じた Jitter（70/20/10 等）で fear/authority/elitism を選択。 |
| 改善 A（市場の変動） | fear 系コピー | 「値崩れ前」「手遅れになる前の48時間」「資産を守る」で市場ベースの緊急性を強調済み。 |
| 改善 B（攻撃的準備） | elitism 系コピー | 「上位5%」「生存者枠」「カモにされない」で防御＝選民フレーム済み。 |
| 本文テンプレ（3パターン） | `PQT_TEMPLATES_3PATTERNS` | dangerLabel あり時は 1 パターン＝1 メッセージ。Jitter で本文と希少性を同一パターンに統一。 |
| 本文テンプレ（従来） | `PQT_TEMPLATES` / `PQT_TEMPLATES_BOT` | dangerLabel なし時。損失回避・固定行動指針。仕手Bot投稿へのリプライ用。 |
