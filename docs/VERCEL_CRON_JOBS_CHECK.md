# Vercel Cronジョブ確認手順

## 📋 vercel.jsonの設定確認

`vercel.json`には以下のCronジョブが設定されています：

### X投稿関連のCronジョブ
1. **`/api/x-post-free-report`**
   - スケジュール: `5 6,18 * * *` (毎日6:05と18:05 UTC)
   - 目的: 無料版レポートをXに投稿

2. **`/api/x-quote-repost`**
   - スケジュール: `0 12-22 * * *` (毎日12-22時 UTC、1時間ごと)
   - 目的: インフルエンサーへの引用リポスト

### その他のCronジョブ（参考）
- `/api/cron`: `*/15 * * * *` (15分ごと)
- `/api/vsl1-post`: `0 14,20 * * *` (毎日14:00と20:00 UTC)
- `/api/vsl2-free-users`: `0 * * * *` (1時間ごと)
- など...

## 🔍 Vercelダッシュボードでの確認方法

### ステップ1: Vercelダッシュボードにアクセス
1. https://vercel.com/dashboard にアクセス
2. プロジェクト「cryptotradeacademy」を選択

### ステップ2: Cronジョブの確認
1. **Settings → Cron Jobs** を開く
2. 以下のCronジョブが表示されているか確認：
   - `/api/x-post-free-report`
   - `/api/x-quote-repost`
3. 各Cronジョブの状態を確認：
   - **Status**: Active / Inactive
   - **Last Run**: 最後の実行時刻
   - **Next Run**: 次回実行時刻
   - **Schedule**: スケジュール設定

### ステップ3: 問題がある場合の対処

#### 問題1: Cronジョブが表示されていない
**原因**: `vercel.json`の設定がVercelに反映されていない

**対処法**:
1. 最新のコミットがデプロイされているか確認
2. 再デプロイを実行
3. デプロイ完了後、Cronジョブが表示されるか確認

#### 問題2: CronジョブがInactiveになっている
**原因**: Vercelプランの制限や設定の問題

**対処法**:
1. VercelプランがPro以上か確認（HobbyプランではCronジョブが制限される可能性）
2. Cronジョブを手動でActiveに設定
3. エラーメッセージがある場合は確認

#### 問題3: Cronジョブは表示されているが実行されていない
**原因**: 環境変数の設定やコードの問題

**対処法**:
1. Functions → Logs でエラーログを確認
2. 環境変数が正しく設定されているか確認
3. 手動実行でテスト

## 🧪 手動実行テスト

### `/api/x-post-free-report`のテスト
1. Functions → `x-post-free-report` を選択
2. 「Invoke」ボタンをクリック
3. ログで実行結果を確認
4. Xアカウント（@trapdefence）で投稿が表示されるか確認

### `/api/x-quote-repost`のテスト
1. Functions → `x-quote-repost` を選択
2. 「Invoke」ボタンをクリック
3. ログで実行結果を確認
4. インフルエンサー発掘と引用リポストが成功しているか確認

## 📊 期待される動作

### `/api/x-post-free-report`（毎日6:05と18:05 UTC）
- 最新の市場データを取得
- 無料版レポートを6言語でXに投稿
- メインツイート + 2-3リプライ（スレッド形式）
- 二重実行防止（KVストレージで管理）

### `/api/x-quote-repost`（毎日12-22時 UTC、1時間ごと）
- 最新の市場データを取得
- Grok APIでインフルエンサーを発掘（1人/言語）
- 引用リポストを投稿（6言語 × 1人 = 6投稿/時間）
- 1日の投稿上限（25投稿/日）をチェック

## ⚠️ 重要な注意事項

1. **Vercel Cronは有料プランが必要**
   - HobbyプランではCronジョブが実行されない可能性があります
   - Proプラン以上が必要です

2. **環境変数の設定**
   - すべての環境変数が正しく設定されているか確認してください
   - Production, Preview, Development すべての環境に設定してください

3. **ログの確認**
   - Vercelダッシュボード → Functions → Logs で実行ログを確認してください
   - エラーが発生している場合は、エラーメッセージを確認してください
