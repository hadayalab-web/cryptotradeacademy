## 補足

- **手順:** 返信本文（冒頭〜署名）と Telegram リンク表をコピーし、そのまま WarriorPlus の承認チャットに貼る。Regular は審査員用1人・期間無制限リンクを記載済み。

### 通常の顧客向けリンク発行フロー（参考）

1. **購入** … 顧客が Whop LP の CTA → WarriorPlus へリダイレクト → Stripe で決済。
2. **IPN** … WarriorPlus が決済完了を `api/whop-webhook` に送信（WP_ITEM_NUMBER で言語を判定）。
3. **リンク発行** … 環境変数に言語別の固定リンクがあればそれを使用。なければ Telegram Bot API の `createChatInviteLink` で **1回限り・7日有効** の招待リンクを発行（`TELEGRAM_CHAT_ID_BTC_EN` 等を使用）。
4. **メール送信** … Resend で購入者メールアドレスに「Join Telegram」リンク付きの案内を送信（差出人: support@cryptotradeacademy.io）。
5. **顧客** … メールのリンクをクリックして該当言語の Regular チャンネルに参加。

審査員に渡すリンクは、上記と同じチャンネルへのアクセスを「1人用・期間無制限」で手動作成したもの。
- 審査用なら、各リンクは **1回限り** または **人数制限付き** にすると安全。Telegram のチャンネル設定で「招待リンク」→「新規作成」→ 使用回数1回 or 期限付きで発行できる。
