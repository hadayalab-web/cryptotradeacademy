## 💰 Grok 4.1 Fast 料金

### 基本料金
- **Input Tokens**: $0.20 / 1M tokens
- **Output Tokens**: $0.50 / 1M tokens
- **Cached Input Tokens**: $0.05 / 1M tokens

### **Live Search料金（重要）**
- **$25.00 / 1,000 sources**

> **注意**: Xリード発見では、Grokが返す各「source」（リード）に対してLive Search料金が発生します。

## 📊 現在の実装でのコスト計算

### 1回の実行（30分ごと）

#### Grok呼び出し回数
- **キーワード検索**: 6言語 × 1回 = **6回**
- **トレンド検索**: 6言語 × 1回 = **6回**
- **合計**: **12回のGrok呼び出し**

#### 1回の呼び出しで取得されるsources数
- **キーワード検索**: 最大100 sources/言語
- **トレンド検索**: 最大50 sources/言語

#### 1回の実行で取得されるsources数
- **キーワード検索**: 6言語 × 100 = **最大600 sources**
- **トレンド検索**: 6言語 × 50 = **最大300 sources**
- **合計**: **最大900 sources/回**

## 💵 コスト計算

### Live Searchコスト

**1回の実行**:
- 900 sources × ($25 / 1,000 sources) = **$22.50 / 回**

**1日（48回実行）**:
- $22.50 × 48 = **$1,080 / 日**

**1ヶ月（30日）**:
- $1,080 × 30 = **$32,400 / 月**

---

### Tokenコスト（追加）

#### Input Tokens
- **プロンプト長**: 約500 tokens/回
- **12回の呼び出し**: 500 × 12 = 6,000 tokens/回
- **1日**: 6,000 × 48 = 288,000 tokens
- **コスト**: 288,000 / 1,000,000 × $0.20 = **$0.058 / 日**

#### Output Tokens
- **max_tokens**: 4,000 tokens/回
- **実際の出力**: 約3,000 tokens/回（推定）
- **12回の呼び出し**: 3,000 × 12 = 36,000 tokens/回
- **1日**: 36,000 × 48 = 1,728,000 tokens
- **コスト**: 1,728,000 / 1,000,000 × $0.50 = **$0.864 / 日**

#### Tokenコスト合計
- **1日**: $0.058 + $0.864 = **$0.922 / 日**
- **1ヶ月**: $0.922 × 30 = **$27.66 / 月**

## 🎯 コスト最適化のポイント

### 1. Live Search料金が主要コスト
- **99.9%のコストがLive Search料金**
- Tokenコストは無視できるレベル（0.1%）

### 2. sources数がコストに直結
- 1,000 sources = $25
- 10,000 sources = $250
- 100,000 sources = $2,500

### 3. 重複除去の重要性
- 同じリードを複数回取得すると無駄なコスト
- 現在の実装では重複除去あり（usernameベース）

---

## 💡 コスト削減の提案

### 1. 実行頻度の調整
- **現在**: 30分ごと（48回/日）
- **提案**: 1時間ごと（24回/日）
- **削減**: 50% → **$16,200 / 月**

### 2. sources数の最適化
- **現在**: 最大100 sources/言語
- **提案**: 50 sources/言語（高品質リードに絞る）
- **削減**: 50% → **$16,200 / 月**

### 3. 言語の優先順位
- **高優先度**: EN, ES（市場規模大）
- **中優先度**: PT-BR, AR
- **低優先度**: JA, KO（必要に応じて）
- **削減**: 30-50% → **$11,340 - $16,200 / 月**

### 4. トレンド検索の削減
- **現在**: キーワード検索 + トレンド検索
- **提案**: キーワード検索のみ（トレンド検索は削除）
- **削減**: 33% → **$21,600 / 月**

## ⚠️ 注意事項

1. **Live Search料金が主要コスト**
   - Tokenコストは無視できるレベル
   - sources数に応じてコストが変動

2. **実際のコストはsources数に依存**
   - Grokが実際に返すsources数によって変動
   - 最大ケースと現実的ケースで大きく異なる

3. **重複除去の重要性**
   - 同じリードを複数回取得すると無駄
   - 現在の実装ではusernameベースで重複除去

4. **実行頻度の調整**
   - 30分ごと → 1時間ごとに変更で50%削減可能
   - ただし、リード発見数も50%減少
