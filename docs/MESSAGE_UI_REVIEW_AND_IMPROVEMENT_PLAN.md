# 📱 メッセージUIレビュー & 改善計画

**作成日**: 2026-01-07  
**目的**: メッセージUIの情報過多問題とUSPフォーカスの検証

## 🔍 現状分析

### 現在のメッセージ構造（JA版）

```
1. ヘッダー（3行）
   - 📚 Dr. Grok Market Leak
   - セッションブリーフィング @ タイムスタンプ

2. 基本市場データ（5行）
   - 💰 BTC 現在価格
   - 📊 取引所ネットフロー
   - ⛏ MPI
   - 🧠 投資家センチメント

3. スコア（1行）
   - 📈 マーケットスコア

4. 市場別データ（JA市場専用、最大4行）
   - ⚖️ リスクリワード比
   - • NUPL
   - • SOPR 30日平均

5. Trap Riskスコア（最大7行）
   - 🚨/⚠️/⚡/✅ トラップリスクスコア
   - • リスク要因（最大3つ）

6. NO TRADEアラート（最大6行）
   - 🚫/⚠️/⏸️ NO TRADEアラート
   - • 理由（最大3つ）
   - 💡 推奨事項

7. トラップ検知（1行）
   - 🧨/✅ トラップ検知

8. トレード・ヴァーディクト（最大6行）
   - 🎯 トレード・ヴァーディクト
   - 🟢/🔴/🛡️ シグナル
   - • エントリー、TP、SL、RR

9. Exit Map（最大30行、条件付き）
   - 🗺️ エグジットマップ
   - ポジション状態、P&L
   - 📍 利確ゾーン（複数）
   - ⚠️ 撤退条件（複数）
   - 💡 推奨事項

10. USP1: 市場バグ検知（最大8行、条件付き）
    - 🐛 市場バグ検知
    - バグタイプ、深刻度、スコア
    - トレンド転換シグナル
    - 詳細情報（複数）

11. USP3: Dr. Grok心理診断（最大8行、条件付き）
    - 💊 Dr. Grok 心理診断
    - 心理状態、リスクレベル
    - サポートレベル
    - 💡 アドバイス
    - サポートメッセージ（長文）

12. Dr. Grokの見立て（3行 + 最大1500文字）
    - 🧬 Dr. Grok の見立て
    - 注意書き
    - Grok分析テキスト（最大1500文字）
    - 免責事項
```

### 📊 情報量の統計

- **最小行数**: 約20行（USP1/USP3/Exit Mapなしの場合）
- **最大行数**: 約60-70行（全機能が有効な場合）
- **Grok分析テキスト**: 最大1500文字
- **総文字数**: 最大2000-2500文字

## ⚠️ 問題点

### 1. **情報過多による混乱**

#### 問題箇所
- **Exit Map（最大30行）**: ポジションがない場合でも表示ロジックが存在
- **Trap Risk + NO TRADEアラート（最大13行）**: 類似機能が重複
- **USP1 + USP3（最大16行）**: 後半に配置され、重要な情報が埋もれる
- **Grok分析（最大1500文字）**: 長文で最後に配置

#### ユーザー混乱のリスク
1. **情報の優先順位が不明確**: 最も重要な「トレードシグナル」が中間（161行目）に配置
2. **USPが埋もれている**: USP1とUSP3が後半（202行目以降）に配置
3. **類似情報の重複**: Trap Risk、NO TRADEアラート、トラップ検知が混在
4. **Exit Mapが長すぎる**: ポジションがない場合でも表示ロジックが存在

### 2. **USPのフォーカス不足**

#### USP1: 市場バグ検知エンジン
- ✅ 実装済み（202-228行目）
- ❌ **問題**: 後半に配置され、トレードシグナルより後に表示
- ❌ **問題**: バグが検知されない場合は表示されない（条件付き表示）

#### USP2: Geminiコンテンツ生成
- ✅ 実装済み（画像・動画は別途送信）
- ❌ **問題**: メッセージ本文に言及がない
- ❌ **問題**: ユーザーが「なぜ画像・動画が送られてきたのか」理解しにくい

#### USP3: Dr. Grokの心理的サポート
- ✅ 実装済み（230-252行目）
- ❌ **問題**: 後半に配置され、トレードシグナルより後に表示
- ❌ **問題**: `medicalSupportLevel === 'NONE'`の場合は表示されない（条件付き表示）
- ❌ **問題**: サポートメッセージが長文（最大200-300文字）

### 3. **情報の優先順位が不明確**

現在の順序：
```
1. 基本データ（価格、フロー、MPI、センチメント）
2. スコア
3. 市場別データ（JA市場専用）
4. Trap Riskスコア
5. NO TRADEアラート
6. トラップ検知
7. トレード・ヴァーディクト ← 最重要だが中間に配置
8. Exit Map（長い）
9. USP1: 市場バグ検知 ← 後半
10. USP3: 心理診断 ← 後半
11. Dr. Grokの見立て（長文）
```

**理想的な順序**:
```
1. トレード・ヴァーディクト（最重要）
2. USP1: 市場バグ検知（なぜそのシグナルなのか）
3. USP3: 心理診断（今の心理状態の警告）
4. 基本データ（補足情報）
5. その他の詳細情報
```

## 🎯 改善提案

### 優先度: 🔴 高

#### 1. **情報の優先順位を明確化**

**変更内容**:
- トレード・ヴァーディクトを最上部（ヘッダーの直後）に移動
- USP1とUSP3をトレード・ヴァーディクトの直後に配置
- 基本データは補足情報として後半に移動

**期待効果**:
- ユーザーが最初に「何をすべきか」を理解できる
- USPが効果的にフォーカスされる

#### 2. **USP2（Geminiコンテンツ）の明示**

**変更内容**:
- 画像・動画送信時にメッセージ本文に1行追加
  - 例: `🎬 AI Market Analysis Video & Image attached (USP2: Gemini Veo 3.1 + Nano Banana Pro)`

**期待効果**:
- ユーザーが「なぜ画像・動画が送られてきたのか」を理解できる
- USP2が明確に伝わる

#### 3. **Exit Mapの簡略化**

**変更内容**:
- ポジションがない場合は表示しない（既に実装済み）
- ポジションがある場合も、主要情報のみ表示（最大10行に制限）
  - 未実現P&L
  - 最重要利確ゾーン（最大2つ）
  - 最重要撤退条件（最大2つ）

**期待効果**:
- メッセージが短縮される（最大20行削減）
- 重要な情報に集中できる

### 優先度: 🟡 中

#### 4. **Trap RiskとNO TRADEアラートの統合**

**変更内容**:
- Trap RiskとNO TRADEアラートが同時に表示される場合、統合表示
- 例: `🚫 NO TRADE (Trap Risk: 85/100, Confidence: HIGH)`

**期待効果**:
- 重複情報を削減（最大6行削減）
- 情報が簡潔になる

#### 5. **USP3の表示条件の緩和**

**変更内容**:
- `medicalSupportLevel === 'NONE'`の場合も、簡潔な1行表示
  - 例: `✅ 心理状態: NEUTRAL（リスク: LOW）`

**期待効果**:
- USP3が常に表示され、機能の存在が明確になる
- ユーザーが「心理診断機能がある」ことを認識できる

### 優先度: 🟢 低

#### 6. **Grok分析テキストの位置調整**

**変更内容**:
- Grok分析を「補足情報」セクションに移動
- または、折りたたみ可能な形式に（将来拡張）

**期待効果**:
- メッセージが簡潔になる
- 重要な情報（USP）が目立つ
