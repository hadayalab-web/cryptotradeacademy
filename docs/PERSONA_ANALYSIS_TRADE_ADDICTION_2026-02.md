# ペルソナ深掘り：含み損・思考停止・トレード依存 × プログラム購入層 × X/Whop適応世代

**前提市況（SoSoValueスクショ想定）**  
BTC 史上高値から約-40%、MA全線下、強制ロスカット報道、ホエール動き・規制ニュース。  
「戻るかも」と「もう終わりかも」のあいだで固まっている層がいる。

## 1. スクショのような市況で「含み損を抱え思考停止中のトレード依存症」とはどんな人か

### 1.1 定義の整理

- **含み損**：高値（ATH前後や10万〜12万ドル帯）で建玉/スポットを保有し、現価（7万台後半）で-30〜-50%程度の未実現損。
- **思考停止**：損切りも買い増しも決断できず、チャートとニュースを「見るだけ」の状態。行動が凍結している。
- **トレード依存症**：過去の勝ち体験や「一発逆転」への執着でリスクを取りすぎ、今は負けポジに縛られ、抜け出せないのにやめられない。

→ **「含み損で思考停止しているトレード依存症」＝ 損切りもホドり続けも“選べない”のに、相場から離れられない人。**

### 1.2 心理・行動の深掘り

| 軸               | 内容                                                                                                                                 |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| **時間の使い方** | チャート・X・ニュースを何度も確認するが、「やること」は決めていない。ルールがないので「見る」だけで終わる。                          |
| **感情**         | 後悔・恥・恐怖が混ざる。「認めたくない（含み損を確定したくない）」「でも戻るかも」と「このまま破綻するかも」の間で揺れる。           |
| **自己認識**     | 「自分はトレードができる」という過去の自己像と、「今の自分は何もできていない」のギャップ。言い訳や他責（相場・情報のせい）が増える。 |
| **情報摂取**     | 自分のポジを肯定する情報を無意識に探す。「底だ」「もう下がらない」系のポストに反応し、利確・損切り論には目を背けがち。               |
| **お金の感覚**   | すでに失った額が大きいほど「ここでやめたら全部無駄」と思い、さらなるホドり・無謀な張りに繋がりうる。                                 |

### 1.3 こんな「瞬間」で刺さる

- 「含み損を“認める”ことと“負け”は違う」と腑に落ちる瞬間。
- 「思考停止しているのは、ルールがなくて“都度判断”に追われているから」と気づく瞬間。
- 「ホドりも一つの戦略だが、条件と出口を決めているか」を問われる瞬間。
- 同じ市況で「動けている人」と「固まっている人」の差（二つの道・同じ日別のゲーム）を絵やストーリーで見せられた瞬間。

### 1.4 メッセージングの注意

- **責めない**：「甘い」「情けない」は防御を固めるだけ。  
  「多くの人が同じ状態になる。大事なのはここからどう動くか」が伝わるトーンがよい。
- **希望の売りすぎに注意**：「必ず戻る」「損切りしなくていい」は依存を助長しうる。  
  「判断の枠組みを持つ」「出口を決めてトレードする」が軸。
- **専門用語より状態の言語化**：「含み損」「思考停止」「ホドり」をそのまま使ってよい。本人が「自分ごと」と感じる言葉で語る。

## 2. 「われのプログラム価格帯でも安いぐらいだと思って簡単にお金を払える人」とはどんな人か

### 2.1 定義の整理

- **安いと感じる**：相対比較（含み損額・過去の損失・将来の損失リスク）で、プログラム価格を「安い」と認知する。
- **簡単に払える**：決済の摩擦が小さく、心理的ハードルが低い。Whopの操作に迷わず、クレカ/Apple Pay等で短時間で完了する。

→ **「安いと思って簡単に払える人」＝ 痛み（損失・後悔）を大きく経験しているほど、その解消への対価を“安い”と感じ、支払いの意思決定が速い人。**

### 2.2 心理・条件の深掘り

| 軸                 | 内容                                                                                                                                                           |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **痛みの大きさ**   | 含み損・実現損が大きいほど「この金額で未来を変えられるなら安い」となる。数十万〜数百万円の損失体験があると、数万〜十万円台のプログラムは「安い」と感じやすい。 |
| **自己投資の許容** | 「情報・教育には金を払う」という価値観。本・講座・コミュニティに過去に課金していると、同じカテゴリの出費に抵抗が小さい。                                       |
| **問題解決志向**   | 「なんとなく」ではなく「手法・枠組み・ルールが欲しい」と具体的。感情論より「どう判断するか」のロジックを求める。                                               |
| **時間的切迫**     | 「このままではまずい」と感じている。相場が動くたびに揺れる今の状態を変えたいという動機が強い。                                                                 |
| **信頼の経路**     | 匿名の広告より、Xでの発信・実績・同じ境遇の人の声に触れて「この人/このプログラムなら」と納得してから払う。                                                     |

### 2.3 「安い」と感じる比較軸（イメージ）

- 含み損額の数％〜十数％で「判断の枠組み」が手に入る → 安い。
- これまで失った時間・機会コストと比べて、プログラム価格は小さい → 安い。
- 今後、ルールなしで同じ失敗を繰り返すリスクを減らせるなら → 安い。
- 同種のスクール・コンサルと比べて明示的・シンプルな価格だと → 安い。

### 2.4 メッセージングの方向性

- **価格を「防御」の対価として語る**：「次の一発で取り返す」より「これ以上傷を深くしないための枠組み」。
- **比較を言語化する**：「含み損の何％か」「一本のポジの損切り幅の何分の一か」など、本人が持つ数字と紐づける。
- **「簡単に払える」を設計する**：Whopの導線・決済方法・説明の短さ。迷いポイントを減らし、「今決めれば今日から変えられる」と感じさせる。

## 3. 「XユーザーかつWhopのコンバージョン操作に抵抗ない人」とはどんな世代か

### 3.1 定義の整理

- **Xユーザー**：情報収集・発信・コミュニティ参加をXで行っている。暗号・トレード・ビジネス系のTLを持っている。
- **Whopのコンバージョン操作に抵抗ない**：LP→Whop→決済・オプトインという流れを「怪しい」と感じず、クリック・入力・支払いまで完遂できる。

→ **「XユーザーでWhopに抵抗がない人」＝ デジタルで“見て・読んで・決めて・払う”一連の流れに慣れ、心理的・操作的摩擦が小さい層。**

### 3.2 世代・属性の深掘り（あなたの問いへの回答）

| 世代イメージ   | 年齢の目安     | Xとの関係                                                             | Whop/オンライン決済                                                                            |
| -------------- | -------------- | --------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| **Z世代**      | 〜20代前半     | 日常的に利用。短いコンテンツ・トレンド・コミュニティに敏感。          | サブスク・投げ銭・デジタル商品に慣れている。操作は苦にしないが、信頼のハードルはある。         |
| **ミレニアル** | 20代後半〜30代 | 仕事・投資・副業の情報をXで取る層が多い。長文・スレッドも読む。       | オンライン講座・情報商材・コミュニティ課金の経験者が多い。「価値があれば払う」が成立しやすい。 |
| **X世代**      | 40代前後       | Xを情報源として使い始めている層。フォロワー数・実績で信頼を測りがち。 | 慣れはミレニアルより劣るが、信頼できれば決済はする。導線が長い・複雑だと離脱しやすい。         |

**「抵抗ない」の中心は ミレニアル〜Z世代（おおよそ20代後半〜30代）。**

- 暗号・トレードに興味があり、かつ
- オンラインで「学ぶ・参加する・払う」をセットで経験している  
  層が、Whopのコンバージョン操作に最も抵抗が少ない。

### 3.3 「抵抗」が生まれるポイント（逆に言うと設計ポイント）

- **不信**：「怪しい」「稼ぎ目的では？」→ 発信者像・実績・第三者っぽい言及で信頼を補強する。
- **手間**：ステップが多い・説明が長い→ クリック数と入力を減らし、Whop側もシンプルに。
- **世代による違い**：若いほど「操作」には慣れているが「高い買い物」には慎重。年上ほど「操作」で離脱しうるので、導線の明確さが重要。

### 3.4 メッセージングの方向性

- **Xの文体・フォーマットに合わせる**：長文ならスレッド、短文ならキャッチ＋リンク。画像（例：風刺画）で「止まって・考えて・クリック」を誘う。
- **Whopへの橋渡し**：「ここを押すとこうなる」を一言で伝える。期待値のギャップを減らす。
- **世代を直接名指ししない**：「トレードで悩んでいる人」「判断の枠組みが欲しい人」のようにニーズで切り、そのニーズがXで集まっている層＝結果的にミレニアル〜Zが多くなる、という設計でよい。

## 4. 3つのペルソナの交差点（誰に・何を・どう届けるか）

- **誰に**：スクショのような市況で含み損・思考停止・トレード依存に近い状態にいる、Xユーザー（特にミレニアル〜Z）。
- **何を**：責めない言語で「含み損と思考停止」「二つの道」「判断の枠組み」を伝えるコンテンツ＋プログラムという商品。
- **どう届けるか**：Xで「状態の言語化」と「希望の売りすぎでない出口」を発信し、Whopでは「安い」と「簡単に払える」を両立させる導線とメッセージ。

この交差点に、今回の風刺画（含み損・思考停止・二つの道など）のイメージを乗せると、「自分ごと」で止まり、かつプログラム価格を「安い」と感じやすい層に届けやすくなる。
