# 初速収益化のためのコスト最適化設定

**作成日**: 2026-01-18  
**目的**: 初速段階でコストを最小限に抑えつつ、高品質リードに集中して確実に収益化

---

## 🎯 初速収益化戦略

### 基本方針
1. **コスト最小化**: 月間$1,000-2,000以下に抑制
2. **高品質リード集中**: ドンピシャリードのみにフォーカス
3. **段階的スケール**: 収益が安定してから拡大

---

## ⚙️ 最適化設定

### 1. 実行頻度の削減

**変更前**: 30分ごと（48回/日）  
**変更後**: **2時間ごと（12回/日）**

**削減率**: 75%削減

**設定**: `vercel.json`
```json
{ "path": "/api/lead-discovery", "schedule": "0 */2 * * *" }
```

---

### 2. Sources数の削減

**変更前**: 最大100 sources/言語  
**変更後**: **最大30 sources/言語**（高品質に絞る）

**削減率**: 70%削減

**設定**: 環境変数
```bash
LEAD_DISCOVERY_MAX_SOURCES=30
```

---

### 3. 言語の絞り込み

**変更前**: 6言語（EN, ES, PT-BR, AR, JA, KO）  
**変更後**: **2言語（EN, ES）のみ**

**削減率**: 67%削減

**設定**: 環境変数
```bash
LEAD_DISCOVERY_LANGUAGES=en,es
```

**理由**:
- EN: 最大市場規模、コンバージョン率28%
- ES: LatAm市場、コンバージョン率26%
- この2言語で全体の60-70%の市場をカバー

---

### 4. トレンド検索の無効化

**変更前**: キーワード検索 + トレンド検索  
**変更後**: **キーワード検索のみ**

**削減率**: 50%削減

**設定**: 環境変数
```bash
LEAD_DISCOVERY_ENABLE_TRENDS=false
```

**スケール後**: `LEAD_DISCOVERY_ENABLE_TRENDS=true` で有効化

---

### 5. Grokプロンプトの最適化

**変更前**: 「最大限のリードを返す」  
**変更後**: **「高品質リードのみを返す」**

**効果**: ドンピシャリードの割合向上

---

## 💵 コスト計算（最適化後）

- **キーワード検索**: 6言語 × 1回 = **6回**
- **トレンド検索**: 無効化 = **0回**
- **合計**: **6回のGrok呼び出し**

#### 1回の実行で取得されるsources数
- **キーワード検索**: 6言語 × 30 = **最大180 sources**
- **トレンド検索**: 0
- **合計**: **最大180 sources/回**

### Live Searchコスト

**1回の実行**:
- 180 sources × ($25 / 1,000 sources) = **$4.50 / 回**

**1日（12回実行）**:
- $4.50 × 12 = **$54 / 日**

**1ヶ月（30日）**:
- $54 × 30 = **$1,620 / 月**

### Tokenコスト

**1日**: 約$0.15  
**1ヶ月**: 約$4.50

### **総コスト（最適化後）**

- **合計**: **$1,624.50 / 月**

## ⚙️ 環境変数設定

### 初速段階（推奨）
```bash
# 言語設定（EN, ESのみ）
LEAD_DISCOVERY_LANGUAGES=en,es

# Sources数（高品質に絞る）
LEAD_DISCOVERY_MAX_SOURCES=30

# トレンド検索（無効化）
LEAD_DISCOVERY_ENABLE_TRENDS=false
```

### スケール後
```bash
# 全言語に拡張
LEAD_DISCOVERY_LANGUAGES=en,es,pt-br,ar,ja,ko

# Sources数増加
LEAD_DISCOVERY_MAX_SOURCES=100

# トレンド検索有効化
LEAD_DISCOVERY_ENABLE_TRENDS=true
LEAD_DISCOVERY_MAX_TREND_SOURCES=50
```
