### 異常パターン1: CronJobが実行されていない

**症状**:
- Vercel LogsにCronJobの実行ログがない
- 「Next Run」時刻が過ぎても実行されていない

**対応**:
1. Vercel Dashboard → Settings → Cron Jobs でCronJobが有効か確認
2. 環境変数 `CRON_SECRET` が正しく設定されているか確認
3. デプロイメントが最新か確認
4. Vercelサポートに問い合わせ

### 異常パターン2: X投稿が実行されていない

**症状**:
- ログに `dryRun: true` が表示されている
- Xアカウントに投稿が表示されていない

**対応**:
1. 環境変数 `X_POSTING_DRY_RUN=false` を確認
2. 環境変数 `X_POSTING_ENABLED=true` を確認
3. X API認証情報（`X_API_*`）が正しいか確認
4. Vercel Logsでエラーメッセージを確認

**症状**:

2. タイムアウトエラーの場合: `maxDuration` を増やす
3. APIエラーの場合: API認証情報を確認
4. リソース不足の場合: Vercelプランをアップグレード

## 🔧 トラブルシューティング

### よくある問題と解決方法

#### 問題1: CronJobが実行されない

**原因**:
- `CRON_SECRET` が設定されていない
- CronJobのスケジュールが間違っている
- Vercelプランが無料プラン（CronJobsが制限される）

**解決方法**:
1. 環境変数 `CRON_SECRET` を設定
2. `vercel.json` のスケジュールを確認
3. Vercel Proプランにアップグレード

#### 問題2: X投稿が実行されない

**原因**:
- `X_POSTING_DRY_RUN=true` になっている
- `X_POSTING_ENABLED=false` になっている
- X API認証情報が間違っている

**解決方法**:
1. 環境変数を確認: `X_POSTING_DRY_RUN=false`, `X_POSTING_ENABLED=true`
2. X API認証情報を再設定
3. Vercel Logsでエラーメッセージを確認

#### 問題3: タイムアウトエラー

**原因**:
- CronJobの実行時間が `maxDuration` を超えている
- 外部API呼び出しが遅い

**解決方法**:
1. `vercel.json` の `maxDuration` を増やす（最大300秒）
2. 外部API呼び出しを最適化
3. 並列処理を制限（`p-limit` を使用）

#### 問題4: 投稿数が少ない

**原因**:
- インフルエンサーストックが不足している
- クールダウン設定が厳しすぎる
- 日次投稿上限に達している

**解決方法**:
1. インフルエンサーストックを確認（824人ストックが活用されているか）
2. クールダウン設定を確認（6-8時間）
3. 日次投稿上限を確認（`X_MAX_DAILY_POSTS=250`）
