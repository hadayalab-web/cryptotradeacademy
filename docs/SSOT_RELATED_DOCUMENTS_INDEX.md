## 📝 使用方法

### SSOTを読む際の推奨順序

1. **まず読む**: `docs/SSOT_TRAP_DEFENSE_BTC.md`（統合SSOT）
2. **価格戦略を理解する**: `docs/PRICING_STRATEGY_UPDATE_REVIEW.md` → `docs/STRATEGIC_EFFECTS_INTEGRATION_AND_RECALCULATION_REVIEW.md`
3. **特典を確認**: `docs/FREE_TRIAL_AND_UPDATES_IMPLEMENTATION_REVIEW.md`
4. **用語を確認**: `docs/TERMINOLOGY_CORRECTION_REVIEW.md`
5. **技術仕様を確認**: `docs/SIGNAL_LOGIC_REVIEW_AND_OPTIMIZATION_PLAN.md`、`config/marketProfiles.js`

### 更新時の注意点

- SSOT更新時は、関連レビュードキュメントも同時に更新が必要な場合がある
- 特に価格・特典・用語変更時は、対応するレビュードキュメントの更新を確認
- 新しいレビュードキュメント作成時は、必ずSSOTの「📚 参照ドキュメント」セクションに追加
