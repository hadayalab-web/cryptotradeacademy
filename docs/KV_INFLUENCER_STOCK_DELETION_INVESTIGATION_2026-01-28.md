# KVインフルエンサーストック削除調査レポート
**作成日時**: 2026-01-28  
**状況**: ストックが空になっている原因を調査

---

## 🔍 調査結果

### 確認したスクリプト
1. **`scripts/check-kv-influencers.js`** - 読み取り専用
   - `kv.get()`のみ使用
   - 削除操作（`kv.del()`, `kv.set()`で空配列など）は**一切なし**

### ストックが空になる可能性のある原因

#### 1. **TTL（有効期限）による自動削除**
- **ストックのTTL**: 24時間（`STOCK_TTL = 24 * 60 * 60`）
- **更新時刻のTTL**: 24時間
- **原因**: 24時間以内にストックが更新されなかった場合、自動的に期限切れで削除される

#### 2. **ストック更新の失敗**
- `/api/x-update-influencer-stock`が実行されていない
- Grok APIのエラーで更新に失敗
- タイムアウトで更新が完了しなかった

#### 3. **KV接続の問題**
- KV接続が失敗してストックが読み込めない
- 環境変数（`KV_REST_API_URL`または`KV_URL`）が設定されていない

#### 4. **手動削除**
- Vercel Dashboardから手動で削除された
- 他のスクリプトやAPIで削除された

## 🔧 対応策

### 即座に実行すべき対応
1. **ストックを再構築**
   ```bash
   node scripts/update-influencer-stock.js --all
   ```

2. **自動更新を有効化**
   - `vercel.json`にCron設定を追加済み（毎日0時UTC）
   - デプロイ後に自動更新が開始される

### 長期的な対応
1. **ストック更新の監視**
   - ストックが空の場合のアラート設定
   - 更新失敗時のリトライ機能

2. **TTLの延長検討**
   - 現在: 24時間
   - 推奨: 48時間または72時間（更新が失敗してもバッファがある）

## ⚠️ 重要な確認事項

**私が作成したスクリプトは削除操作を行っていません。**
- `check-kv-influencers.js`: 読み取り専用（`kv.get()`のみ）

**ストックが空になった原因の可能性:**
