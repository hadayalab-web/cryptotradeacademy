## 2. 広告運用の応用であることの理解

この戦略は **広告運用の応用** である。高視聴率のYouTube番組やTV番組にCMを流してトラフィックを発生させる仕組みと同一である。

| 比喩             | 本戦略での対応                                                                   |
| ---------------- | -------------------------------------------------------------------------------- |
| **高視聴率番組** | 高インプレッション・高エンゲージメントのインフルエンサーのツイート（＝「番組」） |
| **CM枠**         | 引用リポスト（＝あなたのメッセージ＋Whopリンクを載せた「CM」）                   |
| **視聴者**       | インフルエンサーのフォロワー・アルゴリズムで届くユーザー                         |
| **トラフィック** | クリック → Whop（無料版 or 有料版）                                              |
| **成果**         | 無料版オプトイン（Minimal）、有料版購入（Regular）                               |

つまり:

- **在庫（インベントリ）** = 高品質インフルエンサー＝「視聴率の高い番組」を選ぶ
- **クリエイティブ** = 引用リポストのコピー・CTA（無料誘導 vs 有料誘導）
- **配信設計** = どの枠（引用リポスト）を無料版用・どの枠を有料版用に振るか
- **計測** = インプレッション・クリック・コンバージョン（Whop Webhook・UTM）

既存の戦略・コンテンツは、この **「メディア在庫＋CM＋トラフィック→コンバージョン」** の枠組みで再構築する。

## 3. 既存戦略・コンテンツの再構築（対応表）

### 3.1 ファネル＝「どのCMをどこに流すか」

| ファネル      | 役割（広告比喩）      | 既存コンテンツ・API                                                                                              |
| ------------- | --------------------- | ---------------------------------------------------------------------------------------------------------------- |
| **ファネル1** | 無料版への「CM」      | X → VSL1 → **Minimal Version**。`api/vsl1-post.js`, `api/x-post-minimal-version-cron.js`, 引用リポストの無料CTA  |
| **ファネル2** | 無料→有料の「追いCM」 | Minimal ユーザー → VSL2 → **Regular Briefing**。`api/vsl2-free-users.js`, `api/vsl2-last-call.js`, Telegram VSL2 |
| **ファネル3** | 有料版への「直接CM」  | X → **Regular Briefing 直接** → VSL3。`api/x-post-regular-direct.js`, 引用リポストの有料CTA                      |

引用リポストは **ファネル1（無料）とファネル3（有料直接）の両方の「CM枠」** を担う。  
リンク・プロモは `services/telegram/whop-links.js`（`getMinimalVersionCheckoutUrl`, `getWhopProductUrl`, `getPromoCode`）で統一。

### 3.2 目標数値（KPI）の再確認

| 指標                            | 目標        | 備考             |
| ------------------------------- | ----------- | ---------------- |
| 無料版（Minimal）コンバージョン | **150+**/日 | 可能な限り最大化 |
| 有料版（Regular）コンバージョン | **50**/日   | 可能な限り最大化 |

有料50をVSL2経由で賄う設計なら、無料側は **750/日程度のパイプライン** を目安にすると整合する（既存: `docs/REVERSE_STRATEGY_824_INFLUENCERS_2026-01-31.md`）。

### 3.3 必要インプレッション・引用リポスト数（既存逆算の再利用）

| 項目                                        | 値           | 出典                               |
| ------------------------------------------- | ------------ | ---------------------------------- |
| 無料導線で必要なインプレッション/日         | 約 44 万     | 無料750想定、CTR 1%, CVR 20%       |
| 有料直接用インプレッション/日               | 約 20 万     | 有料直接20想定                     |
| **合計目標インプレッション/日**             | **約 64 万** | 無料750＋有料50前提                |
| 1引用リポストあたりインプレッション（仮定） | 5,000        | インフルエンサー品質・アルゴに依存 |
| **必要な引用リポスト数/日**                 | **約 128**   | 64万 ÷ 5,000                       |

※ インフルエンサーが **高品質（高インプレ・高エンゲ）** であれば、1投稿あたりインプレッションは増え、同じコンバージョン目標をより少ない投稿数で達成できる。  
→ **在庫の質の向上＝広告単価（CPM/CPA）の改善** と同じ考え方。

## 4. 広告運用としてのチェックリスト（再構築の軸）

### 4.1 在庫（インベントリ）の質

- **高品質インフルエンサー** = 引用リポストで実際にインプレ・エンゲが取れるアカウント
- やること:
  - リストの検証（tweetId 実在、実インプレ・エンゲでのランキング）
  - 低パフォーマーは入れ替え・削除
- 参照: `docs/INFLUENCER_LIST_REALITY_CHECK_2026-01-31.md`, `scripts/validate-influencer-tweet-ids.js`

### 4.2 クリエイティブ（引用リポストのコピー・CTA）

- **無料CTA**: Minimal Version への誘導（「無料で試す」「VSL1を見る」等）
- **有料CTA**: Regular Briefing への誘導（「50%OFF」「残り50枠」等、プロモコード）
- 既存: Grok `generateQuoteRepostText`, Gemini 最適化、`services/telegram/whop-links.js` のURL・プロモ

### 4.3 配信設計（無料 vs 有料の振り分け）

- 引用リポストの **何割を無料誘導・何割を有料誘導** にするか（例: 7:3 や 8:2）
- 既存: `api/x-quote-repost.js` 内の CTA 選択、`api/x-post-regular-direct.js` のスケジュール
- 目標: 無料150+・有料50 を満たしつつ、可能な限り最大化

### 4.4 計測

- インプレッション・エンゲージメント: X API / Webhook（`api/x-engagement-metrics.js`, `api/x-webhook.js`）
- コンバージョン: Whop Webhook（`api/whop-webhook.js`）、UTM（`utm_source`, `utm_medium`, `utm_campaign`, `utm_content`）
- ダッシュボード: `api/analytics-dashboard.js`（無料・有料のコンバージョン追跡）
