# CryptoTrade Academy プロダクト再定義仕様書

## 📋 概要

本仕様書は、product-optimizerを使用してユーザーに最も選ばれるプロダクトを再定義し、現在のプロダクトとの乖離を抽出し、新しい配信戦略とAIエンジン統合を実装するための要件定義をまとめたものです。

---

## 🎯 現在のプロダクト定義

### プロダクト名
**現状**: CryptoTrade Academy（EN市場） / CryptoSignalAI（コード内）

**市場別ブランド名**:
- EN: CryptoTrade Academy
- AR: MaaliGuard
- KO: KimchiSniper
- JA: Kaizen Trader
- ES: VozComún
- PT-BR: VozComum

### ターゲットユーザー
- BTCトレーダー（アクティブトレーダー）
- 6市場対応（EN, AR, KO, JA, ES, PT-BR）

### コア機能
1. **シグナル生成**
   - CryptoQuantデータ（On-chain分析）
   - 価格・Fear&Greed指数
   - 市場スコアリングとシグナル判定

2. **AI分析**
   - Grok APIによる市場分析（`analyzeMarket`）
   - Xセンチメント分析（`analyzeXSentimentLive`）
   - 市場別ペルソナ対応（6市場）

3. **配信システム**
   - Telegram Bot経由の配信
   - 定期配信: 1日6回（4時間ごと: 0, 4, 8, 12, 16, 20時UTC）
   - 緊急配信: trap.isTrap && trap.confidence === 'HIGH'
   - イベント駆動配信（オプション）

4. **市場別プロファイル**
   - 各市場に最適化されたアルゴリズムパラメータ
   - 市場別ペルソナ（PRECISION_SNIPER, SHIELD_WALL, KIMCHI_SNIPER等）
   - 市場別価格設定

### 技術スタック
- **プラットフォーム**: Vercel（Serverless Functions + Cron）
- **API統合**: CryptoQuant API, Grok API (xAI), Telegram Bot API
- **言語**: Node.js
- **AIエンジン**: Grok API（xAI）のみ
