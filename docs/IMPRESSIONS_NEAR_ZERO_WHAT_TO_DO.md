# インプレがほぼゼロのとき（クリックさせるどころではない）

**状況**: ここ2時間以内の投稿が「1〜2件の表示」で、ほぼインプレなし。このままではクリック・成約は望めない。

**前提**: **まずリーチ（インプレ）がないとクリックは無理。インプレを伸ばすのが最優先。**

---

## 1. 因果の順序

```
インプレ（リーチ） → クリック（CTA） → 成約
```
インプレが 1〜2 なら、CTR をどう工夫してもクリック数はほぼ 0。**いかにクリックさせるか**の前に、**いかにインプレをつけるか**を潰す。

---

## 2. インプレが付かない原因候補

| 原因 | 説明 | 当リポで確認できること |
|------|------|------------------------|
| **アルゴに拾われていない** | 新規投稿は「テスト」で一部ユーザーにだけ表示される。初動のエンゲージメント（いいね・リプ・RT）が無いとランキングに乗らず、インプレが伸びない。 | 自投稿の「投稿直後〜1時間」にエンゲージメントが付いているか。buzzweave_post_log の our_impressions が時間経過で増えているか。 |
| **時間帯** | フォロワーのアクティブ時間とずれていると、初動で誰にも見られずテスト敗退。 | `analyze-our-pqt-buzz.js` で **UTC 時間帯別** の平均インプレを出す。インプレの出る時間帯に投稿を集中させる。 |
| **引用元の熱量** | PQT は「引用元の TL に自分のコメントが乗る」。引用元が伸びていなければ、そのスレを見る人数も少ない。 | 引用元の engagement_score・velocity。伸びている投稿を引用しているか。 |
| **アカウント・コンテンツ** | スパム判定・宣伝っぽいとアルゴが demote。新規アカやリンクだらけの投稿はリーチが付きにくい。 | 同一テンプレの連打を避ける。価値先行のコピー（PQT_CTR_HOW_TO_GET_CLICKS）。 |
| **投稿本数が少なすぎ** | そもそも投稿数が少ないと、当たる本数が少ない。 | Content Create が 23/日 などになっていないか。POST_VOLUME_NOT_GROWING.md で volume を確保。 |

---

## 3. 当リポでできること（優先順）

1. **PQT で「伸びている投稿」を引用する**  
   すでにやっている。**引用元が伸びているほど、そのスレに流れるユーザー数が増える**。検索で取る候補の engagement_score・velocity を上げ、伸びそうな投稿を優先して引用する（品質スコア・Fisherman の見直し）。

2. **「インプレの出る条件」を実データで出す**  
   `buzzweave_post_log` に our_impressions が溜まったら、`scripts/analyze-our-pqt-buzz.js` で **言語・クラスタ・UTC時間帯・引用元 engagement** 別の平均インプレを集計する。**インプレが高い条件に配分を振る**（言語・時間帯・run のタイミング）。

3. **投稿本数を落とさない**  
   インプレが付く確率を増やすには、当たる本数も必要。Content Create が極端に少ないと、そもそも「当たり」が出ない。POST_VOLUME_NOT_GROWING.md のレバーで **500/日 に近づける**。

4. **初動を意識する（運用）**  
   X は投稿直後の数十分で「テスト」し、エンゲージメントが無いと TL から外す。可能なら、**投稿直後に反応を誘う**（質問でリプライを促す、コミュニティで見るよう促す等）は運用で検討。コードで自動化するなら「リプライ誘発しやすいオープニング」をテンプレに強める（GROK_PROMPT_SECRET_WEAPONS の engagement_triggers）。

5. **宣伝っぽさを抑える**  
   リンクだけ・煽りだけにしない。価値先行・構造の話を前面に（PQT_CTR_HOW_TO_GET_CLICKS）。アルゴの demote を避ける。

---

## 4. 直近2時間でインプレ 1〜2 の意味

- **初動でアルゴの「テスト」にほぼ通っていない** 可能性が高い。= 表示されたユーザーが極少、かつエンゲージメントも付いていない。
- 対処は上記の通り: **インプレの出る時間帯・引用元・言語を分析で特定し、そこに振る**。同時に **投稿本数と初動を意識する**。
- アカウントが新規・フォロワーが少ない場合は、**PQT で他者のリーチに便乗する**戦略がそのまま重要。引用元選定（伸びている投稿を引く）と run のタイミングを分析結果で合わせる。
