**作成日**: 2026-01-17  
**作成者**: COO (Cursor/Composer 1)  
**ベース**: Grok CSO+CFO KPI設定分析

---

## 📊 計算の前提条件

### Grok CSO+CFO設定KPI

1. **リスト収集速度**: 50 → 100ユーザー/日（新規ユーザー登録数）
2. **コンバージョン率**: Phase 1期待効果から 2% → 3%（VSL1無料登録からVSL2有料購入への転換）

### 計算式

```
1日あたり成約ユーザー数 = リスト収集速度 × コンバージョン率
```

---

## 📈 シナリオ別計算

### シナリオ1: 現状（Phase 1実装前）

- **リスト収集速度**: 50ユーザー/日
- **コンバージョン率**: 2%
- **1日あたり成約ユーザー数**: 50 × 0.02 = **1.0ユーザー/日**
- **週間成約ユーザー数**: 1.0 × 7 = **7ユーザー/週**
- **月間成約ユーザー数**: 1.0 × 30 = **30ユーザー/月**

---

### シナリオ2: 目標（Phase 1-3実装後）

- **リスト収集速度**: 100ユーザー/日
- **コンバージョン率**: 3%
- **1日あたり成約ユーザー数**: 100 × 0.03 = **3.0ユーザー/日**
- **週間成約ユーザー数**: 3.0 × 7 = **21ユーザー/週**
- **月間成約ユーザー数**: 3.0 × 30 = **90ユーザー/月**

---

### シナリオ3: 最適化後（Gemini最適化 + A/Bテスト効果）

**前提**:
- リスト収集速度: 100ユーザー/日（維持）
- コンバージョン率: 3% → 4%（Gemini最適化 + A/Bテストで+1%向上）

- **1日あたり成約ユーザー数**: 100 × 0.04 = **4.0ユーザー/日**
- **週間成約ユーザー数**: 4.0 × 7 = **28ユーザー/週**
- **月間成約ユーザー数**: 4.0 × 30 = **120ユーザー/月**

## 💰 収益への影響

### ARPU（顧客あたり平均収益）の想定

**実際のプラン価格**（SSOTより）:
- **EN**: 月額$147 / 3ヶ月$397 / 年間$997
- **ES/PT-BR/KO/JA**: 月額$117 / 3ヶ月$317 / 年間$797
- **AR**: 月額$97 / 3ヶ月$267 / 年間$597

**プラン分散**（Alt Bundle効果後）:
- 月額: 21.4%
- 3ヶ月: 35.7%
- 年間: 42.9%

**ENのARPU計算**:
```
月額: 0.214 × $147 = $31.458
3ヶ月: 0.357 × $397 = $141.729
年間: 0.429 × $997 = $427.713
ARPU(EN) = $600.9
```

**ES/PT-BR/KO/JAのARPU計算**:
```
月額: 0.214 × $117 = $25.038
3ヶ月: 0.357 × $317 = $113.169
年間: 0.429 × $797 = $341.313
ARPU = $479.5
```

**ARのARPU計算**:
```
月額: 0.214 × $97 = $20.758
3ヶ月: 0.357 × $267 = $95.319
年間: 0.429 × $597 = $256.113
ARPU = $372.2
```

**言語別配分**:
- EN: 55%
- ES: 20%
- PT-BR: 12%
- JA: 8%
- KO: 3%
- AR: 2%

**加重平均ARPU**:
```
ARPU = (0.55 × $600.9) + (0.20 × $479.5) + (0.12 × $479.5) + (0.08 × $479.5) + (0.03 × $479.5) + (0.02 × $372.2)
ARPU = $330.5 + $95.9 + $57.5 + $38.4 + $14.4 + $7.4
ARPU = $544.1
```

**注意**: この$544.1は、プラン分散（月額21.4%、3ヶ月35.7%、年間42.9%）を考慮した**1ユーザーあたりの平均購入金額**です。

**実際のプラン価格**（EN市場）:
- 月額: $147（約2.2万円）
- 3ヶ月: $397（約6.0万円）
- 年間: $997（約15.0万円）

**プラン分散の前提**:
- 月額: 21.4% → 平均$31.5
- 3ヶ月: 35.7% → 平均$141.7
- 年間: 42.9% → 平均$427.7
- **合計ARPU**: $600.9

年間プランの選択率が42.9%と高いため、平均が$544.1（約8.16万円）になっています。

**注意**: この42.9%という前提は、SSOTに記載されている「Alt Bundle限定予約販売効果（年間プランCVR×3）」に基づいています。詳細な検証が必要です（`docs/PLAN_DISTRIBUTION_VERIFICATION.md`参照）。

**参考: 他のプラン分散シナリオ**

**もし3ヶ月プランのみの場合**:

```
ARPU = $44.1 + $198.5 + $199.4

```

**元のWhopデータ前提での月間収益**:
- 月間成約ユーザー数: 90ユーザー
- 月間売上: 90 × $442.0 = **$39,780**（約597万円）
