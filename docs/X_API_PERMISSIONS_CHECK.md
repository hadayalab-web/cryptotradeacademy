## ⚠️ 現在のエラー

```
403 - "Your client app is not configured with the appropriate oauth1 app permissions for this endpoint."
```

**原因**: Developer Portalでのアプリ権限設定が正しく反映されていない可能性があります。

---

## ✅ Developer Portalでの確認手順

### Step 1: アプリの認証設定を開く

1. X Developer Portalにログイン
2. プロジェクトを選択
3. アプリを選択
4. 「認証設定」または「Authentication Settings」を開く

### Step 2: アプリの権限（必須）を確認

**現在の設定を確認**:
- ❌ 「読む (Read)」が選択されている → **変更が必要**
- ✅ 「読み取りと書き込み (Read and Write)」が選択されている → **正しい**

**変更方法**:
1. 「読み取りと書き込み (Read and Write)」のオプションをクリック
2. 「投稿とプロフィール情報を読み取りおよび投稿する」が選択されていることを確認

### Step 3: アプリの種類（必須）を確認

**現在の設定を確認**:
- ❌ 「ネイティブアプリ (Native App)」が選択されている → **変更が必要**
- ✅ 「ウェブアプリ、自動化アプリまたはボット (Web App, Automated App, or Bot)」が選択されている → **正しい**

**変更方法**:
1. 「ウェブアプリ、自動化アプリまたはボット」のオプションをクリック
2. 「機密クライアント」が選択されていることを確認

### Step 4: 設定を保存

1. すべての設定を確認
2. **「変更を保存する」ボタンをクリック**
3. 保存が完了するまで待機

### Step 5: 設定反映を待機

- 設定変更後、**5〜10分待ってから**再テスト
- それでもエラーが出る場合、**1時間待ってから**再テスト

## 🔍 追加の確認事項

### 1. アプリの状態確認

Developer Portalで以下を確認：
- アプリが「Active」状態であること
- アプリが「Suspended」や「Revoked」状態でないこと

### 2. キーとトークンの確認

以下のキーとトークンが正しく設定されているか確認：
- `X_API_CONSUMER_KEY` ✅ 設定済み
- `X_API_CONSUMER_KEY_SECRET` ✅ 設定済み
- `X_API_ACCESS_TOKEN` ✅ 設定済み
- `X_API_ACCESS_TOKEN_SECRET` ✅ 設定済み

### 3. プランの確認

- ✅ 従量課金プランに変更済み
- ✅ 残高$5.00を確認
- ✅ 支出上限が「無制限」に設定されている
