## 2. インフルエンサー選択戦略

### 言語別の最適化
#### 言語特性を活かしたターゲット設定
- **英語（EN）**: 最大のインプレッションを誇り、幅広いターゲット層にリーチ可能。主要市場として重点配分。
- **日本語（JA）**: 平均ERが最高（12.5%）で、コンバージョン率が高い可能性あり。質を重視し、エンゲージメント率トップ層に集中。
- **韓国語（KO）**: 平均ERは最低だが、購買力が高い。質よりもリーチを重視。
- **スペイン語（ES）、ポルトガル語（PT-BR）、アラビア語（AR）**: 高いエンゲージメント率を活かし、地域密着型の訴求を行う。

#### インフルエンサー選定基準
- **エンゲージメント率（ER）**: 最低10%以上を基準とし、特に高ER（12%以上）を優先。
- **フォロワー数**: 10万～50万人を最適とし、大規模すぎてエンゲージメントが低いインフルエンサーは除外。
- **トピック適合性**: 暗号資産や金融専門のインフルエンサーを優先。
- **過去のCVR実績**: クリックや購買行動を促進できるインフルエンサー（事例データがある場合）。

#### フィルタリングロジック
```javascript
const highCVRInfluencers = influencers.filter(inf => {
  return inf.engagementRate >= 10 && 
         inf.followers >= 100000 && 
         inf.followers <= 500000;
});
```

## 3. コンテンツ戦略

### CTA設計
- **短期的CTA**: 「無料レポートをTelegramで受け取る」「5分で始めるBTC学習」など、行動を促進する具体的な利益を提示。
- **中長期的CTA**: 「限定版投資ガイド」「次回セッションへの招待」など、継続的な関与を促す。

### 心理的トリガー
- **希少性**: 「今だけ限定アクセス」「最初の100人に特典プレゼント」。
- **社会的証明**: 「すでに5,000人以上が利用中」「ユーザー満足度98%」。
- **緊急性**: 「本日限定の特別オファー」「残り時間：3時間」。

### ファネル設計
1. **X投稿**: 短いメッセージで疑問を投げかけ、興味を喚起。
2. **Telegram流入**: 誘導先で詳細を解説（例：無料レポート、コミュニティ参加）。
3. **Whopコンバージョン**: 限定オファーや追加特典で有料プランへの誘導。

### ソーシャルプルーフ活用
- **実績の可視化**: 「過去1週間で800人が参加」「コミュニティのBTCホルダー累計が10万BTC」。
- **レビュー表示**: 他ユーザーの成功体験やコメントを引用。
