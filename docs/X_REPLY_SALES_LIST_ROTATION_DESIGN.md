# Xリプライ直販 リスト取得 6言語ローテ設計

## 前提

- X API `GET /2/tweets/search/recent`: **300 リクエスト / 15分**（Per User）
- 1リクエスト = 1ページ（max_results 最大100件）
- 15分で300ページ使い切る = **1 Run で 1 言語のみ**（300ページ = 300リクエスト）

## 設計

### ローテーション

- **Cron**: 15分ごとに 1 回リスト取得（`*/15 * * * *`）
- **言語選択**: 15分スロット番号で 6 言語を順番に回す
  - スロット: UTC で `slotIndex = hour * 4 + floor(minute / 15)`（1日 96 スロット）
  - 言語: `langIndex = slotIndex % 6` → `LANGS[langIndex]`
  - 順序: `["en", "ar", "es", "pt", "ja", "ko"]`
- **1 Run あたり**: その 1 言語に対して **最大 300 ページ**取得、キューは **1 言語あたり 10 件キャップ**

### 例（UTC）

| 時刻 (UTC) | スロット | 言語 |
|------------|----------|------|
| 00:00 | 0 | en |
| 00:15 | 1 | ar |
| 00:30 | 2 | es |
| 00:45 | 3 | pt |
| 01:00 | 4 | ja |
| 01:15 | 5 | ko |
| 01:30 | 6 | en |
| ... | ... | ... |

→ **90 分で全 6 言語が 1 回ずつ**回る。

### 設定値

| 項目 | 値 | 説明 |
|------|-----|------|
| `X_REPLY_LIST_PAGES` | 450 | 1 Run あたり最大ページ数（API 制限いっぱい） |
| `X_REPLY_QUEUE_CAP_PER_LANG` | 10 | 1 言語あたりキュー保存上限 |

### エンドポイント

- **Cron 用**: `GET /api/x-reply-sales-list?mode=list&scope=rotate`（CRON_SECRET 必須）
- **手動で 1 言語**: `?mode=list&lang=ja` など
- 旧 `en-list` / `regions-list` は **cron からは外し**、手動・互換用として残す（`/api/x-reply-sales-en-list`, `/api/x-reply-sales-regions-list`）

### 時間窓

- EN: 60 分（従来どおり）
- 他言語: 300 分（従来どおり）
- ローテで 90 分に 1 回ずつなので、各言語は 90 分間隔でリスト更新される。

### 送信側

- 送信は従来どおり `*/15 * * * *` で 15 分ごと。キューは 6 言語分が KV に乗っているので、送信 Run では全言語キューから FIFO で取り出してリプライ/DM。

*実装: scope=rotate で targets を上記ロジックで 1 言語に決める。config で 300 ページ・10 キャップ。*
