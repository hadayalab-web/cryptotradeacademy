# 最新ログ分析ガイド

**作成日時**: 2026-01-23T08:45:00.000Z

## ⚠️ Vercelログの遅延について

Vercelのログは遅れて表示されることがあります。そのため、古いログを分析している可能性があります。

## 🔍 最新ログを確実に取得する方法

### 方法1: タイムスタンプでフィルタリング

1. Vercelダッシュボードからログをエクスポート
2. エクスポート時に「最新30分」または「最新1時間」を選択
3. デプロイ時刻以降のログのみを取得

### 方法2: 最新ログ分析スクリプトを使用

```bash
node scripts/analyze-latest-logs.js
```

このスクリプトは：
- 最新100件のログを分析
- または過去30分以内のログを分析
- デプロイ後のログを自動的に識別

### 方法3: 手動でタイムスタンプを確認

1. ログファイルを開く
2. 各ログの`TimeUTC`または`timestampInMs`を確認
3. デプロイ時刻以降のログのみを分析

## 📋 デプロイ後のテスト手順（改訂版）

### ステップ1: デプロイ確認
- [ ] Vercelダッシュボードでデプロイ完了を確認
- [ ] **デプロイ時刻を記録**（重要！）

### ステップ2: 少し待つ
- [ ] デプロイ完了後、**5-10分待つ**（ログの反映を待つ）

### ステップ3: 16個のCron Jobsを順次実行
- [ ] デプロイ時刻**以降**に実行する
- [ ] 各実行のタイムスタンプを確認

### ステップ4: ログ取得
- [ ] Vercelダッシュボードからログをエクスポート
- [ ] **デプロイ時刻以降のログのみ**を取得
- [ ] `logs_result.json`として保存

### ステップ5: 最新ログ分析
```bash
node scripts/analyze-latest-logs.js
```

## 🎯 エラー率0%達成の確認方法

### 確認項目

1. **x-quote-repost**: エラー率 0%
2. **lead-discovery**: エラー率 0%（403エラーはスキップとして扱う）
3. **最新ログのタイムスタンプ**: デプロイ時刻以降

### 成功の証拠

- ✅ リード取得のメール報告が流れてくる
- ✅ 最新ログでエラーが0件
- ✅ 403エラーがスキップとして扱われている

## 💡 推奨事項

1. **デプロイ時刻を記録**: デプロイ完了時刻を必ず記録する
2. **ログ取得前に待つ**: デプロイ後5-10分待ってからログを取得
3. **タイムスタンプでフィルタリング**: デプロイ時刻以降のログのみを分析
4. **最新ログ分析スクリプトを使用**: 自動的に最新ログを識別

---

**重要**: 古いログを分析すると、修正前のエラーが表示される可能性があります。必ず最新ログを確認してください。
