## 実証日
2026-01-07

## 目的
CryptoQuant API（Exchange Netflow、MPI、NUPL、SOPR）とX（Twitter）のリアルタイム解析を組み合わせて、トレンド転換のタイムラグを捉えるアルゴリズムを、Grok、GPT、Geminiそれぞれで生成し、最も正確で実用的なものを特定する。

3. **80%勝率達成**: SELL/SHORTシグナルの精度
4. **コード品質**: 保守性、拡張性、パフォーマンス
5. **理論的正確性**: 金融市場の理論に基づいているか

## 実装の課題と解決策

### 課題1: 時系列データの蓄積
**問題**: 現在の`api/cron.js`は各実行が独立しており、時系列データを保持しない

**解決策**:
- 外部ストレージ（Redis、データベース）に時系列データを保存
- または、`TrendReversalDetector`インスタンスをグローバルに保持（サーバーレス環境では制約あり）

### 課題2: リソース消費
**問題**: GPT提案のアルゴリズムは計算コストが高い

**解決策**:
- リード/ラグ推定を間引き（例: 1時間ごと）
- ウィンドウサイズを調整（240 → 120など）

### 課題3: 既存ロジックとの統合
**問題**: 既存の`decideSignal`と新しい`TrendReversalDetector`をどう統合するか

**解決策**:
- ハイブリッドアプローチ: 両方の結果を組み合わせ
- または、段階的に移行（A/Bテスト）
