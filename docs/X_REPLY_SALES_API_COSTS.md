# Xリプライ直販 関連API単価（参照用）

X Developer の料金表に基づく。実際の請求は利用量・税率等で変動する。

## リスト取得で使うもの

| リソース | 課金単位 | 単価 | 当システムでの発生箇所 |
|----------|----------|------|------------------------|
| **投稿: 読み取り** | 取得したリソースごと | $0.005 / リソース | 検索で返るツイート数（max_results × ページ数） |
| **ユーザー: 読み取り** | 取得したリソースごと | $0.010 / リソース | expansions=author_id で取得するユーザー数（投稿と同数程度） |

- 1言語1回で 5ページ×100件 = 最大 500投稿 + 500ユーザー  
  → 投稿 $2.50 + ユーザー $5.00 = **最大 $7.50/回**（実際はヒット数に応じて変動）
- 44回/日 × 実取得リソース数で日次コストが決まる

## 送信で使うもの

| リソース | 課金単位 | 単価 | 当システムでの発生箇所 |
|----------|----------|------|------------------------|
| **コンテンツ: 作成** | リクエストごと | $0.010 / リクエスト | リプライ投稿（POST /2/tweets）1回 = 1リクエスト |

- **課金は「作成成功時のみ」**。403（reply not allowed）や 404 等で失敗した場合はツイートが作成されないため、Content Create ・クレジット消費は発生しない（試行回数だけでは増えない）。
- 1リプライ成功 = $0.010  
- 1440発/日キャパなら最大 **約 $14.40/日**（実際は送信成功数に応じて変動）

## 使っていないが一覧で出てくる主な項目

- DMイベント: 読み取り $0.010/リソース
- DMインタラクション: 作成 $0.015/リクエスト
- ユーザーインタラクション: 作成 $0.015/リクエスト
- リスト: 読み取り $0.005/リソース（検索結果の「投稿」とは別）
- その他（スペース、コミュニティ、ノート、トレンド等）: リプライ直販では未使用
