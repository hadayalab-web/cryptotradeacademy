# Vercelログ取得頻度ガイド - 2026-01-21
**作成日時**: 2026-01-21  
**目的**: Vercel DashboardからJSONログをエクスポートする最適な頻度

---

## 📅 システム実行頻度

### リード発見システム

- **`/api/lead-discovery`**: **2時間ごと**（0時、2時、4時、6時、8時、10時、12時、14時、16時、18時、20時、22時 UTC）
  - **1日12回実行**
  - **リード発見の主要エンドポイント**

- **`/api/lead-discovery/process`**: **5分ごと**
  - **1日288回実行**
  - **キューに溜まったリードを処理**

- **`/api/lead-discovery-daily-report`**: **毎日9時（UTC）**
  - **CEOレポート自動送信**

- **`/api/lead-discovery-weekly-report`**: **毎週月曜9時（UTC）**
  - **週次レポート自動送信**

### VSLワークフロー

- **`/api/vsl1-post`**: **1日2回**（9時、21時 UTC）
- **`/api/vsl2-free-users`**: **1時間ごと**
- **`/api/vsl1-reminder`**: **12時間ごと**
- **`/api/vsl2-last-call`**: **1時間ごと**

## 🎯 推奨取得頻度

### 1. **日次取得（推奨）** ✅

**頻度**: **1日1回**

**推奨時刻**: 
- **毎日9時（UTC）** = **18時（JST）**
- CEOレポート送信時刻と合わせる

**取得期間**: **過去24時間**

**理由**:
- CEOレポートと同時に確認できる
- 1日分のデータで十分な分析が可能
- リード発見は2時間ごとなので、1日12回分のデータが含まれる

**分析内容**:
- 日次リード発見数（目標: 200-300件/日）
- 日次VSL1送信数（目標: 60-90件/日）
- 日次エラー数
- CVR（目標: 30%）

---

### 2. **週次取得（推奨）** ✅

**頻度**: **1週間1回**

**推奨時刻**: 
- **毎週月曜9時（UTC）** = **月曜18時（JST）**
- 週次レポート送信時刻と合わせる

**取得期間**: **過去7日間**

**理由**:
- 週次レポートと同時に確認できる
- 週次トレンドを把握できる
- 1週間分のデータで十分な分析が可能

**分析内容**:
- 週次リード発見数（目標: 1,400-2,100件/週）
- 週次VSL1送信数（目標: 420-630件/週）
- 週次エラー数
- 週次CVR
- 言語別パフォーマンス
- 時間別パフォーマンス

---

### 3. **問題発生時（随時）** ⚠️

**頻度**: **必要に応じて**

**取得タイミング**:
- CEOレポートで異常値が検出された時
- Vercel Dashboardでエラーが増加している時
- リード発見数が急激に減少した時

**取得期間**: **問題発生時点から過去24時間**

**理由**:
- 問題の原因を特定するため
- エラーの詳細を分析するため

## 💡 推奨ワークフロー

### 日常運用

1. **毎日18時（JST）**: 
   - CEOレポートを確認
   - 必要に応じてVercelログをエクスポート（過去24時間）
   - 異常値があれば分析

2. **毎週月曜18時（JST）**:
   - 週次レポートを確認
   - Vercelログをエクスポート（過去7日間）
   - 週次トレンドを分析

3. **問題発生時**:
   - 即座にVercelログをエクスポート（過去24時間）
   - エラー分析を実施
   - 問題の原因を特定

## 🎯 最適な取得頻度の結論

### **推奨: 日次取得（1日1回）**

**理由**:
1. **リード発見は2時間ごと**: 1日12回実行されるため、日次取得で十分なデータが得られる
2. **CEOレポートと同期**: 毎日9時（UTC）にCEOレポートが送信されるため、同時にログを取得できる
3. **分析効率**: 1日分のデータで十分な分析が可能
4. **コスト効率**: 過度な取得は不要

### **追加: 週次取得（1週間1回）**

**理由**:
1. **週次トレンドの把握**: 1週間分のデータでトレンドを分析できる
2. **週次レポートと同期**: 毎週月曜9時（UTC）に週次レポートが送信されるため、同時にログを取得できる

## 📝 取得時の設定

### Vercel Dashboardでの設定

1. **Timeline**: 「Last day」（日次）または「Last 7 days」（週次）
2. **Filter**: `/api/lead-discovery`でフィルタリング（オプション）
3. **Export**: 「Export to JSON」をクリック

### 取得するログの種類

- ✅ **リード発見関連**: `/api/lead-discovery`、`/api/lead-discovery/process`
- ✅ **VSLワークフロー関連**: `/api/vsl1-post`、`/api/vsl2-free-users`など
- ✅ **エラー関連**: すべてのエンドポイントのエラーログ
