### 1. 無料版レポートX投稿（新規）

**エンドポイント**: `api/x-post-free-report.js`

**実装内容**:
- 無料版レポート配信後に自動実行
- 6言語のMinimal版レポートをXに投稿
- スレッド化投稿または時間分散
- Grokが各言語の最適タイミングを判断

**投稿内容**:
```
🚨 BREAKING: BTC Trap Score 25/100

Very low trap risk detected ✅

💰 BTC: $89,859 (-0.02%)

💡 Market is stable, but stay vigilant

Get FREE trap defense report 👇
t.me/TrapDefenceBot?start=minimal_en_x

#BTC #CryptoTrading #TrapDefence
```

**実装方法**:
```javascript
// api/x-post-free-report.js
async function postFreeReportToX() {
  const targetLangs = ['en', 'es', 'pt-br', 'ar', 'ja', 'ko'];
  
  // スレッド化投稿または時間分散
  const useThread = parseBoolean(process.env.X_FREE_REPORT_USE_THREAD, true);
  
  if (useThread) {
    // スレッド化投稿（1投稿 + 5スレッド）
    await postFreeReportAsThread(targetLangs);
  } else {
    // 時間分散投稿（各言語のピーク時間帯に順次投稿）
    await postFreeReportTimeDispersed(targetLangs);
  }
}
```

### 3. 引用リポスト（新規）

**エンドポイント**: `api/x-quote-repost.js`

**実装内容**:
- Grokがインフルエンサーを発掘
- 各言語のホットインフルエンサーに引用リポスト
- 24投稿/日（6言語 × 2人 × 2投稿）
- Grokがインプレッション最大化の文章を生成

**実装方法**:
```javascript
// api/x-quote-repost.js
async function postQuoteReposts() {
  const targetLangs = ['en', 'es', 'pt-br', 'ar', 'ja', 'ko'];
  
  for (const lang of targetLangs) {
    // Grokがインフルエンサーを発掘
    const influencers = await discoverInfluencers(lang);
    
    // 各インフルエンサーに引用リポスト
    for (const influencer of influencers.slice(0, 2)) {
      const quoteText = await generateQuoteRepostText(lang, influencer);
      await postQuoteTweet(influencer.tweetId, quoteText);
    }
  }
}
```

## 📊 投稿スケジュール

### 無料版レポートX投稿

**タイミング**: 無料版レポート配信後（UTC 6時、18時など）

**方法1: スレッド化投稿（推奨）**
- メイン投稿（英語）→ スレッドで5言語を追加
- 1/6, 2/6, 3/6, 4/6, 5/6, 6/6の形式
- 各スレッドに言語別のCTAとDeep Link

**方法2: 時間分散投稿**
- 各言語のピーク時間帯に順次投稿
- 1時間に1投稿（6時間で完了）
- Grokが各言語の最適タイミングを判断

**頻度**: 1日2回

**内容**: VSL1 YouTubeリンク + Deep Link

**頻度**: 24投稿/日（1時間に1投稿）
