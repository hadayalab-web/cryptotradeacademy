## 3. 現時点の固定方針

- 読者は WarriorPlus アフィリエイター
- 目的は募集ページではなく「参加後に売りまくるための実戦ガイド」
- 主力商品は `Regular`
- `Minimal` はリードマグネット
- `KIBA` は `Regular` 内の paid-only value layer
- 基本言語は英語
- 一部アセットは `EN / ES / PT / AR / KO / JA` に対応
- `50% recurring` は主訴求に使う
- `DEFEND50` は廃止済みのため本文では使わない

---

## 4. WarriorPlus 版への変換ルール

既存資料には `FirstPromoter`、`Whop`、`DEFEND50` 前提のものが多い。
それらは「素材」であり、完成原稿にはそのまま貼らない。

### 必ず適用する変換

- `DEFEND50` を削除
- クーポン前提のクロージングを削除
- `ref link + DEFEND50` を WarriorPlus 前提の導線説明に置換
- `FirstPromoter signup` 文脈を WarriorPlus affiliate 文脈へ変換
- `Whop 直販` の空気を削り、現在の WarriorPlus 決済フローに合わせる
- 投資助言に見える表現を避ける
- 保証表現や未検証の強い数字を避ける
