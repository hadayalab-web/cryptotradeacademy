## ④ アフィリエイター向け：動画の作り方ガイド

| 項目 | 内容 |
|------|------|
| **長さ** | 25〜35秒が最も伸びる |
| **フック** | 最初の1秒で「え？」と思わせる |
| **声のトーン** | 落ち着いて、淡々と事実を語る |
| **映像素材** | チャート / クジラの影 / 損失の赤画面 / 家族と夕食 / 罠のメタファー |
| **テロップ** | 白字＋黒縁、1行ずつ、1秒に1行 |
| **CTA** | 「無料で受け取る」「罠にかからないために」「Telegramはこちら」 |
| **投稿頻度** | 1日1本でOK。ザイオンス効果で信頼が積み上がる |
