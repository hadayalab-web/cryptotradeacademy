## 📋 Geminiからの主要アドバイス

### 1. **視覚的階層構造**
- **最重要シグナルを最上位**: トレードシグナルを冒頭に配置
- **USPをハイライトセクション**: 3つのUSPを1つのセクションに集約
- **視覚的区切り**: `---`、絵文字、太字（`*text*`）を活用

### 2. **情報量の最適化**
- 詳細情報はリンクで誘導
- 各セクションは要点のみ（3-5行以内）
- 全体的な行数を40行以内に削減

### 3. **USPの明確な強調**
- USP1/USP2/USP3を1つの「ハイライトセクション」に統合
- 各USPを簡潔に説明（1-2行）

---

## 🎯 改善後のメッセージ構造（提案）

```
1. ヘッダー（2行）
   📚 Dr. Grok Market Leak
   セッションブリーフィング @ タイムスタンプ

2. 【最重要】トレード・ヴァーディクト（6行）
   🎯 トレード・ヴァーディクト
   🟢/🔴/🛡️ シグナル: BUY/SELL/STANDBY
   • エントリー、TP、SL、RR

3. 【USPハイライト】3つの独自機能（8-10行）
   ✨ 本日のハイライト (3つのUSP)
   🐛 USP1: 市場バグ検知 → 簡潔な説明
   🎬 USP2: Gemini画像・動画 → 添付をチェック
   💊 USP3: 心理診断 → 簡潔な説明

4. 基本市場データ（5行）
   💰 BTC価格、フロー、MPI、センチメント

5. リスク情報（統合、最大5行）
   🚨/⚠️ 統合リスクアラート（Trap Risk + NO TRADE）

6. Exit Map（簡略化、最大8行）
   🗺️ エグジットマップ（主要情報のみ）

7. Dr. Grokの見立て（3行 + 要約版）
   🧬 分析要約（500文字以内）
```
