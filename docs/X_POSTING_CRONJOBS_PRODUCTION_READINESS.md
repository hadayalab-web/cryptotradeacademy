### Step 2: 本番環境移行（ドライランテスト完了後）

#### 2.1 環境変数の変更

**Vercel Dashboard** → **Project Settings** → **Environment Variables**

**変更内容**:
```
X_POSTING_DRY_RUN=false  （true → false に変更）
```

**重要**: 
- この変更により、実際にXに投稿が開始されます
- 変更後、再デプロイが必要な場合があります

---

#### 2.2 再デプロイ（必要に応じて）

**Vercel Dashboard** → **Deployments** → **Redeploy**

または、新しいコミットをプッシュして自動デプロイ

---

### Step 3: 本番環境での実行開始

**自動実行**:
- Cron設定により、自動的に実行されます
- 各言語のピーク時間帯に投稿が開始されます

**手動実行（テスト用）**:
```bash
# force=trueで時間帯チェックをスキップしてテスト実行
curl -X GET "https://cryptotradeacademy.vercel.app/api/x-quote-repost-en?force=true" \
  -H "Authorization: Bearer YOUR_CRON_SECRET"
```

## ⚠️ 注意事項

### 1. ドライランモードの解除

**重要**: `X_POSTING_DRY_RUN=false`に変更しない限り、実際の投稿は行われません。

**確認方法**:
- Vercel Dashboardで環境変数を確認
- ログに「🧪 X dry-run enabled」が表示されていないことを確認

---

### 2. 初回実行の監視

**推奨**:
- 初回実行時はVercel Dashboardのログをリアルタイムで監視
- エラーが発生した場合は即座に対応

---

### 3. インプレッション数の確認

**確認方法**:
- X Analyticsでインプレッション数を確認
- 期待値: 300-1,050万インプレッション/日

**注意**:
- インプレッション数は投稿後1-2時間で反映される
- 初日は完全な数値が得られない可能性がある

---

### 4. コンバージョン率の確認

**確認方法**:
- Whop Dashboardで新規ユーザー数を確認
- UTMパラメータ（`?promo=DEFEND50`）でトラッキング

**注意**:
- コンバージョン率は数日〜数週間かけて安定する
- 初日は完全な数値が得られない可能性がある
