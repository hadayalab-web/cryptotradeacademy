# 戦略：思考停止・依存症トレーダーに特効薬を渇望させる

## 方針

- **ペルソナ**: 思考停止中のトレード依存症／中毒のトレーダー。
- **ゴール**: 彼らに我々の**特効薬（プログラム＝Minimal / Regular Briefing）**を渇望させる。
- **手段**: 無料版（Minimal Version）・有料版（Regular Briefing）の TG 定期配信を含め、メッセージ・訴求・CTA を**さらに彼らに寄せる**。

## 後続アクション

- **ユーザー**: 最新の Minimal / Regular の TG 定期配信を共有する（後ほど）。
- **実装側**: 共有いただいた配信を、
  - 思考停止・依存症の心理（無力感・「誰かに従いたい」・判断委譲・特効薬願望）に合わせて読み解く。
  - 特効薬として「渇望」させる観点で、TG 文面・X 投稿・CTA・ファネルを最適化する。
