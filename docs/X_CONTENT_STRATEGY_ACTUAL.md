## 🎯 実際の戦略

### ✅ 採用されている戦略

#### 1. **テキストベースのコンテンツ**（自動化コンテンツ生成を廃止）

**理由**:
- NanoBananaとVeoが生成する素材の精度が不安定
- コンテンツ生成は自動化させない戦略に切り替え

**実装状況**:
- 動画・画像の自動生成は実装されているが、実際には使用されていない
- `getContentFormat`関数で定義されている動画30%、ポール30%、画像20%の配分は**冗長**（実際には機能していない）

#### 2. **トレード依存症のトレーダーをターゲットにする訴求力強化**（核心戦略）

**実装されている機能**:

**メンタルブロック検出**:
- `ALWAYS_TRADING`: 「常に取引する必要がある」という思い込み
- `WAITING_IS_WEAKNESS`: 「待つことは弱さ」という思い込み
- `FOMO`: 取り逃しの恐怖
- `FEAR`: 過度な恐怖
- `GREED`: 極端な強欲

**心理的サポート機能**:
- Dr. Grokによる心理分析
- メンタルブロックの検出と除去アドバイス
- コーチングメッセージの提供

**実装コード例** (`services/grok/psychologicalSupport.js`):
```javascript
// ALWAYS_TRADINGブロック検出

  });
```

### 心理的訴求力の強化要素

#### 1. **メンタルブロック検出に基づくコンテンツ**

**ALWAYS_TRADING検出時**:
- 「70%の時間は何もしない。これが最強の戦略。」
- 「待つ勇気が、真のトレーダーの証。」
- 「明確な優位性が出るまで待つ。」

**WAITING_IS_WEAKNESS検出時**:
- 「待つことは弱さではない。最強の戦略である。」
- 「待つ勇気が、真のトレーダーの証。」

**FOMO検出時**:
- 「FOMOがピーク。多くのトレーダーが罠にハマる。」
- 「極端なFOMOは、貧しいエントリーポイントにつながる。」

#### 2. **センチメント連動コンテンツ生成**

**バリアント選択ロジック** (`services/x/vsl1-strategy.js`):
- `retailFomo >= 70` → FOMOバリアント
- `whaleBias <= -50` → Whale Warningバリアント
- `mentalBlocks.includes('FEAR')` → Fearバリアント
- `mentalBlocks.includes('ALWAYS_TRADING')` → トレード依存症向けメッセージ

**実装例**:
```javascript
function selectVsl1Variant(sentiment) {
  if (normalized.retailFomo >= 70) {
    return { variant: 'fomo', reason: 'retailFomo>=70' };
  }
  if (normalized.whaleBias <= -50) {
    return { variant: 'whale_warning', reason: 'whaleBias<=-50' };
  }
  if (normalized.mentalBlocks.includes('FEAR')) {
    return { variant: 'fear', reason: 'mentalBlock=FEAR' };
  }
  // ALWAYS_TRADING検出時はneutralバリアントで「待つ勇気」メッセージ
  return { variant: 'neutral', reason: 'default' };
}
```

#### 3. **コーチングメッセージの統合**

**Grok分析結果の活用**:
- `coachingAdvice`: メンタルブロック除去のためのコーチングアドバイス
- `psychologicalPattern`: 典型的なトレーダーの心理的パターンの説明
- `mentalBlocks`: 検出されたメンタルブロックのリスト

### 1. **テキストベースの利点**

- **精度の安定性**: 自動生成コンテンツの精度不安定を回避
- **メッセージの一貫性**: 心理的訴求力が一貫している
- **コスト効率**: 動画・画像生成のコストが不要

### 2. **心理的訴求力強化の効果**

- **メンタルブロック検出**: リアルタイムで心理状態を分析

### 3. **センチメント連動の効果**
