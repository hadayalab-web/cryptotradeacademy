# Chapter 11 - Six-Language Fast Pack

This chapter is not a full translation of the entire guidebook.

It is a fast multilingual utility pack for affiliates who want to move quickly across the six active language lanes:

- EN
- ES
- PT
- AR
- KO
- JA

The goal is simple:

give affiliates short, clean, reusable blocks they can copy into posts, replies, DMs, bios, and light bridge copy without rebuilding the message from scratch every time.

---

## 1. How to Use This Chapter

Use this chapter when you need:

- a fast hook
- a short post
- a clean `Minimal` CTA
- a warm transition into the paid offer
- a short explanation of `KIBA`
- a safe optional disclaimer line

This chapter is for speed, not complexity.

If you need longer copy, use Chapter 09.

## 4. Default Routing Rule

Use the same routing logic in every language:

- cold traffic -> `Minimal`
- warm traffic -> `Minimal` or a short paid explanation
- hot traffic -> WarriorPlus affiliate link

Do not send cold traffic into a hard paid close by default.

**Delivery note:** Any language checkout delivers the full 6-language access pack by email. Use this line when a prospect asks what they get after buying.

## 11. Final Usage Notes

The best way to use this chapter is:

1. Pick one language lane.
2. Pick one block only.
3. Match the CTA to the audience temperature.
4. Do not mix sanitized copy with legacy coupon copy.
5. Keep the voice calm, clear, and defense-first.

This chapter is designed for repetition.

That means the copy should feel:

- short
- direct
- consistent
- easy to deploy

If you need more detail, move into Chapter 09.
