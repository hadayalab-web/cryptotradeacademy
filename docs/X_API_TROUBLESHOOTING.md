## 🔧 トラブルシューティング手順

### Step 1: Developer Portalの設定確認

1. X Developer Portalにログイン
2. アプリの「認証設定」を確認
3. 以下が設定されていることを確認：
   - ✅ 「読み取りと書き込み (Read and Write)」が選択されている
   - ✅ 「ウェブアプリ、自動化アプリまたはボット」が選択されている
   - ✅ 「変更を保存する」をクリック済み

### Step 2: プランの確認

1. X Developer Portalで「Billing」または「プラン」を確認
2. 現在のプランが**Free**の場合：
   - **Basicプラン（$200/月）**へのアップグレードを検討
   - Freeプランでは書き込みが制限されている可能性が高い

### Step 3: 設定反映の待機

- 設定変更後、**5〜10分待ってから**再テスト
- それでもエラーが出る場合、**1時間待ってから**再テスト

### Step 4: 再テスト

設定反映後、以下のコマンドで再テスト：

```bash
npm run test:x-post
```

## ⚠️ 注意事項

### Freeプランの制限

**無料プラン（Free）では**:
- 読み取り: 100 reads/月
- 書き込み: 500 posts/月

しかし、**ツイート投稿機能が制限されている可能性**があります。  
Basicプラン（$200/月）以上へのアップグレードを検討してください。

### Basicプランの制限

**Basicプラン（$200/月）では**:
- 読み取り: 15,000 reads/月
- 書き込み: 50,000 posts/月
- VSL1投稿頻度: 1日2回 = 月60回 → **十分対応可能**
