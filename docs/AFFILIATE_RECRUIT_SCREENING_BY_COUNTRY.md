Trap Defence リクルート用。国ごとに「泥臭さの基準」が違うため、**国別の最適フィルター**をまとめる。

## 第1層: EN / ES / PT / AR（現行6言語のうち4言語）

### 🇧🇷 PT（ブラジル）

世界最大級のアフィリエイト文化。行動量が高いので基準を少し上げる。

**必須条件**
- 過去7日 **15ポスト以上**
- 引用RT **7回以上**
- フォロワー **100〜5,000**（BR はフォロワー増えやすい）
- プロフィールに "Hotmart / afiliado / renda extra"

**優先**
- 動画投稿がある（ブラジルは動画文化が強い）

---

### 🇲🇽🇨🇴🇦🇷 ES（メキシコ・コロンビア・アルゼンチン）

ラテンは熱量は高いが継続力が弱い → **継続力の判定を強める**。

**必須条件**
- 過去7日10ポスト
- **いいね0でも投稿継続**
- プロフィールに "dinero / ingresos / afiliado / DM abierto"

**優先**
- 行動ログが多い
- 自己啓発が少ない（ラテンは自己啓発が多い）

---

### 🇺🇸🇬🇧 EN（アメリカ・イギリス）

英語圏は情報商材系・詐欺系も多い。**売り物がない人だけを狙う**。

**必須条件**
- **リンクなし**
- **プロモツイートなし**
- 過去7日10ポスト
- プロフィールに "affiliate / DM open / side hustle"

**除外**
- "coach / consultant / agency owner / mentor"
- 自己啓発ポストが多い

---

### 🇸🇦🇪🇬🇦🇪 AR（サウジ・エジプト・UAE）

SNS 熱量は高いが詐欺系も多い。**行動量＋誠実さ** を見る。

**必須条件**
- 過去7日10ポスト
- 引用RT 5回以上
- プロフィールに "affiliate / open DM / online income"

**優先**
- 自己啓発が少ない
- 行動ログがある（珍しいので強いシグナル）

### 3ブロック共通の「初心者ファイター抽出コア条件」


**本物の初心者ファイターの証拠（世界共通）**

## 実装メモ

- 現行リクルート対象言語: EN / ES / PT / AR / KO / JA（`config/affiliateRecruitConfig.js`）
- 国別条件をスコアリングに反映する場合は、`lang` に応じて閾値（ポスト数・引用RT数・フォロワー帯）を変える拡張が可能
- 第2層（PH/VN/IN/NG）は言語・検索クエリの追加が必要
- 第3層（アフリカ／ロシア／中東）: 除外キーワード（forex trader, crypto signals, MLM, guru）は `affiliateRecruitScoring.js` の `PROFILE_EXCLUDE_KEYWORDS` に追加済み。政治・宗教系はキーワードが多岐のため doc 参照で運用
- 第4層（SEA・LATAM）: PH/VN/ID/TH/MY と MX/CO/AR/BR の初心者ファイター向け条件は上記の通り。現行スコアリング（努力系キーワード・30–1500 ゾーン・リンクなしは URL 未取得時で間接評価）で共通コア条件の多くをカバー済み
