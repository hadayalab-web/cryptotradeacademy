# 国別・泥臭いアフィリエイター スクリーニング条件

Trap Defence リクルート用。国ごとに「泥臭さの基準」が違うため、**国別の最適フィルター**をまとめる。  
ベース: [AFFILIATE_RECRUIT_SCREENING_PRINCIPLES.md](./AFFILIATE_RECRUIT_SCREENING_PRINCIPLES.md)

---

## 第1層: EN / ES / PT / AR（現行6言語のうち4言語）

### 🇧🇷 PT（ブラジル）

世界最大級のアフィリエイト文化。行動量が高いので基準を少し上げる。

**必須条件**
- 過去7日 **15ポスト以上**
- 引用RT **7回以上**
- フォロワー **100〜5,000**（BR はフォロワー増えやすい）
- プロフィールに "Hotmart / afiliado / renda extra"

**優先**
- 動画投稿がある（ブラジルは動画文化が強い）

---

### 🇲🇽🇨🇴🇦🇷 ES（メキシコ・コロンビア・アルゼンチン）

ラテンは熱量は高いが継続力が弱い → **継続力の判定を強める**。

**必須条件**
- 過去7日10ポスト
- **いいね0でも投稿継続**
- プロフィールに "dinero / ingresos / afiliado / DM abierto"

**優先**
- 行動ログが多い
- 自己啓発が少ない（ラテンは自己啓発が多い）

---

### 🇺🇸🇬🇧 EN（アメリカ・イギリス）

英語圏は情報商材系・詐欺系も多い。**売り物がない人だけを狙う**。

**必須条件**
- **リンクなし**
- **プロモツイートなし**
- 過去7日10ポスト
- プロフィールに "affiliate / DM open / side hustle"

**除外**
- "coach / consultant / agency owner / mentor"
- 自己啓発ポストが多い

---

### 🇸🇦🇪🇬🇦🇪 AR（サウジ・エジプト・UAE）

SNS 熱量は高いが詐欺系も多い。**行動量＋誠実さ** を見る。

**必須条件**
- 過去7日10ポスト
- 引用RT 5回以上
- プロフィールに "affiliate / open DM / online income"

**優先**
- 自己啓発が少ない
- 行動ログがある（珍しいので強いシグナル）

---

## 第2層: PH / VN / IN / NG（拡張候補）

「人口が多い × SNS熱量が高い × 稼ぐ系文化が強い」第2層。国ごとに泥臭さの質が違う。

### 🇵🇭 フィリピン（PH）

| 項目 | 内容 |
|------|------|
| 特徴 | 英語堪能（EN と同じ DM で可）、SNS 依存度高、副業文化強い。「簡単に稼げる系」に流れやすい。 |
| **必須** | 過去7日10ポスト、引用RT 5回以上、プロフィールに "side hustle / extra income / affiliate / DM open"、フォロワー **50〜2,000**（PH は伸びにくい） |
| **優先** | 行動ログ、英語投稿（PH は英語/タガログ混在） |
| **除外** | "crypto signals" "forex guru" → 詐欺系多い |

---

### 🇻🇳 ベトナム（VN）

| 項目 | 内容 |
|------|------|
| 特徴 | SNS 熱量高い、英語弱い層多い、行動量はあるがアフィリエイト文化は浅い。泥臭さはアジアでトップクラス。 |
| **必須** | 過去7日10ポスト、英語投稿あり、プロフィールに "make money / affiliate / online income"、フォロワー **50〜1,500** |
| **優先** | 行動ログ多い、自己啓発少ない |
| **除外** | ベトナム語のみ（DM コミュニケーション難）、"dropshipping guru" |

---

### 🇮🇳 インド（IN）

| 項目 | 内容 |
|------|------|
| 特徴 | 世界最大級の SNS 人口、英語通じる、行動量高いが詐欺系・自己啓発系も多い。泥臭さは世界トップクラス。 |
| **必須** | 過去7日 **15ポスト**、引用RT **7回以上**、プロフィールに "hustle / grind / affiliate / DM open / side income"、フォロワー 100〜3,000 |
| **優先** | 行動ログ、英語投稿、自己啓発より実務系 |
| **除外** | "coach / mentor / guru"、自己啓発ポスト多い、"crypto signals" |

---

### 🇳🇬 ナイジェリア（NG）

| 項目 | 内容 |
|------|------|
| 特徴 | SNS 熱量異常に高い、英語通じる、行動量世界トップ。詐欺系・MLM 系が非常に多い。泥臭さは世界最強クラス。 |
| **必須** | 過去7日 **15ポスト**、引用RT **10回以上**、プロフィールに "affiliate / hustle / DM open / online income"、フォロワー 100〜2,500 |
| **優先** | 行動ログ、英語投稿、**プロモツイートなし**（詐欺系を避ける） |
| **除外** | "forex trader", "crypto signals", "MLM", "coach / mentor" |

## Trap Defence OS 観点での優先順位

1. **フィリピン（PH）** — 即戦力
2. **インド（IN）** — 即戦力
3. **ベトナム（VN）** — 泥臭さの宝庫
4. **ナイジェリア（NG）** — 当たれば爆発、外れれば地雷。スクリーニング厳しめ推奨

PH と IN は英語が通じる。VN は泥臭さが強い。NG は行動量最強だがリスク高。

## 実装メモ

- 現行リクルート対象言語: EN / ES / PT / AR / KO / JA（`config/affiliateRecruitConfig.js`）
- 国別条件をスコアリングに反映する場合は、`lang` に応じて閾値（ポスト数・引用RT数・フォロワー帯）を変える拡張が可能
- 第2層（PH/VN/IN/NG）は言語・検索クエリの追加が必要
