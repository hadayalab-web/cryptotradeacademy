## BRICS圏＋周辺に共通する「初心者ファイターの核」

### 共通の最強シグナル
- 過去7日で10ポスト以上
- 反応ゼロでも投稿継続
- 引用RT 3〜5回
- フォロワー30〜1500
- プロフィールに努力系ワード（learning / beginner / building / trying / side hustle / renda extra / ingresos / aprendiendo）
- リンクなし
- 行動ログあり
- 自己啓発が少ない

### 共通の除外条件
- MLM / crypto signals / forex trader
- coach / mentor / guru
- 宗教系・政治系

（詳細な条件・国別差分は [AFFILIATE_RECRUIT_FIGHTER_CONDITIONS.md](./AFFILIATE_RECRUIT_FIGHTER_CONDITIONS.md) と [AFFILIATE_RECRUIT_SCREENING_BY_COUNTRY.md](./AFFILIATE_RECRUIT_SCREENING_BY_COUNTRY.md) を参照。）
