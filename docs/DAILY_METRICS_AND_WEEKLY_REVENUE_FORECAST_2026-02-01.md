## 1. 一日あたりの投稿数

**スタンバイ**: 6言語計 **300 リスト**（インフルエンサー）が KV にスタンバイしており、引用リポストのキューとして利用される。

| 項目           | 値                   | 備考                                                                                                    |
| -------------- | -------------------- | ------------------------------------------------------------------------------------------------------- |
| **目標投稿数** | **約 240 投稿/日**   | `config/influencerStrategy.js` の目標値（en 72, es 48, pt-br 24, ar 48, ko 24, ja 24）                  |
| Cron 実行回数  | 144 回/日            | 6言語 × 24時間（各言語 1回/時）                                                                         |
| 1回あたり      | 言語別 1～3 投稿     | ストック・クールダウン・ピーク時間で変動                                                                |
| 実際の投稿数   | ストックと制限に依存 | 6言語計300リストスタンバイ時はキュー不足になりにくい。8hクールダウン・日次上限で 240 未満になる場合あり |

**結論**: 一日あたりの投稿数は **最大約 240 投稿/日**（目標）。**6言語計300リストがスタンバイ**している前提で、運用上 **約 100～240 投稿/日** の範囲で変動すると想定。

**結論**: 無料版（Minimal Version）のコンバージョン率は、**クリックベースで 2～5%** を目安に計測・チューニング推奨。

## 6. 今週の収益予測

### 前提

- **収益**: Regular Briefing（有料）の **手取り**（50%クーポン適用後・Whop 手数料控除後）を想定。
- **単価**: 上記「50%クーポン常時展開と Whop 決済手数料」の **手取り 約 $47.30/件**（月額・50%off・[Whop 公式手数料](https://docs.whop.com/fees) 適用後）。3ヶ月・年額は実績で按分可。
- **今週**: 7 日間。

### 計算式

```
今週のクリック数（保守） ≈ 1日あたりインプレッション（保守）× 7 × クリック率（0.5%）
今週のクリック数（楽観） ≈ 1日あたりインプレッション（楽観）× 7 × クリック率（1.5%）

今週の有料コンバージョン数 ≈ 今週のクリック数 × Regular CR（0.3%～1.5%）
今週の収益予測 ≈ 今週の有料コンバージョン数 × 手取り単価（50%クーポン・Whop手数料控除後）
```

### 例（手取り単価: 約 $47.30/件＝50%クーポン・[Whop 公式手数料](https://docs.whop.com/fees) 控除後）

| 項目                         | 保守          | 楽観            |
| ---------------------------- | ------------- | --------------- |
| 1日 imp                      | 120 万        | 360 万          |
| 今週 imp                     | 840 万        | 2,520 万        |
| クリック率                   | 0.5%          | 1.5%            |
| 今週クリック数               | 42,000        | 378,000         |
| Regular CR                   | 0.5%          | 1%              |
| 今週の有料コンバージョン数   | 210           | 3,780           |
| **今週の収益予測（手取り）** | **約 $9,933** | **約 $178,794** |

※ 手取り = 顧客支払い（50%off後）− Whop 公式手数料（カード 2.7%+$0.30、Billing 0.5%、Tax 0.5%、3DS $0.03、Radar $0.07 等）。プラン内訳・為替・キャンセルで変動。Minimal 経由後のアップセルは別途計測。

### あなたの今週の収益予測を出すには

1. **手取り単価**: 50%クーポン常時＋[Whop 公式手数料](https://docs.whop.com/fees) 控除後の **約 $47.30/件** を基準。実績の手数料・プラン内訳で調整可。
2. 上記の「今週の有料コンバージョン数」を、実測または保守/楽観のどちらかで選ぶ。
3. **今週の収益予測 ＝ 今週の有料コンバージョン数 × 手取り単価（例: 約 $47.30）** で計算。

必要なら、Whop のダッシュボードで「今週の新規購入数」を追い、実績と予測の差で CR やクリック率を逆算すると精度が上がります。
