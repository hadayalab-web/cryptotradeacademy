## 最適化のポイント（PT-BR）

- **"br"** … ブラジル・ポルトガル語圏に絞るため維持。
- **"admin" / "dono" / "contato"** … グループ管理者・連絡先を狙うキーワード。必要に応じて "dono" も追加可。
- **"sinais" / "mentoria" / "afiliados"** … BRでよく検索される語のまま。
- **"conteúdo"** … アクセント付きで検索精度アップ。
- **"comissão" "dólar" "vagas"** … アフィリエイト・収益系でよく使う語。
- **"parceria" / "parceiro"** … 提携・パートナー募集に合う語。
