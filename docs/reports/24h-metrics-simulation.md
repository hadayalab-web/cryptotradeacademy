## 📊 シミュレーション前提条件

### 投稿戦略設定（`config/influencerStrategy.js`より）

#### インフルエンサーリスト構成
- **70人の高品質インフルエンサーリスト**: 言語別にストック管理
- **ストック数**: EN 20人、その他言語 各10人（合計70人）

#### 投稿頻度設定
- **インフルエンサー1人あたりの投稿頻度**: **最大2回/日**（8時間クールダウン制限あり）
- **ローテーション機能**: 同じインフルエンサーは1日1回まで（重複防止）
- **時価配分**: ピーク時間（UTC 0,1,20,21,22）に多く投稿、オフピーク時間（UTC 13,14）に少なく投稿

#### 言語別投稿数計算
- **英語 (EN)**: 
  - ピーク時間: 10人/時間 × 5時間 = 50回
  - 通常時間: 10人/時間 × 19時間 = 190回（理論値）
  - オフピーク時間: 4人/時間 × 2時間 = 8回
  - **実際の投稿数**: ローテーション + 8時間クールダウン制限により **約100-120回/日**（AI推奨値に基づく最適化）
- **その他言語 (ES, PT-BR, AR, KO, JA)**: 
  - ピーク時間: 2人/時間 × 5時間 = 10回
  - 通常時間: 2人/時間 × 19時間 = 38回（理論値）
  - オフピーク時間: 1人/時間 × 2時間 = 2回
  - **実際の投稿数**: ローテーション + 8時間クールダウン制限により **各言語約20-25回/日**（AI推奨値に基づく最適化）

#### 合計投稿数
- **合計**: **200-250回/日**（AI推奨値に基づく最適化）
- **根拠**: 
  1. **AI推奨値**: grok-4-1-fast-reasoning推奨「200-300/日（1人2-3回分散）」
  2. **AI推奨値**: gemini-3-pro-preview推奨「160-200投稿/日、上限250投稿/日」
  3. **X APIレート制限**: Per User 100/15min = 理論上9,600/24hrs（実運用では200-300が安全）
  4. **スパム判定回避**: 200-300投稿/日がスパム判定リスクとROIの最適バランス
  5. **実装目標**: 70インフルエンサー × 2-3投稿/日 = 140-210投稿/日
  6. **ローテーション機能**: 同じインフルエンサーは1日1回まで（2周目は8時間クールダウン後）
  7. **8時間クールダウン**: 連続投稿を防止し、スパム判定リスクを低減

### インプレッション目標（`config/influencerStrategy.js`より）
- **EN**: 10万～20万インプレッション/日
- **ES/PT-BR/KO**: 5万～10万インプレッション/日
- **AR/JA**: 3万～8万インプレッション/日
- **合計**: 約30万～60万インプレッション/日（保守的）

### エンゲージメント率（ER）想定
- **一般的なX（Twitter）のER**: 2-5%
- **インフルエンサー投稿のER**: 3-6%（フォロワー規模による）
- **シミュレーション**: 保守的2.5%、現実的4.0%、楽観的5.5%

### コンバージョン率想定
- **CTAクリック率**: 5-10%（エンゲージメントから）
- **オプトイン率**: 20-40%（CTAクリックから）
- **Whop CVR**: 2-5%（トラフィックから成約）

## 🔍 データ検証方法

### 1. ダッシュボードAPI確認
```bash
# 全インフルエンサーの日次パフォーマンス取得
GET /api/x-dashboard-performance?date=2026-01-27&lang=en

# 特定インフルエンサーのRolling集計取得
GET /api/x-dashboard-performance?date=2026-01-27&lang=en&username=influencer1&window=7d
```

### 2. Vercel Logs確認
- 日次メトリクス更新ログ（`api/x-engagement-metrics.js`）
- Webhook受信ログ（`api/x-webhook.js`）
- 投稿成功/失敗ログ（`api/x-post-minimal-version.js`）

### 3. KVデータ確認
- `x:perf:influencer:day:{date}:{lang}:{username}`: 日次パフォーマンス
- `x:perf:influencer:roll:{window}:{lang}:{username}`: Rolling集計
- `x:eng:tweet:{tweetId}:*`: ツイート別エンゲージメント
