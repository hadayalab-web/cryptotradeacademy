## 📈 旧モデルとの比較

### 旧サブスクリプションモデル
- **Basic**: $200/month
- **Pro**: $5,000/month

### 新従量課金制のメリット
- ✅ **初期フェーズ**: $20.30/月（旧比90%削減）
- ✅ **成長フェーズ**: $103.00/月（旧比48%削減）
- ✅ **成熟フェーズ**: $212.50/月（旧比6%削減、ただし無制限スケール可能）

### 損益分岐点
- 月間投稿約120回、読み取り約20,000回で旧$200プランと同等
- それ以下では新モデルが有利

## 🔧 実装

価格設定は `config/xApiPricing.js` に保存されています。

```javascript
const pricing = require('./config/xApiPricing');

// 月間コスト計算
const monthlyUsage = {
  posts: 60,
  userReads: 10000,
};
const cost = pricing.calculate.monthlyCost(monthlyUsage);
console.log(`月間コスト: $${cost.total.toFixed(2)}`);
```

## ⚠️ 注意事項

1. **価格変動**: 価格は変更される可能性があります。最新情報はX Developer Consoleで確認してください。

3. **クレジット購入**: 開発者コンソールからクレジットを事前購入できます。
