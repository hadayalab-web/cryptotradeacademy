## ⚠️ 注意事項

1. **ローテーション機能**: 8時間クールダウンにより、同じインフルエンサーへの連続投稿は防止されます
2. **実際の投稿数**: インフルエンサーのストック数、クールダウン状況、インプレッション目標により変動します
3. **環境変数による調整**: `INFLUENCER_COUNT_EN`などの環境変数で調整可能です
4. **レート制限**: X APIのレート制限により、実際の投稿数は制限される可能性があります
