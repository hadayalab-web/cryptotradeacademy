# X API Webhookデータ活用戦略

## 🎯 現在の状況

### Webhookデータ取得状況
- **投稿数**: 180-220投稿/日（最適化実装完了）
- **Webhookイベント**: いいね、リツイート、リプライをリアルタイム取得
- **データ保存**: Vercel KV（Upstash Redis）に保存
- **分析**: `api/x-engagement-metrics.js`で日次集計

## 📊 Webhookで取得できるデータ

### 1. エンゲージメントイベント
- **いいね（Likes）**: `favorite_events`
- **リツイート（Retweets）**: `retweet_events`
- **リプライ（Replies）**: `tweet_create_events`（`in_reply_to_status_id_str`で識別）

### 2. バイラル検出
- **高エンゲージメント投稿**: 短時間で多くのエンゲージメントを獲得
- **インフルエンサーからのエンゲージメント**: 特定のインフルエンサーからの反応

### 3. インフルエンサー別パフォーマンス
- **投稿ID → インフルエンサーID**: `x:post:influencer:{tweetId}`でマッピング
- **インフルエンサー別エンゲージメント率**: どのインフルエンサーが高パフォーマンスか

## 🚀 データ活用戦略

### Phase 1: エンゲージメント分析（即座に実装可能）

#### 1.1 インフルエンサー別パフォーマンス分析
**実装内容:**
- WebhookイベントからインフルエンサーIDを取得（`x:post:influencer:{tweetId}`）
- インフルエンサー別のエンゲージメント率を計算
- 高パフォーマンスインフルエンサーを特定

**期待される成果:**
- 上位20%のインフルエンサーに投稿を集中
- エンゲージメント率の向上

#### 1.2 投稿タイミング最適化
**実装内容:**
- 投稿時刻とエンゲージメント率の相関分析
- 高エンゲージメントタイミングの特定
- Cronスケジュールの動的調整

**期待される成果:**
- エンゲージメント率の10-20%向上

#### 1.3 コンテンツパターン分析
**実装内容:**
- 高エンゲージメント投稿のテキストパターン分析
- ハッシュタグ、CTA、フックの効果測定
- A/Bテスト結果の分析

**期待される成果:**
- コンテンツ最適化によるエンゲージメント率向上

---

### Phase 2: フィードバックループ構築（1-2週間）

#### 2.1 エンゲージメント率に基づく投稿頻度調整
**実装内容:**
- エンゲージメント率>2%のインフルエンサー: 1日2回投稿を許可
- エンゲージメント率<1%のインフルエンサー: 1日1回に制限
- 8時間クールダウンは維持

**期待される成果:**
- 高パフォーマンスインフルエンサーへの集中
- 全体のエンゲージメント率向上

#### 2.2 バイラル投稿の自動拡散
**実装内容:**
- 1時間以内にエンゲージメント率>5%を検出
- 同一コンテンツを他のインフルエンサーにも投稿
- テキストを微調整して重複を回避

**期待される成果:**
- バズ投稿の機会損失を防止
- リーチの最大化

---

### Phase 3: 高度な分析（1ヶ月以内）

#### 3.1 センチメント分析との統合
**実装内容:**
- Grok分析結果（whaleBias, retailFomo）とエンゲージメント率の相関
- センチメント別の最適投稿タイミング
- センチメント連動の動的投稿

**期待される成果:**
- センチメントに応じた最適化投稿
- コンバージョン率の向上

#### 3.2 リプライ自動化
**実装内容:**
- リプライイベントをWebhookで取得
- Grok分析でリプライ内容を分析
- 自動リプライ（将来の機能）

**期待される成果:**
- エンゲージメントの深化
- コミュニティ構築
