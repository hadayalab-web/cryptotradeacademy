## ⚙️ 環境変数による制御

### X投稿の有効/無効化
```bash
# X投稿を無効化
X_POSTING_ENABLED=false

# X投稿をDry Runモード（実際には投稿しない）
X_POSTING_DRY_RUN=true
```

### 言語別の制御
```bash
# VSL1の対象言語を指定
VSL1_LANGS=en,ja,ko

# VSL1の多言語配信を有効化
VSL1_MULTI_LANG=true

# X投稿の言語を指定（デフォルト: 最初の言語）
X_VSL1_LANG=ja
```

## 🔍 次回投稿時刻の確認方法

### Vercel Dashboard
1. Vercel Dashboard → Project → Settings → Cron Jobs
2. 各Cronジョブの「Next Run」を確認

### ログ確認
- Vercel Dashboard → Project → Logs
- 投稿時刻に実行ログを確認
- `scripts/analyze-x-post-status.js` を使用して投稿状況を分析

---

## 📝 注意事項

1. **UTC時刻で実行**: すべてのCronジョブはUTC時刻で実行されます
2. **タイムゾーン変換**: JST = UTC + 9時間
3. **エラー処理**: 投稿失敗時はログに記録され、次回実行時に再試行される可能性があります
4. **レート制限**: X APIのレート制限に注意（1日あたりの投稿数制限あり）
5. **Dry Runモード**: テスト時は `X_POSTING_DRY_RUN=true` を設定して実際の投稿を防ぐことができます
