# 引用リポスト即効性アップ・明日から収益化（2026-02-06）

## 現状の把握

### 運用フロー
- **Cron**: 各言語が **毎時1回**（EN :04, ES :09, PT-BR :14, AR :19, JA :24, KO :29）
- **1回あたりの投稿数**（`config/influencerStrategy.js`）:
  - EN 6, ES 3, PT-BR 2, AR 3, KO 2, JA 2 → **合計 18投稿/時**
- **オフピーク**（UTC 13, 14時）: 上記の **50%** に削減（即効性が弱い時間帯）
- **日次合計**: 約 **400〜430投稿/日**（レート制限の約12%程度しか使用していない）

### 即効性がない主因
1. **1回あたりの投稿数が控えめ** → ストック（EN 124人など）を活かしきれていない
2. **オフピークで半分に削減** → 13・14時UTCの露出が少ない
3. **本番投稿が無効の可能性** → `X_POSTING_ENABLED=false` や `X_POSTING_DRY_RUN=true` のままの可能性

### 資産（すでに揃っているもの）
- ストック: EN 124, ES 48, PT-BR 35, AR 52, KO 30, JA 11（約300人）
- X API レート: 100/15分（理論上 400/時）、現在 約18/時 → **余裕あり**
- セールスレター・Minimal/Regular 導線・Whop リンクは実装済み

## 実施した変更（明日から収益を最大化）

### 1. 1回あたりの投稿数を増加（露出即増）
- **EN**: 6 → **12**
- **ES**: 3 → **6**
- **PT-BR**: 2 → **4**
- **AR**: 3 → **6**
- **KO**: 2 → **4**
- **JA**: 2 → **4**
→ **1時間あたり 18 → 36投稿**、**日次 約400 → 約800投稿/日** に増加。

### 2. オフピークもフル配分
- UTC 13・14時の **0.5倍制限を撤廃**（multiplier 0.5 → 1.0）
→ 全時間帯で最大投稿数になり、即効性が上がる。

### 3. 環境変数・運用チェック（必ず確認）
本番で **実際にXに投稿** し、収益につなげるために以下を確認してください。

| 項目 | 推奨値 | 説明 |
|------|--------|------|
| `X_POSTING_ENABLED` | `true` | 未設定時は true。false だと投稿しない。 |
| `X_POSTING_DRY_RUN` | `false` | true だと投稿せずログのみ。 |
| X API 4キー | すべて設定 | CONSUMER_KEY, CONSUMER_SECRET, ACCESS_TOKEN, ACCESS_TOKEN_SECRET |
| インフルエンサーストック | KV にデータあり | 空だと「No influencers in stock」でスキップ。`/api/x-update-influencer-stock?lang=xx` で補充可能。 |

Vercel の Environment Variables で上記を設定後、再デプロイまたは次回 Cron 実行から反映されます。

## 期待効果
- **露出**: 約 2倍（約400 → 約800投稿/日）
- **即効性**: オフピークもフル配分のため、24時間を通してリーチが増加
- **収益**: 露出増 → Telegram/Whop への流入増 → 明日から収益獲得の土台が強化

さらに増やしたい場合は、`config/influencerStrategy.js` の `INFLUENCER_COUNT_BY_LANG` を環境変数（`INFLUENCER_COUNT_EN` など）で上書き可能です。

## 明日から収益を始めるためのチェックリスト

1. **Vercel の Environment Variables を確認**
   - `X_POSTING_ENABLED` = `true`（または未設定でOK）
   - `X_POSTING_DRY_RUN` = `false`（本番投稿するなら必須）
   - X API の 4 キーがすべて設定されていること

2. **インフルエンサーストックの確認**
   - 各言語でストックが入っていること（空だとスキップされる）
   - 不足時: `/api/x-update-influencer-stock?lang=en` などで補充（手動またはスクリプト）

3. **デプロイ**
   - 上記コード変更を push してデプロイすれば、次回 Cron から **1回あたり2倍・全時間フル配分** が適用される。

4. **動作確認（任意）**
   - Vercel Logs で `[QuoteRepost-EN]` 等のログを確認し、`posted_count` が増えていること、`dryRun` でないことを確認。
