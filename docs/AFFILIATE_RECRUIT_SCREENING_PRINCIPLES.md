# 泥臭いアフィリエイターを見抜くスクリーニング原理（DM前）

**目的**: DM を送る前に、行動量が高く・売る商品がなく・泥臭く動けるアフィリエイターだけを抽出する。  
Trap Defence のリクルート OS の核となる判定ロジック。

---

## 1. 投稿量の「質」（習慣の痕跡）

泥臭い人は **「毎日投稿している」ではなく「毎日投稿せざるを得ない生活」** をしている。

**判定基準**
- 過去7日で **最低10ポスト**
- そのうち **3つ以上が自分の意見**（引用RTやコピペではない）
- ポストの時間帯がバラけている（＝習慣化）

習慣化している人は、アフィリエイトでも動く。

---

## 2. 「売るものがない人」を優先

泥臭いアフィリエイターは **商品がないから動く**。

**判定**
- プロフィールにリンクがない
- リンクがあるが **死んでいる / 更新されていない**
- 固定ポストが副業系なのに、売り物がない
- プロモツイートが1つもない

→ 動きたいのに動けていない ＝ 最も反応が良い。

---

## 3. 引用RTの頻度

**引用RTが多い人は、行動量が高い。**

**判定**
- 過去7日で **引用RTが5回以上**
- 内容が「絡み」ではなく「意見」になっている
- 反応が少なくても続けている

引用RTは能動的行動の証拠。泥臭い人は反応がなくても動き続ける。

---

## 4. プロフィールの「匂い」

泥臭いアフィリエイターは、プロフィールに **焦り・野心・行動量** が滲む。

**優先キーワード（泥臭さ）**
- hustle, grind, affiliate, DM open, make money, side income, entrepreneur, building, learning

**除外キーワード（動かない・プライド高い・返信率低い）**
- growth hacker, SEO expert, consultant, coach, agency owner

---

## 5. フォロワー数の中途半端ゾーン

**最適ゾーン: 100〜3,000 フォロワー**

- 100未満 → SNS 習慣が弱い
- 3,000以上 → 自分の商品を持ち始める / プライドが出る

100〜3,000 は **最も泥臭く、最も動く**。

---

## 6. 「反応が少ないのに投稿している」を最重要視

**反応ゼロでも投稿を続けている人は、アフィリエイトで最強。**

**判定**
- いいね 0〜3 の投稿が連続している
- それでも毎日投稿している
- それでも引用RTしている

行動量の証明。Trap Defence のアフィリエイトでは行動量がすべて。

---

## 7. 「自分語りが少ない人」を優先

泥臭いアフィリエイターは **自分語りより行動**。

**判定**
- 自己啓発ポストが少ない
- 自分の人生語りが少ない
- 代わりに「行動ログ」が多い（今日の投稿数・学び・作業）

---

## 必須条件（DM前の抽出ロジック）

```
【必須】
- 過去7日で10ポスト以上
- 引用RTが5回以上
- フォロワー100〜3000
- プロフィールに "hustle / affiliate / DM open / make money" のいずれか
- リンクがない or 死んでいる
- 反応が少なくても投稿を継続している

【優先】
- 固定ポストが副業系
- 自己啓発より行動ログが多い
- 投稿時間帯がバラけている（習慣化）
```

---

## Cursor 用：スクリーニング自動化プロンプト

```
あなたの役割は「泥臭く行動するアフィリエイター候補」をX上から抽出するフィルターです。

【目的】
DMを送る前に、行動量が高く、売る商品がなく、泥臭く動けるアフィリエイターだけを抽出する。

【抽出基準（必須）】
- 過去7日で10ポスト以上
- 過去7日で引用RTが5回以上
- フォロワー100〜3000
- プロフィールに以下のいずれかを含む：
  "affiliate", "DM open", "hustle", "grind", "make money", "side income"
- リンクがない、またはリンクが死んでいる（更新されていない）
- いいね0〜3の投稿が複数あっても継続して投稿している

【優先条件】
- 固定ポストが副業系
- 自己啓発より「行動ログ」が多い（例：今日の作業、今日の学び）
- 投稿時間帯がバラけている（習慣化の証拠）
- 自分の商品を持っていない（プロモツイートがない）

【除外条件】
- "coach", "consultant", "agency owner", "SEO expert", "growth hacker" を含む
- フォロワー3000以上（プライドが高く動かない）
- 自己啓発ポストばかりのアカウント
- 投稿が少ない or 反応がないと止まるタイプ

【出力】
- スコア（0〜100）
- スコア理由（行動量・泥臭さ・売り物の有無・継続力）
- DMを送るべきか（YES/NO）
```

---

## スコアリングモデル（100点満点）

### A. 行動量（最大40点）
| 指標 | 点数 |
|------|------|
| 過去7日10ポスト | +10 |
| 過去7日15ポスト | +15 |
| 過去7日20ポスト | +20 |
| 引用RT 5回以上 | +10 |
| 引用RT 10回以上 | +20 |

### B. 継続力（最大20点）
| 指標 | 点数 |
|------|------|
| いいね0〜3でも投稿継続 | +10 |
| 投稿時間帯がバラけている | +10 |

### C. 泥臭さ（最大20点）
| 指標 | 点数 |
|------|------|
| 行動ログがある | +10 |
| 自己啓発より行動が多い | +10 |

### D. 商材の有無（最大10点）
| 指標 | 点数 |
|------|------|
| リンクなし | +10 |
| リンクあるが死んでいる | +5 |

### E. プロフィール適性（最大10点）
| 指標 | 点数 |
|------|------|
| hustle / grind / affiliate / DM open 等 | +10 |

---

## DM 送信基準

- **70点以上** → DM 送るべき
- **50〜69点** → 保留（国によっては送る価値あり）
- **49点以下** → 送らない

---

## 実装との対応

- 現行スコアリング: `services/td/affiliateRecruitScoring.js`
  - Bio・フォロワー帯・ER・hype・泥臭さ・努力系・泥臭ゾーン・初心者ゾーン・リンクなし・行動ログ
  - **擬似継続力**（`scoreConsistencyFromRecentTweets`）: タイムラインの日付ばらつき・いいね0〜3の割合で「反応ゼロでも投稿継続」を近似
  - **痛み＋行動ログボーナス**: hype/痛みキーワードと行動ログの両方がある候補を加点（自己啓発だけより本当に動きたい層を優先）
  - **REGION_COEFFICIENT**: 将来 lang/region 連携時に掛ける地域係数（IN/PH/BR 等）を定数で定義済み・未使用
- **DM優先度の目安**（スコア 0–100）: 70以上→即DM、50〜69→保留、49以下→送らない。将来 `priority = score * qualityFactor * regionCoefficient` の階層化を検討可
- **検証**: 言語圏別のスコア分布・返信率をログすると「どの言語圏がファイター率高いか」を仮説検証しやすい
