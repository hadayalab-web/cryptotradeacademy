# X チート戦略 — 確立文書（2026-01-31）

## 戦略の定義

**あなたが私に期待すること**を、次の1文に集約する。

> **824人のインフルエンサーリストを最大限活用して投稿数を可能な限り引き上げ、Grok と Gemini から必要なアイデアを取得し、インプレッションとエンゲージメントを集め、そのトラフィックを Whop に流し込むチート戦略を確立する。**

---

## 前提

- **現状**: フォロワーがほぼいない。
- **方針**: インフルエンサーに**寄生**し、彼らのリーチを借りる。
- **出口**: 集めたトラフィックを **Whop** に流し込む（無料版 → 有料版のファネル）。

---

## チート戦略の4本柱

### 1. 824人インフルエンサーリストの最大活用（投稿数最大化）

| レバー | 内容 | 現状・目標 |
|--------|------|------------|
| **ローテーション** | 824人を言語別に均等に回し、同じ人に偏らない | `config/influencerStrategy.js` のストック数・選択ロジック |
| **実行頻度** | 引用リポストの cron を増やし、1日の投稿機会を増やす | `vercel.json` の quote-repost スケジュール（現状: EN 10分毎など） |
| **1回あたり人数** | 言語別に「1回の実行で何人のインフルエンサーに引用リポストするか」を引き上げ | `INFLUENCER_COUNT_BY_LANG`（EN 35, ES 20…） |
| **言語カバー** | EN, ES, PT-BR, AR, JA, KO の6言語で 824 人をフルに回す | ストック数: EN 210, ES 168, PT-BR 158, AR 112, JA 98, KO 78 |

**目標**: 1日あたりの引用リポスト数を可能な限り増やし、824人を「回し切り」に近づける。

---

### 2. Grok から得るアイデア

| 用途 | 内容 |
|------|------|
| **X アルゴリズム** | 引用リポスト・スニペット・RT 等の扱い。何がインプレ・エンゲージメントに効くか。 |
| **コピー・フック** | 歴史的ヘッドライン風の一言、感情を動かす短いコメント。 |
| **投稿タイミング** | 時間帯・曜日別の推奨（UTC ベースで cron に反映）。 |
| **リンク配置** | 1投稿1リンク、2枚目以降 or スレッド2枚目に置く等のルール。 |

**実装の入口**: `services/grok/`（xAlgorithmAnalyzer, client）、`services/x/contentOptimizer.js`、引用リポスト用テンプレート。

---

### 3. Gemini から得るアイデア

| 用途 | 内容 |
|------|------|
| **心理・誘導** | 無料版（Minimal）・有料版（Regular）への「理由」と CTA。 |
| **ファネル設計** | Telegram を「選ばれた層」のコミュニティとして見せる、Whop を「結果への近道」として見せる。 |
| **Whop コンバージョン** | リンクの置き方、プロモコード（例: DEFEND50）の見せ方、リスク逆転の言い回し。 |

**実装の入口**: `services/gemini/messageOptimizer.js`、`services/x/contentOptimizer.js`（cvrPsychologicalAlgorithm, whopConversion）。

---

### 4. インプレッション・エンゲージメント → Whop へのファネル

```
[インフルエンサー投稿] → [引用リポストで寄生]
         ↓
  インプレッション・エンゲージメント
         ↓
  ┌──────────────────────────────────────┐
  │  CTA: 無料版（Minimal） or 有料版へ    │
  │  Telegram Deep Link / Whop URL        │
  └──────────────────────────────────────┘
         ↓
  [無料版] → 体験 → [有料版 Regular / Whop]
         ↓
  Whop コンバージョン（プロモコード DEFEND50）
```

- **投稿内**: リンクは1本に絞る。Telegram または Whop を Grok/Gemini の推奨に合わせて選択。
- **Landing**: Whop 商品ページ + UTM（例: `?promo=DEFEND50`）。
- **計測**: `api/whop-webhook.js` で Whop イベントを受信し、X 経由トラフィックを識別可能にする。
