### 6. Grok APIのレスポンス品質

#### 成功したレスポンスの特徴

**高品質なレスポンス例**:
```json
{
  "influencers": [
    {
      "username": "saylor",
      "tweetId": "1841185994600853315",
      "tweetText": "Bitcoin is the apex property...",
      "engagementRate": 0.12,
      "followerCount": 3500000,
      "recentImpressions": 2500000
    }
  ]
}
```

**特徴**:
- ✅ tweetId: 19桁の数値（正しい形式）
- ✅ username: 1-15文字（正しい形式）
- ✅ tweetText: 1-280文字（正しい形式）
- ✅ engagementRate: 0-1の範囲（正しい形式）
- ✅ followerCount: > 0（正しい形式）

#### 空配列が返される原因の推測

**可能性1: Grokの内部制限**
- 連続リクエストで一時的に空配列を返す
- リトライで成功するため、一時的な問題の可能性が高い

**可能性2: プロンプトの厳格さ**
- 「REAL tweetId」「ACTUAL tweet」という要件が厳しすぎる
- Grokが条件を満たすインフルエンサーを見つけられない場合がある

**可能性3: レート制限**
- Grok APIのレート制限に引っかかっている可能性
- リトライで成功するため、一時的なレート制限の可能性
