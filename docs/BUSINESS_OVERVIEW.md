## 🎯 価値提案の3層構造

### Layer 1: コンテンツ生成（AIオーケストレーション）
```
CryptoQuant API（オンチェーンデータ）
    ↓
Gemini（記事生成、過去分析、画像生成）
    ↓
Grok（品質評価、Xアルゴリズム最適化）
    ↓
Veo + HeyGen（動画生成）
    ↓
Resend API（Eメール配信）
```

**成果物**:
- SoSoValue風の高品質記事（1000-1500文字）
- チャート画像（NanoBnana）
- ホログラフィックビジュアライゼーション
- Veo動画（8秒、720p）
- HeyGen動画（AIアバター解説）
- X投稿文（Grok最適化）

### Layer 2: 差別化機能（独自指標・アラート）
```
Trap Score（独自リスク指標）
    ├─ 基本指標: Exchange Netflow, MPI
    ├─ 追加指標: Fear & Greed Index, Funding Rate, Open Interest
    └─ カスタム設定: 重み付け、閾値設定（Premium Tier）

リアルタイムアラート（6種類）
    ├─ 価格変動アラート
    ├─ Trap Scoreアラート
    ├─ Exchange Netflowアラート
    ├─ MPIアラート
    ├─ Fear & Greed Indexアラート
    └─ Funding Rateアラート
```

### Layer 3: プラットフォーム統合（スケーリング）
```
Thinkific統合
    ├─ コース構造化（Minimal/Regular/Premium）
    ├─ 自動コンテンツアップロード
    ├─ サブスクリプション管理
    └─ 学習進捗追跡
```
