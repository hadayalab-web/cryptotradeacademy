# リード発見レポート機能

**作成日**: 2026-01-19  
**目的**: Resendレポートの機能と見積もり追跡について

---

## 📊 レポート種類

### 1. 実行レポート（`generateLeadDiscoveryReport`）

**送信タイミング**: リード発見実行時（2時間ごと）  
**対象期間**: 過去24時間

**内容**:
- 今回の実行結果（発見リード数、VSL1送信数、エラー数）
- 見積もり vs 実測値比較（1回の実行）
- CVR統計（過去24時間）
- Whop統計（過去24時間）

---

### 2. 日次レポート（`generateDailyReport`）

**送信タイミング**: 毎日9:00 UTC（日本時間18:00）  
**対象期間**: 昨日1日分

**内容**:
- 日次見積もり vs 実測値比較
- 日次目標売上 vs 実測値比較
- 日次統計（リード数、VSL1送信数、成約数、CVR、売上）
- 言語別統計（6言語別のリード数、CVR、売上）
- Whop統計
- 分析と次のアクション

---

### 3. 週次レポート（`generateWeeklyReport`）

**送信タイミング**: 毎週月曜日9:00 UTC（日本時間18:00）  
**対象期間**: 過去7日間（デフォルト）

**内容**:
- 週次見積もり vs 実測値比較
- 週次目標売上 vs 実測値比較
- 週次統計（リード数、VSL1送信数、成約数、CVR、売上）
- 言語別統計（6言語別のリード数、CVR、売上）
- Whop統計（週次）
- 週次分析と次のアクション

### 目標売上額

| 期間 | 目標 | 根拠 |
|------|------|------|
| **1日** | $15,660 | $469,800 / 30日 |
| **1週間** | $108,500 | $469,800 / 4.33週 |
| **1ヶ月** | $469,800 | 3,132成約 × $150/成約 |

**計算根拠**:
- 月間リード数: 10,440件
- CVR: 30%（目標）
- 月間成約数: 10,440 × 0.30 = 3,132成約
- 1成約あたり売上: $150（想定）
- 月間売上: 3,132 × $150 = $469,800

### CVR目標

- **全体CVR**: 30%（リード → 成約）

## 🌍 言語別集計

### 対応言語

- **英語 (EN)**: 55%配分（推定）
- **スペイン語 (ES)**: 20%配分（推定）
- **ポルトガル語 (PT-BR)**: 12%配分（推定）
- **アラビア語 (AR)**: 2%配分（推定）
- **日本語 (JA)**: 8%配分（推定）
- **韓国語 (KO)**: 3%配分（推定）
- **その他**: 未分類リード

### 言語別統計項目

各言語について以下を集計：
- **リード数**: その言語で発見されたリード数
- **VSL1送信数**: その言語のリードへのVSL1送信数
- **成約数**: その言語のリードからの成約数
- **CVR**: その言語のコンバージョン率
- **売上**: その言語のリードからの売上

## 🔍 データ取得方法

### 自動追跡

1. **リード記録**: `recordLead()` → Vercel KVに保存（`lang`フィールド含む）
2. **VSL1送信記録**: `recordVSL1Sent()` → Vercel KVに保存
3. **成約記録**: `recordConversion()` → Vercel KVに保存
4. **CVR統計**: `getCVRStats()` → Vercel KVから集計
5. **言語別統計**: `getCVRStatsByLanguage()` → Vercel KVから言語別集計
6. **Whop統計**: `getWhopStats()` → Whop APIから取得

## 🚀 使用方法

### 手動送信

```bash
# 日次レポート
node scripts/send-lead-discovery-report.js daily [date]

# 週次レポート
node scripts/send-lead-discovery-report.js weekly [startDate] [endDate]

# 実行レポート
node scripts/send-lead-discovery-report.js execution [stats]
```

### 自動送信

- **実行レポート**: `/api/lead-discovery` 実行時に自動送信
- **日次レポート**: 毎日9:00 UTCに自動送信（Cron）
- **週次レポート**: 毎週月曜日9:00 UTCに自動送信（Cron）
