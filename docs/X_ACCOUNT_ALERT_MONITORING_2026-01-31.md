# Xアカウントアラート監視ガイド

**作成日**: 2026-01-31  
**状況**: 午前中からかなりの数のドライランテストを実行したため、Xアカウントに「provisional label」と「potential spam/platform manipulation warning」が表示され始めた

## 現在の状況

### 観察された問題
- Xアカウントに「provisional label（暫定ラベル）」が表示
- 「potential spam/platform manipulation warning（スパム/プラットフォーム操作の警告）」が表示
- X API使用状況ダッシュボードで、1月24日以降に急激な使用量増加を確認
  - 総投稿数: 184件（1月全体）
  - 総リクエスト数: 914件（1月全体）
  - 1月24日以降の急増: Content Create 40-53件/日、Read 38-191件/日

### 原因の推測
- **今日の午前中からかなりの数のドライランテストを実行**
- ドライラン失敗時のタイムアウトエラーによる連続リトライが、X APIに不要なリクエストを送信
- 「試行回数だけ伸びて実投稿が空になる」という異常なパターンが、Xのシステムに検出された可能性

## 実装した対策

### 1. ドライランモード時の書き込み操作（POST）を完全にスキップ
- **ファイル**: `services/x/client.js`
- **効果**: ドライランモード時は、書き込み操作のリクエスト自体を送信しないため、「試行だけして投稿しない」という異常なパターンを防止

### 2. ドライランモード時のタイムアウトエラーリトライ無効化
- **効果**: ドライランモード時は、タイムアウトエラーをリトライせず、即座にエラーをスロー

### 3. タイムアウトエラーのリトライ回数削減
- **効果**: タイムアウトエラーのリトライ回数を最大3回→1回に削減

## 監視ポイント

### 1. Xアカウントの状態
- [ ] 「provisional label」が解除されるか
- [ ] 「potential spam/platform manipulation warning」が解除されるか
- [ ] アカウントの制限やペナルティが発生していないか

### 2. X API使用状況
- [ ] リクエスト数の推移（異常な増加がないか）
- [ ] エラー率（タイムアウトエラーの発生率）
- [ ] 投稿成功率（試行回数に対して実際の投稿が成功しているか）

### 3. CronJobsの動作
- [ ] ドライランモード時の動作（不要なリクエストが送信されていないか）
- [ ] 本番環境での動作（正常に投稿が成功しているか）
- [ ] タイムアウトエラーの発生頻度

## 今後の対応方針

### 短期（1-2週間）
1. **様子を見る**: 実装した対策の効果を確認
2. **監視を継続**: Xアカウントの状態とAPI使用状況を定期的に確認
3. **ドライランテストの頻度を制限**: 必要最小限のテストに留める

### 中期（1ヶ月）
1. **アラートが解除された場合**: 対策が効果的だったと判断
2. **アラートが継続する場合**: 追加の対策を検討
   - ドライランテスト時のAI分析処理もスキップする
   - タイムアウト時間の短縮（30秒→10秒）
   - リトライロジックのさらなる最適化

### 長期（3ヶ月）
1. **パターンの分析**: X API使用状況のパターンを分析し、最適化
2. **予防策の確立**: ドライランテスト時のベストプラクティスを確立

## 注意事項

### ⚠️ 重要な警告
- **CronJobsが正常に動作しない場合（試行回数だけ伸びて実投稿が空になる場合）は、完全にスパム扱いになる可能性があります**
- 本番環境では、CronJobsが正常に動作していることを確認してから、ドライランモードを解除してください

### 推奨事項
1. **ドライランテストの頻度を制限**: 必要最小限のテストに留める
2. **本番環境での動作確認**: ドライランモード解除後は、実際の投稿が正常に成功していることを確認
3. **定期的な監視**: Xアカウントの状態とAPI使用状況を定期的に確認
