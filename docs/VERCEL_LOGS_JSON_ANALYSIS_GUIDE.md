# VercelログJSON分析ガイド - 2026-01-21
**作成日時**: 2026-01-21  
**目的**: Vercel DashboardからエクスポートしたJSONログの分析方法

---

## 📊 分析対象メトリクス

### 1. リード獲得関連

- **総リード発見数**: 全言語の合計
- **言語別リード発見数**: en, es, pt-br, ar, ja, ko
- **Perfect Match数**: ドンピシャリードの数
- **VSL1送信数**: 実際にVSL1が送信された数
- **tweetIdありのリード数**: VSL1送信可能なリード数
- **エラー数**: リード処理中のエラー数

### 2. VSLワークフロー関連

- **VSL1投稿数**: X投稿の成功数
- **VSL1リマインダー送信数**: Telegram DM送信数
- **VSL2配信数**: Telegram DM送信数
- **VSL2ラストコール送信数**: Telegram DM送信数

### 3. エラー分析

- **エラーの種類**: Binance API、X API、Grok API、KVストレージなど
- **エラーの頻度**: 時間別、エンドポイント別
- **エラーの影響**: リード獲得、VSLワークフローへの影響

### 4. パフォーマンス分析

- **時間別パフォーマンス**: 時間帯によるリード発見数の変動
- **言語別パフォーマンス**: 言語によるリード発見数の差
- **CVR**: VSL1送信数 ÷ リード発見数

## 🚀 分析の流れ

1. **JSONログの読み込み**: エクスポートしたJSONファイルを読み込む
2. **ログのフィルタリング**: リード発見関連のログを抽出
3. **メトリクスの抽出**: リード発見数、VSL1送信数などを抽出
4. **エラー分析**: エラーの種類と頻度を分析
5. **レポート生成**: 分析結果をレポート形式で出力

## 💡 分析で確認すべきポイント

### 1. リード獲得数が目標を達成しているか

- 日次リード発見数: 200-300件/日
- 週次リード発見数: 1,400-2,100件/週

### 2. CVRが目標を達成しているか

- 目標CVR: 30%
- 実際のCVR: VSL1送信数 ÷ リード発見数

### 3. エラーがリード獲得に影響しているか

- エラー数がリード発見数を下回っているか
- エラーがVSL1送信を妨げているか

### 4. 言語別パフォーマンスに差があるか

- 特定の言語でリード発見数が少ないか
- 特定の言語でエラーが多いか
