# Copilot 用：X Ads（手動ダッシュボード）への切り替えと戦略アドバイス依頼

以下を Copilot に貼り付け、X Ads 戦略についてアドバイスを求める。

---

## 共有したい内容

私たちは、X（旧Twitter）上のオーガニック施策（引用リポスト・リプライ便乗）で Whop の有料サブスクへトラフィックを送る試みを続けてきましたが、インプレ・クリックがほぼ得られず成約ゼロでした。このため、**X Ads に切り替える方針です。X Ads API は使わず、広告ダッシュボード（手動）からキャンペーンを運用します。**

**前提と見込み：**

- **トラフィックさえ流せれば CVR は高いと見込んでいます。** プロダクト品質・Whop の LP・Whop 内の VSL・Telegram の Briefing はいずれも整っており、ファネル下流は問題ないと考えています。課題は「見つけられていない・インプレ・トラフィックがほぼない」ことだけです。
- **言語別にオファーが独立しています。** EN / ES / PT / AR / KO / JA の 6 言語それぞれで、以下が用意されています。
  - Whop の LP ページ（言語別）
  - VSL（Whop 内・言語別）
  - Telegram の Briefing（言語別）
- **目的は「トラフィックとインプレッションの獲得」に絞ります。** まずは各言語の LP に適切なユーザーを送り、インプレ・クリックを確保できれば、既存の LP・VSL・Briefing で成約に繋がると想定しています。

**お願いしたいアドバイス：**

1. **手動の X Ads ダッシュボードで、トラフィック・インプレを最優先で獲得するための戦略**を教えてください。キャンペーン目的の選び方（インプレ重視 vs クリック重視 vs コンバージョン重視）、予算配分、テスト順序、言語別の出し分け（EN から先行するか、複数言語を同時にテストするか）など、実務で使える指針が欲しいです。

2. **6 言語（EN/ES/PT/AR/KO/JA）をどう扱うか**について、最初は 1 言語に絞るべきか、複数言語を少額ずつ並行テストするべきか、また言語別のターゲティング・クリエイティブの考え方（例：EN は広め・他言語は興味/地域で絞る等）のアドバイスが欲しいです。

3. **クリプト・トレード系の有料サブスク（Whop）への誘導**という文脈で、X Ads のポリシー・審査で気をつけるべき点（表現・画像・訴求の制約、認証の要否など）と、審査を通しつつクリックを引きやすいクリエイティブ・コピーの方向性を教えてください。

4. **「トラフィックとインプレが取れれば CVR は見込める」** という前提で、最初のテスト期間に重視すべき指標（インプレ数・クリック数・CTR・単価など）と、どの段階で「トラフィックは確保できている」と判断し、次のステップ（スケール or クリエイティブ/ターゲティングの改善）に進むかの目安を教えてください。

以上を踏まえ、手動 X Ads への切り替え後の戦略についてアドバイスをお願いします。
