## 概要
SELL/SHORTシグナル生成アルゴリズムを再構築し、80%以上の勝率を目標に改善を実施。

## 主な変更点

### 1. marketCore.js - SELL/SHORT専用ロジック追加

#### トラップ検出ベースのSELLシグナル
- **FOMO Bull Trap**: 
  - 条件: `change24h > 7 && inflow > 2500 && retailFomo >= 85 && whaleBias <= -0.5`
  - より厳格な条件（流入量2500以上、FOMO85以上、クジラバイアス-0.5以下）

- **Bull Trap**: 
  - 条件: `change24h > 6 && inflow > 2000 && retailFomo >= 75`
  - 極端な流入（3000以上）とマイナー売却（MPI > 1.0）を追加要求

- **天井検出（ダイバージェンス）**: 
  - 条件: `change24h > 3 && change24h < 8 && smartMoneyScore < -15 && retailFomo >= 75 && inflow > 1000`
  - 適度な上昇範囲（3-8%）、より負のsmartMoneyScore（-15以下）、マイナー売却確認

#### 追加フィルタリング条件
- 適度な上昇範囲: `change24h > 2 && change24h < 8`（急騰すぎない）
- 極端な流入: `inflow > 3000`（明確な分布シグナル）
- マイナー売却: `mpi > 1.0`（マイナーの売却圧確認）

#### Confidence閾値の調整
- トラップベース: `confidence >= MIN_CONF_FOR_TRADE * 0.85`（従来の0.8から引き上げ）
- 天井検出: `confidence >= MIN_CONF_FOR_TRADE * 0.8`（従来の0.7から引き上げ）

### 2. synthesizeOnchainAndSocialロジック改善

#### Bull Trapパターン注入の強化
- 価格上昇5%以上時、25%の確率でBull Trapパターンを注入
- 流入量: 2000-5000 BTC
- MPI: 1.5-3.0（高い売却圧）

#### 天井検出パターン注入
- 価格上昇2.5-7%時、15%の確率で天井パターンを注入
- 価格上昇 + オンチェーン弱気（ダイバージェンス）

### 3. generate_and_backtest_recent.js更新

#### テスト用閾値ロジックの改善
- marketCore.jsと同じロジックを適用
- より厳格な条件でSELLシグナルを生成
