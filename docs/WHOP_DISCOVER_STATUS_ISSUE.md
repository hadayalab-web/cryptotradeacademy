# Whopディスカバーステータス問題の調査結果
**作成日時**: 2026-01-17 14:07:03  
**作成日**: 2026-01-17  

**日付**: 2026-01-27  
**問題**: ダッシュボードで「5/5 完了」と表示されているのに、ディスカバーステータスが「未上場」のまま

---

## 🔍 状況

- ✅ ダッシュボード上で「5/5 完了」と表示されている
- ✅ すべての条件（ビジネスロゴ、商品タイトル、商品ヘッドライン、商品説明、製品メディア）が満たされている
- ❌ しかし、ディスカバーステータスは「未上場 - ディスカバーに掲載」のまま

---

## 📋 調査結果

### APIでの制御

**Whop API v2には、ディスカバーステータスを直接制御するエンドポイントが存在しません。**

- `listed_on_discover`フィールドは存在しない
- `/products/{id}/discover`のようなエンドポイントは存在しない
- `/products/{id}/list_on_discover`のようなエンドポイントも存在しない

### 現在の対応方法

**APIでは制御できません。Whopサポートに問い合わせる必要があります。**

- ダッシュボード上で「5/5 完了」と表示されているのに、ディスカバーステータスが「未上場」のままの場合、Whop側のシステム問題の可能性があります
- APIにはディスカバーステータスを制御するエンドポイントが存在しないため、Whopサポートに問い合わせる必要があります

---

## ⚠️ 問題点

ダッシュボード上では「5/5 完了」と表示されているのに、ディスカバーステータスが「未上場」のままになっている場合、以下の可能性があります：

1. **Whop側の審査待ち**: 条件は満たしているが、Whop側の審査が完了していない
2. **UIの表示遅延**: 実際には掲載されているが、UIの表示が更新されていない
3. **別の設定が必要**: 「List on Discover」のトグルを手動で有効化する必要がある
4. **Whop側のバグ**: システム側の問題で、条件を満たしているのに掲載されない

---

## 🔧 推奨アクション

1. **Whopサポートに問い合わせ**
   - ダッシュボードで「5/5 完了」と表示されているのに、ディスカバーステータスが「未上場」のままの場合、Whopサポートに問い合わせる
   - APIでは制御できないため、Whop側のシステム問題の可能性があります

2. **時間を置いて再確認**
   - 審査には時間がかかる場合があるため、数時間後に再確認
   - UIの表示遅延の可能性もあります
