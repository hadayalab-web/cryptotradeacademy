## 📋 実行内容

### EN（英語）
- **目標数**: 210人
- **バッチサイズ**: 25人/バッチ
- **実行時間**: 約10-15分（Grok APIの応答時間に依存）

### 実行プロセス

1. **Grokから取得**: 25人ずつ取得
2. **厳格な検証**: tweetId、username、tweetTextの完全性チェック
3. **段階的保存**: 各バッチ後に保存
4. **保存後検証**: ファイルを読み込んで確認
5. **繰り返し**: 目標数（210人）に達するまで

## ✅ 実行後の確認

### 1. ファイルの確認

`data/influencers/influencers-en.json` が作成されているか確認してください。

### 2. データ数の確認

ファイルを開いて、`count`フィールドが210に近いか確認してください。

### 3. データの完全性確認

各インフルエンサーに以下のフィールドが存在するか確認：
- `username`: @なしのユーザー名
- `tweetId`: 18-19桁の数値
- `tweetText`: 1-280文字のツイートテキスト
- `followerCount`: > 0
- `engagementRate`: 0-1の範囲

## 🛡️ 安全機能

### バックアップ

各保存前に自動的にバックアップが作成されます：
- `data/influencers/backups/influencers-en-{timestamp}.json`

### 段階的保存

各バッチ（25人）ごとに保存されるため、途中でエラーが発生しても既存データは保持されます。

### 重複チェック

既存データとの重複を自動的にチェックし、重複を除外します。

## 🚨 トラブルシューティング

### エラー: "Grokから取得失敗（0人）"

**原因**: Grok APIのエラー、または検索条件が厳しすぎる

**対策**:
- 少し待ってから再実行
- Grok APIのレート制限を確認

### エラー: "検証後0人"

**原因**: Grokが返したデータが検証を通過しなかった

**対策**:
- 検証ログを確認
- バッチサイズを小さくして再試行（スクリプト内の`BATCH_SIZE`を10-15に変更）

### エラー: "保存失敗"

**原因**: ファイルシステムのエラー

**対策**:
- ディレクトリの権限を確認
- ディスク容量を確認
- バックアップを確認
