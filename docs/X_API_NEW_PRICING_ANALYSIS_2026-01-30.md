# X API 新しい料金プラン分析
**作成日**: 2026-01-30  
**参照**: X API Developer Console - 新しい従量課金プラン

## 📊 新しい料金プランの概要

X APIは **従量課金モデル（Pay-per-use）** に移行しました。

### 従量課金のメリット

1. **柔軟性**: ユースケースに応じて必要なリソースを柔軟に調整。ムダなく利用。
2. **透明性**: 使用量に基づく明確な課金。予期せぬコストを回避。
3. **拡張性**: ビジネスの成長に合わせて容易にスケールアップ・ダウン。
4. **革新性**: 最新のAI機能とAPIに常にアクセス可能。

## 💰 エンドポイント別レート（引用リポスト関連）

### 主要エンドポイントのレート

| APIエンドポイント | レート（使用量あたり） | 説明 |
|-----------------|-------------------|------|
| **POST `/2/tweets`** | **0.001** | ツイート投稿（引用リポスト含む） |
| **GET `/2/tweets/:id`** | **0.001** | ツイート取得 |
| **GET `/2/users/:id`** | **0.001** | ユーザー情報取得 |
| **POST `/2/media/upload`** | **0.005** | メディアアップロード（画像・動画） |

**重要**: 
- 引用リポストは **POST `/2/tweets`** を使用
- レート: **0.001**（1リクエストあたり）
- メディアアップロードは他のエンドポイントより **5倍高い**（0.005）

## 🔄 従量課金 vs. サブスクリプション

### 従量課金（新しいモデル）

**メリット**:
- ✅ 初期費用なし
- ✅ 利用した分だけ支払う
- ✅ 柔軟なスケール

**デメリット**:
- ⚠️ 予測が困難な場合あり

**現在の使用量でのコスト**: **約$36.24/月**（引用リポスト + データ取得）

### サブスクリプション（旧モデル）

**メリット**:
- ✅ 月額固定料金（予測が容易）
- ✅ 特定の機能が利用可能

**デメリット**:
- ❌ 利用しない月も費用発生
- ❌ 旧モデル（現在は従量課金に移行）

**旧Proプラン**: $5,000/月（1,000,000ツイート/月まで）

## 📊 コスト比較

| プラン | 月額料金 | 現在の使用量でのコスト | 差額 |
|-------|---------|---------------------|------|
| **従量課金（新）** | 使用量に応じて | **$36.24/月** | - |
| **旧Proプラン** | $5,000/月 | $5,000/月 | **-$4,963.76/月** |

**結論**: 新しい従量課金モデルでは、現在の使用量（約12,240投稿/月）で **約$36.24/月** のコストが発生します。これは旧Proプラン（$5,000/月）と比較して **99.3%のコスト削減** になります。

## ⚠️ 注意事項

### 1. レート制限は依然として存在

従量課金モデルに移行しても、**レート制限は依然として存在**します：

- **POST `/2/tweets`**: 100/15min (Per User, OAuth 1.0a)
- **GET `/2/tweets/:id`**: 900/15min (Per User)
- **GET `/2/users/:id`**: 900/15min (Per User)

現在の実装は、これらのレート制限内で安全に動作しています。

### 2. コストの変動要因

**コストが増加する要因**:
- 投稿数の増加（現在: 408投稿/日）
- メディアアップロードの追加（レート: 0.005）
- ツイート取得・ユーザー情報取得の増加

**コストを削減する方法**:
- キャッシュを活用してAPI呼び出しを削減
- 不要なデータ取得を避ける
- メディアアップロードを最小限に抑える

### 3. 予測と予算管理

従量課金モデルでは、使用量に応じてコストが変動するため：

- ✅ **監視**: 使用量とコストを定期的に監視
- ✅ **アラート**: 予算超過のアラートを設定
- ✅ **最適化**: 不要なAPI呼び出しを削減

- アラート閾値: $40（予算の80%）
