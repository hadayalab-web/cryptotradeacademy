# Whop MCP整理計画

## 📋 現状

### MCPサーバー構成
1. **カスタマイズMCP（`whop`）**
   - スクリプト: `scripts/whop-mcp-server.js`
   - ツール数: 約19ツール
   - 特徴: 日本語説明、独自ツール名（`whop_get_products`など）
   - 状態: ✅ 有効

2. **公式MCP（`whop-official`）**
   - コマンド: `npx -y @whop/mcp`
   - ツール数: 100+ツール
   - 特徴: 公式サポート、英語説明、標準ツール名（`get_products`など）
   - 状態: ✅ 有効

### 問題点
- **重複**: 2つのMCPサーバーが同じ機能を提供
- **混乱**: どちらを使うべきか不明確
- **ドキュメント散在**: 36個のWhop関連ドキュメントが散在

## 🎯 整理方針

### 推奨構成

#### オプション1: 公式MCPを優先（推奨）
- **公式MCP（`whop-official`）**: メインとして使用
  - ✅ 公式サポート
  - ✅ より多くのツール（100+）
  - ✅ 最新機能への対応
  - ✅ 標準的なツール名

- **カスタマイズMCP（`whop`）**: 無効化または削除
  - 理由: 公式MCPで代替可能
  - 例外: 日本語説明が必要な場合のみ有効化

#### オプション2: カスタマイズMCPを優先
- **カスタマイズMCP（`whop`）**: メインとして使用
  - ✅ 日本語説明
  - ✅ 独自の最適化（キャッシュ、リトライなど）

- **公式MCP（`whop-official`）**: 補完的に使用
  - 公式MCPのみの機能が必要な場合のみ使用
