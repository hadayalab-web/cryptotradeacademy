# Telegram全言語版接続テスト結果

全6言語（EN、ES、AR、PT-BR、KO、JA）の有料版・無料版チャンネル

## 🧪 テスト実行方法

```bash
cd cryptosignal-ai
node scripts/test-telegram-all-languages.js
```

## ✅ テスト結果

テスト実行後、各言語の接続状況が表示されます。

### 期待される結果

- ✅ 全言語の有料チャンネルへの送信成功
- ✅ 全言語の無料チャンネルへの送信成功
- ✅ 環境変数が正しく設定されていることの確認

### トラブルシューティング

#### 環境変数が設定されていない場合

`.env`ファイルに以下の環境変数が設定されているか確認してください：

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID_BTC_{LANG}` (各言語)
- `TELEGRAM_CHAT_ID_MINIMAL_{LANG}` (各言語)

#### Botの権限エラーが発生する場合

1. Botが各チャンネルの管理者として追加されているか確認
2. Botに「メッセージを送信」権限が付与されているか確認
3. チャンネルIDが正しいか確認（通常は`-100`で始まる）
