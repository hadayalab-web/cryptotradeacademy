### 🎯 マーケティング戦略：Global Blitz 48h

#### リスト収集チャネル（優先順位順）
週末までの短期間で10万ドルを稼ぐには、最低でも**10,000人〜20,000人の有効リーチ**が必要です（単価$100、CVR 5%想定）。

1.  **Telegramグループ・スクレイピング** - 期待リスト数: 50,000人、CVR: 3-5%
    *   **理由:** 競合製品や類似ジャンルの公開グループからメンバーを抽出。X API Freeプランの制限を受けず、最も高速にターゲットリストを構築可能。
2.  **X (Twitter) キーワード抽出 & メンション/DM** - 期待リスト数: 5,000人、CVR: 2-4%
    *   **理由:** X API Freeを活用し、「特定の悩み」や「競合名」を呟いている層をピンポイントで抽出。数は少ないが質が極めて高い。
3.  **既存メールリスト/データベース (Resend活用)** - 期待リスト数: 10,000人、CVR: 1-2%
    *   **理由:** 過去の接点があるリストへの一斉送信。信頼関係がゼロではないため、初動の売上を作るのに最適。

#### VSL+セールスレター戦略
「なぜ今、あなたに必要なのか」を1分で分からせ、Whopへ流し込みます。

*   **VSL生成**: 
    *   **HeyGen**で各言語のネイティブアバターを作成。
    *   冒頭5秒で「稼げる/解決できる」証拠（実績画面）を提示。
    *   「週末限定価格（$100,000達成イベント）」を強調し、今すぐクリックさせる。
*   **セールスレター**: 
    *   Whopのページ自体をレター化。長い文章は読まれないため、**「ベネフィットの箇条書き」「強力な保証」「限定タイマー」**の3点に絞る。
*   **DM構成**: 
    *   【挨拶なしの衝撃】「（ターゲットの悩み）を解決する準備はできていますか？」＋【パーソナライズVSLリンク】＋【Whop直リンク】。
*   **期待CVR**: 3.5%（VSLによる教育効果込み）

*   **EN (英語圏)**: **「Efficiency & Scale」**。自動化、効率化、圧倒的な収益性をロジカルに訴求。
