## 🔧 実装例

### 推奨実装（本番環境）

```javascript
// GPT-5.2 API関数（本番環境推奨）
async function gptApiRequest(prompt, options = {}) {
  // 本番環境では特定バージョンを使用
  const model = options.model || process.env.NODE_ENV === 'production' 
    ? 'gpt-5.2-2025-12-11'  // 本番: 特定バージョン
    : 'gpt-5.2';             // 開発: 最新版
  
  const response = await openai.chat.completions.create({
    model: model,
    messages: [
      {
        role: 'system',
        content: options.systemPrompt || 'You are an expert assistant.'
      },
      {
        role: 'user',
        content: prompt
      }
    ],
    max_tokens: options.maxTokens || 2000,
    temperature: options.temperature || 0.7
  });

  return response.choices[0].message.content;
}
```

### 1. 特定バージョンの利点

- ✅ **再現性**: 同じ入力に対して同じ出力が期待できる
- ✅ **安定性**: 予期しない変更による影響を回避
- ✅ **デバッグ**: 問題発生時の原因特定が容易

### 3. 最新版の注意点

- ⚠️ **再現性**: 更新により動作が変わる可能性
