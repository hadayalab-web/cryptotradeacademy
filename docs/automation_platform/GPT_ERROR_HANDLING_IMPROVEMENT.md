# GPT APIエラーハンドリング改善

**作成日**: 2026-01-13  
**目的**: GPT APIエラー時のフォールバック処理を改善

---

## 問題点

実際の配信メッセージで「GPT analysis unavailable due to API error.」と表示されることがあり、ユーザー体験が損なわれていました。

## 実施した改善

### 1. メッセージテンプレート側の改善 (`regular.en.js`)

- **エラーメッセージ検出**: API error、unavailable、error、failed、timeoutなどのキーワードを検出
- **フォールバック処理**: エラー検出時は、CryptoQuantデータから基本的な分析を自動生成
- **ユーザーフレンドリーなメッセージ**: エラーメッセージをそのまま表示せず、代替分析を提供

### 2. API呼び出し側の改善 (`cron.js`)

- **エラーメッセージ検証**: GPT分析結果にエラーメッセージが含まれていないか確認
- **null設定**: エラー検出時は`null`を設定し、メッセージテンプレート側のフォールバック処理を利用

## フォールバック処理の内容

GPT分析が利用できない場合、以下の情報を自動生成：

1. **On-Chain Metricsの解釈**
   - Exchange Netflow（Inflow/Outflow）
   - Miners' Position Index (MPI)
   - 価格変動率
   - センチメント

2. **心理的解釈**
   - データから読み取れる市場心理
   - トレーダーの行動パターン

3. **市場コンテキスト**
   - 現在の市場状況の説明
   - 待機モードの推奨

## 改善効果

- ✅ エラーメッセージがユーザーに表示されない
- ✅ 常に有用な情報を提供
- ✅ ユーザー体験の向上
- ✅ メッセージの一貫性の維持
- ✅ フォールバックメッセージから「Please note」を削除し、自然な表現に改善

## 追加修正（2026-01-13）

### Summary行の形式修正
- **問題**: Telegram Markdownパーサーが`[Summary]`をリンクとして解釈し、`Summary`として表示されていた
- **修正**: `[Summary]`を`Summary:`に変更
- **効果**: 意図した通りに表示されるようになった

### フォールバックメッセージの改善
- **問題**: フォールバックメッセージに「Please note: Detailed AI analysis is temporarily unavailable.」という技術的なメッセージが含まれていた
- **修正**: このメッセージを削除し、自然な分析文のみを表示
- **効果**: ユーザーに技術的な問題を意識させず、スムーズな体験を提供
