# 多言語自動マーケティングワークフロー実装ガイド

## 📋 概要

EN版で完成した自動マーケティングワークフローを他5言語（JA, ES, KO, AR, PT-BR）にも実装します。

## 🔄 ワークフローの流れ

### EN版のワークフロー構造

```
ステルス投稿（VSL1）
  ↓
無料版オプトイン
  ↓
無料版利用
  ↓
プロモコード告知（VSL2）
  ↓
Whopアクセス
  ↓
プロダクトページ（VSL3）
  ↓
コンバージョン（無料版オプトインから3日以内目標）
```

### 各フェーズの詳細

#### Phase 1: ステルス投稿（VSL1）
- **タイミング**: 初回接触時
- **目的**: トラップ防御プロトコルの紹介
- **CTA**: 無料版オプトイン
- **VSL**: VSL1（ステルス投稿用）

#### Phase 2: 無料版オプトイン
- **タイミング**: VSL1視聴後
- **目的**: リードマグネットとして無料版を提供
- **CTA**: 無料版登録
- **提供内容**: Trap Score + 簡易分析

#### Phase 3: 無料版利用
- **タイミング**: 無料版オプトイン後
- **目的**: 価値を実感してもらう
- **提供内容**: 定期配信（Trap Score + 簡易分析）
- **期間**: 3日間

#### Phase 4: プロモコード告知（VSL2）
- **タイミング**: 無料版オプトイン後24時間
- **目的**: 50%オフプロモコードを告知
- **CTA**: Whopアクセス（プロモコード適用）
- **VSL**: VSL2（プロモコード告知用）
- **告知内容**: 「残りあと○○枠」の緊迫感

#### Phase 5: Whopアクセス
- **タイミング**: VSL2視聴後
- **目的**: Whopプロダクトページへの誘導
- **CTA**: プロダクトページ閲覧

#### Phase 6: プロダクトページ（VSL3）
- **タイミング**: Whopアクセス後、または無料版オプトイン後48時間
- **目的**: 完全な機能紹介
- **CTA**: 有料版購入
- **VSL**: VSL3（プロダクトページ用）

#### Phase 7: コンバージョン
- **タイミング**: 無料版オプトインから3日以内
- **目的**: 有料版への転換
- **目標**: 無料版オプトインから3日以内にコンバージョン
