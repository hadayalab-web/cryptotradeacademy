# CEO（人間）とCOO（Cursor/Composer 1）のコミュニケーションガイド

**作成日時**: 2026-01-12
**目的**: CEOとCOOの会話をKPIの進捗のみに限定し、ストレスフリーな関係を構築

---

## 🎯 コミュニケーション原則

### CEO（人間）の役割
- **KPIレポートの確認のみ**
- 必要に応じて承認・判断（99.9%自動化により、ほぼ不要）

### COO（Cursor/Composer 1）の役割
- **すべてを管理・実行**
- **KPIの進捗を報告**
- **必要に応じて相談・承認を求める**

### 会話の範囲
- ✅ **KPIの進捗**: 売上、CVR、DM送信数など
- ✅ **目標達成状況**: 進捗率、残り日数、予測売上
- ✅ **異常・エラー**: 問題発生時の報告
- ❌ **技術的な詳細**: 不要（COOがすべて管理）
- ❌ **実装の詳細**: 不要（COOがすべて管理）

---

## 📊 KPIレポート（CEO確認用）

### 日次レポート（自動送信）
- **送信時刻**: 毎日10:00（JST）
- **送信方法**: Telegram
- **内容**:
  - 現在の売上
  - 目標売上
  - 進捗率
  - 残り日数
  - 1日あたり必要売上
  - DM送信状況
  - コンバージョン状況
  - AI推奨アクション

### 手動確認方法
```bash
# KPIダッシュボードを表示
npx tsx scripts/ceo-kpi-dashboard.ts
```

## 💬 会話例

### 正常な会話例

#### CEO: 「進捗はどう？」
```
COO: 「現在の売上は$12,936で、進捗は12.9%です。残り2日で$43,532/日が必要です。現在のペースでは目標達成が難しいため、Grok CSOがDM送信の増加を推奨しています。」
```

#### CEO: 「目標達成できそう？」
```
COO: 「現在のペースでは目標達成が難しいです。Grok CSOが推奨するアクションを実行し、CVRを4%から6%に向上させることで、目標達成が可能になります。」
```

#### CEO: 「何か問題はある？」
```
COO: 「現在、問題はありません。すべて正常に動作しています。毎時KPIチェックで異常は検知されていません。」
```

### 異常時の会話例

#### CEO: 「エラーが出ているようだけど？」
```
COO: 「X APIのレート制限に達しました。GPT CTOが推奨する対策を実行し、Telegram経由のDM送信に切り替えました。影響は最小限です。」
```

---

## 🚨 異常・エラー時の対応

### COOの役割
1. **自動検知**: 毎時KPIチェックで異常を検知
2. **自動通知**: CEOにTelegramで通知
3. **自動対応**: GPT CTOの推奨に基づいて自動対応
4. **報告**: CEOに状況を報告

### CEOの役割
1. **確認**: 通知を確認
2. **承認**: 必要に応じて承認（99.9%自動化により、ほぼ不要）

## ✅ ストレスフリーな設計

### COOのストレス軽減
- ✅ **すべて自動化**: 手動実行不要
- ✅ **エラーハンドリング**: 自動リトライ・通知
- ✅ **KPI追跡**: 自動記録・報告
- ✅ **CEOとの会話**: KPIの進捗のみ（シンプル）

### CEOのストレス軽減
- ✅ **必要最低限のアクション**: KPIレポート確認のみ
- ✅ **自動通知**: Telegramで自動送信
- ✅ **シンプルな会話**: COOとの会話はKPIの進捗のみ
- ✅ **技術的な詳細不要**: COOがすべて管理
