## 📋 デプロイエラー時の対応手順

### Step 1: エラーログの収集

#### Vercel Dashboardから取得

1. Vercel Dashboard → **Deployments** → 失敗したデプロイを選択
2. **Build Logs** または **Function Logs** を確認
3. エラーメッセージをコピー

#### Vercel CLIから取得

```bash
# 最新のデプロイログを取得
vercel logs --follow

# 特定のデプロイIDのログを取得
vercel logs [DEPLOYMENT_ID]
```

## 🔧 よくあるデプロイエラーと対処法

### 1. モジュールが見つからないエラー

**エラーメッセージ例**:
```
Error: Cannot find module 'xxx'
```

**原因**:
- `package.json` に依存関係が記載されていない
- `node_modules` がインストールされていない

**GPT 5.2 Codex Highへの引き継ぎ内容**:
```
モジュール 'xxx' が見つからないエラーが発生しています。
package.jsonを確認して、必要な依存関係を追加してください。
```

### 2. 環境変数が設定されていないエラー

**エラーメッセージ例**:
```
Error: Environment variable 'XXX' is not set
```

**原因**:
- Vercel Dashboardで環境変数が設定されていない
- 環境変数名が間違っている

**GPT 5.2 Codex Highへの引き継ぎ内容**:
```
環境変数 'XXX' が設定されていないエラーが発生しています。
必要な環境変数を確認して、Vercel Dashboardで設定するか、
コードでデフォルト値を設定してください。
```

### 3. 関数のタイムアウトエラー

**エラーメッセージ例**:
```
Error: Function execution exceeded timeout
```

**原因**:
- 関数の実行時間がVercelの制限（10秒）を超えている
- 外部APIの応答が遅い

**GPT 5.2 Codex Highへの引き継ぎ内容**:
```
関数の実行時間がタイムアウト制限を超えています。
処理を最適化するか、vercel.jsonでタイムアウト時間を延長してください。
```

### 4. Cronジョブの設定エラー

**エラーメッセージ例**:
```
Error: Invalid cron schedule
```

**原因**:
- `vercel.json` のCron設定が不正
- Cronスケジュールの形式が間違っている

**GPT 5.2 Codex Highへの引き継ぎ内容**:
```
Cronジョブの設定エラーが発生しています。
vercel.jsonのCron設定を確認して、正しい形式に修正してください。
```

### 5. ファイルサイズ制限エラー

**エラーメッセージ例**:
```
Error: Function bundle size exceeds limit
```

**原因**:
- 関数のバンドルサイズがVercelの制限（50MB）を超えている
- 不要なファイルが含まれている

**GPT 5.2 Codex Highへの引き継ぎ内容**:
```
関数のバンドルサイズが制限を超えています。
不要なファイルを除外するか、vercel.jsonのincludeFiles設定を最適化してください。
```

## 💡 ベストプラクティス

### 1. エラーログの完全な収集

- ビルドログ全体をコピー
- エラーメッセージだけでなく、その前後のコンテキストも含める
- 関連するファイルの内容も含める

### 2. GPT 5.2 Codex Highへの明確な依頼

- 具体的な依頼内容を記載
- 期待される動作を明確に記載
- 試した対処法も記載（重複作業を避けるため）

### 3. 段階的なアプローチ

- まず簡単なエラーから解決
- 複雑なエラーは段階的に解決
- 各ステップで動作確認
