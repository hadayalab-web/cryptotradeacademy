# Telegram特化戦略

**作成日**: 2026-01-13  
**目的**: Trap Defense BTCをTelegram配信に完全特化

---

## 🎯 戦略方針

### Telegram特化の理由

1. **コスト最適化**
   - Resend APIのコストが不要
   - Telegram Bot APIは無料

2. **即時性**
   - リアルタイム配信が可能
   - プッシュ通知で確実に届く

3. **運用負荷の最小化**
   - Bot作成: 1回だけ
   - チャットグループ管理が簡単

4. **ユーザー体験**
   - 暗号通貨トレーダーが日常的に使用
   - メッセージの開封率が高い

## 🔧 環境変数設定

### 必須設定
```bash
# Telegram Bot Token（1つだけ、全資産共通）
TELEGRAM_BOT_TOKEN=your_bot_token_here

# 各資産のChat ID
TELEGRAM_CHAT_ID=...          # BTC用（既存）
TELEGRAM_CHAT_ID_ETH=...      # ETH用（追加予定）
TELEGRAM_CHAT_ID_SOL=...      # SOL用（追加予定）
TELEGRAM_CHAT_ID_MINIMAL=...  # 無料版用（追加予定）
```

### オプション設定
```bash
# Telegram配信の有効化（デフォルト: true）
ENABLE_TELEGRAM=true

# メール配信の有効化（デフォルト: false）
ENABLE_EMAIL=false
```
