# Whop MCPサーバー ツール削減計画

## 現状
- **Whop MCPサーバーのツール数**: 44個
- **全体のツール数**: 85個（推奨制限80を超過）
- **削減目標**: 5個以上削減して80以下に

## 削除候補ツール

### 1. Experience関連ツール（4個）- 高優先度
**理由**: Experience機能が使用不可のため

削除候補:
- `whop_get_experiences`
- `whop_create_experience`
- `whop_update_experience`
- `whop_delete_experience`

**削減効果**: 44 → 40ツール（全体: 85 → 81ツール）

### 2. Entry関連ツール（4個）- 中優先度
**理由**: Experience機能が使用不可のため、Entry機能も使用できない可能性が高い

削除候補:
- `whop_get_entries`
- `whop_get_entry`
- `whop_create_entry`
- `whop_approve_entry`
- `whop_reject_entry`
- `whop_delete_entry`

**削減効果**: 40 → 34ツール（全体: 81 → 75ツール）

### 3. アフィリエイト関連ツール（一部）- 低優先度
**理由**: 使用頻度が低い可能性

削除候補（検討）:
- `whop_get_affiliate_commissions` - 詳細なコミッション履歴（必要時のみ使用）
- `whop_get_affiliate_stats` - 統計情報（必要時のみ使用）

**削減効果**: 34 → 32ツール（全体: 75 → 73ツール）

### 4. 返金・支払い関連ツール（一部）- 低優先度
**理由**: 使用頻度が低い可能性

削除候補（検討）:
- `whop_get_refunds` - 返金一覧（必要時のみ使用）
- `whop_get_refund` - 返金詳細（必要時のみ使用）
- `whop_create_refund` - 返金作成（必要時のみ使用）
- `whop_get_payments` - 支払い一覧（必要時のみ使用）
- `whop_get_payment` - 支払い詳細（必要時のみ使用）

**削減効果**: 32 → 27ツール（全体: 73 → 68ツール）

## 推奨削減プラン

### プランA: 最小限の削減（推奨）
**削除**: Experience関連ツール（4個）
- **削減後**: 44 → 40ツール（全体: 85 → 81ツール）
- **メリット**: 影響が最小限
- **デメリット**: まだ80を超えている

### プランB: 中程度の削減
**削除**: Experience関連（4個）+ Entry関連（6個）= 10個
- **削減後**: 44 → 34ツール（全体: 85 → 75ツール）
- **メリット**: 80以下に確実に削減
- **デメリット**: Entry機能が必要な場合に影響

### プランC: 積極的な削減
**削除**: Experience関連（4個）+ Entry関連（6個）+ アフィリエイト詳細（2個）+ 返金・支払い詳細（5個）= 17個
- **削減後**: 44 → 27ツール（全体: 85 → 68ツール）
- **メリット**: 大幅に削減、余裕がある
- **デメリット**: 一部機能が使用不可になる

## 推奨アクション

**プランB（中程度の削減）を推奨**

1. Experience関連ツール（4個）を削除
2. Entry関連ツール（6個）を削除
3. 合計10個削除で、全体を75ツールに削減

これにより、推奨制限の80を下回り、パフォーマンスが改善されます。

## 実装方法

### オプション1: コードから削除（推奨）
Whop MCPサーバーのコードから該当ツールを削除

### オプション2: Cursor UIで無効化
Cursor Settings → Tools & MCP → whop → 該当ツールを無効化

### オプション3: 条件付き読み込み
環境変数でツールを動的に有効/無効化
