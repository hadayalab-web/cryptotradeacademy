# 思考機能・思考シグネチャ実装

## 概要

Gemini APIの思考機能（Thinking）と思考シグネチャ（Thought Signatures）をMCPサーバーに追加しました。これにより、複雑な問題の分析・解決能力が大幅に向上します。

## 追加された機能

### ✅ 1. 思考機能の強化 (`gemini_generate_text`)

**機能**: テキスト生成に思考機能を統合

- **思考予算**: 推論に使用するトークン数を制御
- **思考シグネチャ**: 思考プロセスの要約を取得可能
- **ドキュメント**: https://ai.google.dev/gemini-api/docs/thinking

**新規パラメータ**:
- `thinkingBudget` - 思考予算（0で無効化、複雑なタスクでは高く設定）
- `includeThoughtSignature` - 思考シグネチャを含めるか

### ✅ 2. 思考分析 (`gemini_thinking_analysis`)

**機能**: 複雑な問題の分析・解決に特化した思考機能

- **ドキュメント**: https://ai.google.dev/gemini-api/docs/thinking
- **推奨モデル**: `gemini-2.5-pro`（デフォルト）

**機能**:
- 推論と多段階計画の能力を最大限に活用
- タスクの複雑さに応じた自動思考予算設定
- 思考シグネチャによる推論プロセスの可視化

**タスクの複雑さ**:
- `simple` - 思考を無効化（事実の取得、分類など）
- `medium` - 中程度の思考（デフォルト）
- `complex` - 高度な思考（複雑な数学、コーディングタスクなど）

## 思考機能の詳細

### 思考予算の設定

思考予算は、モデルが推論に使用するトークン数を制御します：

- **簡単なタスク**: `thinkingBudget: 0`（思考を無効化）
  - 例: 「DeepMindはどこで設立されましたか？」
  - 例: 「このメールは会議を依頼するものですか？」

- **中程度のタスク**: `thinkingBudget: 1000`（デフォルト）
  - 例: 「光合成と成長を例える」
  - 例: 「電気自動車とハイブリッド車を比較対照します」

- **複雑なタスク**: `thinkingBudget: 5000`（高度な思考）
  - 例: 「AIME 2025の問題1を解きます」
  - 例: 「ユーザー認証を含む、リアルタイムの株式市場データを可視化するウェブアプリケーションのPythonコードを作成します」

### 思考シグネチャ

思考シグネチャは、モデルの思考プロセスの要約を提供します：

- **推論の確認**: タスクをどのように分解して結論に達したかを確認
- **デバッグ**: 期待どおりの回答が得られない場合の分析に有用
- **最適化**: 推論プロセスを改善するための情報を提供

## 使用例

### 基本的なテキスト生成（思考機能付き）

```javascript
{
  "model": "gemini-2.5-pro",
  "prompt": "複雑な問題を分析し、解決策を提案してください",
  "thinkingBudget": 2000,
  "includeThoughtSignature": true
}
```

### 思考分析（複雑なタスク）

```javascript
{
  "model": "gemini-2.5-pro",
  "prompt": "AIME 2025の問題1を解きます。17bが97bの約数となるすべての整数基数b>9の合計を求めます。",
  "taskComplexity": "complex",
  "includeThoughtSignature": true
}
```

### 簡単なタスク（思考を無効化）

```javascript
{
  "model": "gemini-2.5-flash",
  "prompt": "DeepMindはどこで設立されましたか？",
  "taskComplexity": "simple"
}
```

## ベストプラクティス

### 1. タスクの複雑さに応じた設定

- **簡単なタスク**: 思考を無効化してレイテンシを削減
- **中程度のタスク**: デフォルトの思考予算を使用
- **複雑なタスク**: 高い思考予算を設定して推論能力を最大化

### 2. 思考シグネチャの活用

- デバッグ時に思考プロセスを確認
- 推論の質を評価
- プロンプトの改善に活用

### 3. 推論のガイダンス

- 特に長い出力を希望する場合は、プロンプトでガイダンスを指定
- 思考の量を制限して、レスポンス用のトークンを確保

## 対応モデル

思考機能は、以下のモデルでサポートされています：

- `gemini-3-pro-preview`
- `gemini-3-flash-preview`
- `gemini-2.5-pro`（推奨）
- `gemini-2.5-flash`

## トークン使用量

思考モデルは、最終的なレスポンスの質を高めるために完全な思考を生成します：

- **思考トークン**: 推論プロセスに使用されるトークン
- **出力トークン**: 最終的なレスポンスに使用されるトークン
- **価格**: 思考トークンと出力トークンの合計に基づいて計算
