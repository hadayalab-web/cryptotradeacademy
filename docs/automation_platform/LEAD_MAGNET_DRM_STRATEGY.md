## 🚀 実装方法

### 1. リードマグネット配布

```bash
# デフォルトリードマグネットを生成
npx tsx scripts/lead-magnet-distribution.ts init

# リードマグネットを配布（Telegram）
npx tsx scripts/lead-magnet-distribution.ts distribute free-report-en telegram EN

# リードマグネットを配布（X）
npx tsx scripts/lead-magnet-distribution.ts distribute free-tool-en x EN
```

### 2. メールアドレス収集

```bash
# リードを登録（メールアドレス収集）
npx tsx scripts/lead-magnet-distribution.ts register user@example.com "John Doe" EN free-report-en telegram
```

### 3. メールシーケンス自動開始

リード登録時に自動的にメールシーケンスが開始されます。
