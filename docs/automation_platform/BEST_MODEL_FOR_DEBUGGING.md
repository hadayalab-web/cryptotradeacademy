## 🎯 デバッグ用途別推奨モデル

### 1. **ビルドエラー・型エラー**: GPT-5.2-2025-12-11 🏆
- **理由**: TypeScript/Next.jsの型エラー解決に最適
- **実装**: `scripts/gpt-mcp-server.js`の`gpt_analyze`ツール
- **使用例**: Next.js 16のビルドエラー解決

### 2. **大規模コードベース分析**: Grok 4.1 Fast Reasoning
- **理由**: 2Mトークンのコンテキストウィンドウで大規模コードベースを一度に分析可能
- **実装**: `api/unified-api.ts`の`callGrok41FastReasoning`
- **使用例**: 複数ファイルにまたがるエラーの分析

### 3. **マルチモーダルデバッグ**: Gemini 3 Pro
- **理由**: コードと画像（エラーログ、スクリーンショット）を同時に分析可能
- **実装**: `api/unified-api.ts`の`callGemini3Pro`
- **使用例**: ビジュアルなエラー情報を含むデバッグ
