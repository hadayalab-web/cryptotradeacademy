feat(services): Optimize AI models for Vercel timeout prevention

P0 Fix: Reduce AI model processing time to prevent 60s timeout

Root Cause:
- GPT analysis uses gpt-5.2-2025-12-11 (heavy, 10-20s per call)
- Gemini deep psychology uses gemini-3-pro-preview (heavy, 15-30s per call)
- Combined with Grok API calls, total processing time exceeds 60s limit

Solution:
- GPT analysis: gpt-5.2-2025-12-11 → gpt-4o (production)
  - Processing time: 10-20s → 3-8s
  - Cost reduction: ~90%
- Gemini deep psychology: gemini-3-pro-preview → gemini-2.0-flash-exp (production)
  - Processing time: 15-30s → 2-5s
  - Cost reduction: ~80%

Impact:
- Reduces timeout risk for /api/x-quote-repost-en and /api/x-quote-repost-es
- Maintains quality for critical gates (GPT_MODEL_GATE still uses gpt-5.2-2025-12-11)
- Development environment still uses premium models for testing

Files Changed:
- services/gpt/client.js: GPT_MODEL_ANALYSIS default changed to gpt-4o
- services/gemini/deepPsychologicalAnalyzer.js: GEMINI_MODEL default changed to gemini-2.0-flash-exp
